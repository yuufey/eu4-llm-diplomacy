## 宏观即时通知的来源缺口

这些通知属于原始需求。每项以正常订阅能交付所需业务变化为目标，复用已有事件顺序、去重、断档、持久化和取消验收。新增来源只检查其实际影响的环节。来源内部的其它写入路径按是否会遗漏既定通知决定处理范围。

| 所需通知 | 当前基础 | 尚缺的交付 |
| --- | --- | --- |
| 宿敌变化 | 正式 v61 已接入生产记录捕获、共享入口、队列、逻辑快照去重和 C04 | 当前世界的实际变化回调与订阅正例；间接或内联写入的未覆盖范围仍需登记 |
| 宣战 | 已有原生 C04 报告、持久订阅、发生时的参战名单及攻守角色 | 绕过现有入口的宣战调用及旧 registry 引用复用的采集覆盖 |
| 关系变化 | 联盟、联姻、保障、军事通行、支持独立和宗属记录已有采样或写入路径及离线交付 | 当前世界的实际回调正例、直接或内联写入的覆盖边界和未分类来源 |
| 本国修正自然到期 | 已有真实到期日志、C04 事件、完整读取和冷重开交付 | 该子项已取得正例；仍需与新增、非到期移除分开验收，不能合并为“修正变化已完成” |
| 本国修正新增及非到期移除 | 已有 N07/N08 查询和离线事件投影 | 实际新增及非到期移除回调与 C04 交付正例 |
| 任务进展 | 已有 M02 跨日查询、变化采样、最外层与直接省份持有条件变化及任务完成来源 | 其它真正写入位置；嵌套条件按当前任务需求处理，任意条件穷举仍属扩展 |

- N02 军团和舰船的规模、类别、人力与上限已能支持核心摘要；精确待补员人数、逐团就绪、逐型号穷举和所有型号正数实采归按需或扩展。

- G03 要塞等级已有验收，归具体省份详情；完整控制区、驻军、补给和国家对汇总按后续情境安排。
- N09 省份产出修正已有公开接口和订阅验收；逐缓存槽、荒废分量和唯一来源归因归扩展研究。
- 任意任务条件穷举、精确贸易反事实模拟、独立自动威胁评分和判断系统不构成当前 P0/P1 门槛，除非某个选定外交决策明确依赖它们。
