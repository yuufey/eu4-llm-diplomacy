# 宏观战略信息范围审查

更新日期为2026-11-07。用户明确以“信息支持宏观战略决策”为原则。本次修订覆盖上一版要求74主题全部收口、所有字段重新核对的安排。审查及复盘已整理，用户已要求按此范围恢复开发。

## 取舍原则

保留会改变结盟、宣战、参战、经济支持、扩张方向、议和和履约选择的信息。涉及具体国家、领土或方案时，展开相关上下文。已有实现与验收记录继续使用，新增采集工作需要说明缺少哪项信息会影响哪个可执行决策。

74主题目录用于追溯历史计划。历史条目中的细节按本页重新取舍，397个实现字段及其内部元数据均有各自用途，数量覆盖与宏观交付完成分别管理。

## 已有检查如何继承

上版表格中统一的“待重核实际配置、字段语义、可知范围与端到端证据”是整理时填写的占位内容，没有逐项对应未完成事实，容易让已有验收被重新排入开发。现已删除该占位列，逐主题写明本轮范围与处理。

- 有现成查询、报告或订阅收据的能力，继承原结论和适用版本、观察方、场景。
- `partial`保留具体限制。已有可用部分继续计入交付，超出宏观范围的剩余细节单独归档。
- 版本、代码、来源配置、路由或语义发生相关变化，或者发现具体矛盾时，安排受影响部分的验证。
- 原生读取的进程、观察方、地址和单位守卫继续在实现中发挥作用。已有来源证明和完整调度演示按依赖变化复用。
- 2秒/5秒独立订阅、取消隔离和恢复矩阵按共享机制验收，后续叶字段变化以受影响入口检查为主。
- 完整回归安排在交付整合里程碑。237批失败与后续修复分开列明，具体阻塞问题按影响处理。
