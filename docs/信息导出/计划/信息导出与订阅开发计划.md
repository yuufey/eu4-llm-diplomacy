# 信息导出与订阅开发计划

2026-11-12执行基线。当前先补完已确定的信息导出条目及规定事件，再开展整体使用验证。开发按宏观战略用途确定目标，每轮交付一项明确缺项，复用已有实现和验收。批次履历见[计划历史迁出记录](../../../logs/文档迁出记录/2026-11-11-信息导出与订阅开发计划-批次履历与测试运行.md)。

## 项目目标与当前用途

项目最终目标是让 LLM 负责指定非玩家国家的外交决策，同时保留游戏原生 AI 对军事、经济等系统的控制，并支持玩家文字谈判。信息模块的直接用途是把游戏状态、外交请求、可用行动和执行结果整理成 LLM 能够比较和复查的输入。

当前原则是“信息支持宏观战略决策”。已有查询、报告、能力发现、多周期采样、自主配置和持久化机制继续复用；按它提供何种宏观战略信息判断条目价值，先补齐既定范围内的缺项。每项开发说明目标字段、使用场景及完成条件，达到条件后转向下一条目。

## 当前范围的依据

[历史功能与验收正文](原始功能与验收要求.md)和[74主题历史目录](LLM导出信息目录.md)保留需求演变记录。当前取舍以用户确认的宏观战略范围为准，具体分类见[宏观战略信息范围审查](宏观战略信息范围审查.md)。

## 宏观战略交付

| 决策问题 | 核心信息 | 范围 |
| --- | --- | --- |
| 当前应处理什么 | 本国、日期、战争、重要提议、战略目标和已有承诺 | 本国及当前相关国家 |
| 能承担什么风险 | 财政与债务、军力和后备人力、主要质量指标、外交资源、国内压力 | 国家级摘要，准确说明单位与缺项 |
| 谁会帮助或反对本国 | 盟友、宗属、保障、停战、宿敌、包围网、好感、人情及承诺 | 与当前比较对象有关的关系网 |
| 向哪里扩张 | 任务目标和战略奖励、核心与宣称、候选领土价值、相关贸易网络与本国收益 | 当前相关任务、地区和节点 |
| 采取哪项行动 | 宣战、召盟、议和及其它外交行动的合法性、成本、接受原因和实际后果 | 具体对象与方案，复用原生预览 |
| 何时重新评估 | 战报、外交请求与回应、关键到期及重大状态变化 | 自动记录事件，交付摘要并保留明确要求的完整记录 |

军力摘要继承已有规模、类别、人力和上限。精确待补员人数、逐记录 strength、具体型号穷举归按需或扩展；要塞等级归具体目标详情，省份荒废度和逐槽产出来源研究归扩展。修正以影响当前判断的有效值、主要变化和关键到期为核心，并对单位、精度、观察方和未知原因作明确说明。

逐场战报按宏观战略用途交付日期、战斗地点、参战双方与观察国所在侧、胜负和双方损失。沿已有来源提供兵力或舰船规模、攻守角色及关联战争，支持判断战局与议和时机。默认输出简洁业务数据，核对损失单位、国家与战斗对应关系。原生Line1、完整弹窗原文、图标及逐控件还原归后续扩展。

宏观即时通知同样属于原需求。核心来源包括宿敌变化、宣战、关系变化、本国修正新增或失效、任务进展及关键自然到期；每项都要说明捕获入口、事件顺序、去重、断档、持久化和订阅交付。自然到期已有正例不替代新增、非到期移除或其它变化的正例。

## 恢复后的执行顺序

| 顺序 | 工作 | 完成条件 |
| --- | --- | --- |
| P0 信息查询补齐 | 补齐既定宏观战略信息条目，包括已明确要求的数量上限和剩余查询主题中的必要信息 | 目标字段能通过正常查询入口导出，值、对象、业务含义及简洁输出可用 |
| P1 事件与战报补齐 | 补宏观即时通知、外交提议生命周期及逐场战略战报 | 捕获、顺序、去重、断档及订阅交付可用，战报胜负、双方损失等必要字段可直接理解 |
| P2 交付整合 | 修复影响上述条目的整合故障，复用调度与恢复验收 | 核心查询、报告及订阅可持续通过正常入口使用 |
| P3 整体使用验证 | 用完整的信息交付验证非玩家国家的LLM方案比较、行动预览与结果复查 | 输入能支持实际外交判断，执行前后结果可复查 |
| 后续与扩展 | 精细模型、穷尽归因、自动威胁评分和长期记忆分析 | 由明确用途决定后续范围 |

每个新增采集项先说明其对应的既定信息条目、目标字段、战略用途和完成条件。优先复用已有读取与来源。达到条目要求后继续下一缺项，只有具体故障或字段含义不清时才深入相关内部细节。已有验收按适用条件继承。正常入口已能交付所需信息时即可结束该条目的开发，LLM整体使用验证统一安排在P3。

查询条目按以下决策用途限定开发深度。各条目的具体完成状态统一见日志。

| 主题 | 战略用途与交付目标 | 完成边界 |
| --- | --- | --- |
| F04 外国压力与继承风险 | 判断外交窗口，提供国家级厌战、叛乱压力、受占领情况、属国忠诚及继承风险 | 交付可见摘要及关键条件，按需求读取相关省份 |
| G05 领土兴趣 | 识别联盟摩擦、许诺土地与议和分配冲突，提供有关国家公开兴趣及交集 | 围绕当前比较对象输出公开信息 |
| W03 战争态势 | 判断战局变化，提供占领、封锁、当前兵力、两次观测间的军力净变化及关联战报损失 | 复用当前军力和历史查询记录，达到国家级趋势比较即可；逐场战报按既定要求交付 |
| P06 和约后续义务 | 比较和约的长期影响，提供停战期限、持续义务及后续整合或再战条件 | 说明所选和约产生的关键后果，复用既有预览与规则 |
| S03 属国状态 | 比较维持、扶植、整合或放弃依附关系，提供自由欲、忠诚、独立支持、贡赋兵役义务、整合条件及进度 | 提供当前关系的有效状态、类型规则与关键条件 |

新增子字段须能回答表中的决策问题。读取规模以选定国家、关系或战争为限，细化到足以解释业务值即结束该项研究。实现中发现的其它机制与细节记入后续范围，再继续既定条目。

W03历史字段名`reinforcement_change`按上述军力净变化范围实现。它比较两次可见规模，可能同时包含损失、新建、解散和补充等影响，不能据此归因具体补员人数。精确补员过程沿用范围审查的扩展分类。

## 检查与完成规则

已有验收按原版本、观察方和场景继承。只有在相关代码、来源配置、协议或语义改变，或出现具体矛盾时，才执行受影响检查；单位未解释的字段继续标明原单位，已有正确读数与解释限制分别记录。

共享查询、报告、调度、取消隔离、持久化和冷重开按功能组验收。单个叶字段的改动按依赖选择验证入口，完整回归集中在整合里程碑；当前失败按是否影响核心交付分类，而不是把每个历史研究节点都提升为新门槛。

完成依据是：上述决策问题所需的信息、查询和事件能通过正常入口使用；LLM 能基于这些输入比较实际外交方案；执行前后的状态和未知原因可复查；已有证据与真正缺项清楚可查。详细清单见[信息计划验收清单](../开发与验收/信息计划验收清单.md)。原 no-repeat、资源上限、观察方隔离、原生读取守卫和按恢复需要保存的规则继续适用。
