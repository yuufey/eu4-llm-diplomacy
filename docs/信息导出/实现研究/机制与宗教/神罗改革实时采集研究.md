## 第117批补充：状态标记与操作按钮已分开定位

新的[控件关联报告](../../../work/runtime/information-full-regression-20261103-117-001/reform-ui-gates-001/widget-binding-report.json)闭合了一个先前未分清的数据流。B23 的改革条目构造函数中，`this+0x28` 接收名为 `reform_selected_frame` 的控件，`this+0x30` 接收 `reform_button`，`this+0x38` 接收 `reform_checkbox`。当前有效中文模组的普通和皇帝两个模板都将它们定义为不同的直接子节点：前者为 `iconType`，后两者为 `guiButtonType`。

两个条件 helper 的布尔结果仅直接传给 `reform_button` 对象。之后的共同路径独立扫描神罗对象 `+0x28/+0x34` 表，与该条目保存的对象指针精确比较，再对 `reform_selected_frame` 选择不同的虚函数路径。因此，不能把这些按钮条件直接当成读取“已通过改革记录”必须满足的条件。这个结论来自静态控制流及命名控件的对应，不是实际绘制观察，也没有闭合虚函数的全部副作用。

普通字节核对范围是 RVA `[0x7068c0,0x7071d5)` 的 2325 字节和 `[0x706210,0x70654c)` 的 828 字节；后一地址更正了旧报告中的 `0x7066210` 笔误。[条件摘要](../../../work/runtime/information-full-regression-20261103-117-001/reform-ui-gates-001/gate-analysis.json)保留世界字段、阈值和未跟随调用，不把它们强行命名为某条游戏规则。

该证据已明确把全局通过表与独立状态标记联系起来，后续只读接口验证应限定为“当前全局记录中的改革标识”，并继续保留实际 UI、效果及更广可知范围的限制；无需先重建全部按钮操作条件。当前私有 v2 profile 和公开工厂尚未改变，也没有把上一进程的空表当作当前值。

本页记录当前全局神罗 `passed_reform` 表的私有只读采集。v2 尚未注册到信息服务工厂；公开的 S01 实时来源仍只支持皇帝和选侯，`reforms` 继续为 `unsupported`。当前研究不能作为外国可见性、改革效果或改革可用条件的证明。

## 读取合同

`empire_reforms_memory.py` 复用现有神罗、世界和国家完整引用校验。已核对的 B23 writer 位于 RVA `[0x701210,0x701423)`，字符串 serializer 位于 `[0x1707cc0,0x1707fab)`；二者是普通字节核对证据，不能称新 REA 证据或运行时执行观察。目标 EXE SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`，上述地址均为 RVA。

神罗对象为当前 world 的 `+0x15d0`。改革表位于神罗对象 `+0x28`，符号 int32 计数位于 `+0x34`；表中每槽为 8 字节对象指针。改革对象 `+0x10` 是 String32 存储，`+0x28` 是容量；容量小于 16 时使用内联存储，否则解引用堆指针。没有把这些对象按固定步长平铺读取。

writer 传入的字符串路径支持按 NUL 结尾读取；serializer 该路径还有 context 字节条件，完整条件语义尚未闭合。采集器采用独立的有界 NUL 读取，不信任尚未核实的对象 `+0x20` 长度字段。ID 只接受最多 128 字节 ASCII 标识，改革数最多 4096；单遍改革读取最多 128 KiB，整次神罗采集最多 512 KiB，单次读取最多 1024 字节。遇到非法计数、指针、字符串、重复 ID 或预算耗尽时，改革项为 `unknown`。

双遍比较分别处理全局状态与改革项：改革项失败或变化时，只撤回改革项；会话、世界、日期、角色或基础神罗引用变化时，撤回整次采集。明确读到稳定计数 0 才能得到私有的已知空列表；缺失、读取失败及历史存档中没有该字段都不表示空列表。双遍一致仍不是原子快照。
