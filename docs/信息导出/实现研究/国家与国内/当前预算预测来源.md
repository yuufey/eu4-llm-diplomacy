# 当前月度预算预测的来源

当前公开接口已能查询、报告和订阅[上月经常性收支](../../02-使用与接口/国家与国内/月度经济台账只读接口.md)。本轮继续核对当前预算预测，已经定位经济界面的12个收入分项、21个支出分项及合计位置；这些发现属于来源研究，尚未新增公开字段或改变月度接口的口径。

收入分项在经济视图中按32位加法合计，存入视图的 `+0x578`；支出合计存入 `+0x5bc`，界面结余以这两项相减得到。分项包含省份和其他对象遍历、维护费用及修正计算，不能只复制一个国家字段就取得全部当前预算。视图选择的国家也必须与信息服务观察国绑定，现有缓存的新鲜度尚未证明。

另一个候选字段是存档中的 `estimated_monthly_income`。已确认它以 signed int32、scale 1000 保存在国家对象的 `+0xe38`。所定位的写入路径先把本月台账转入上月台账，再从收入槽位 `0..8、15、16` 求和，最后把低于1的原值设为1。因此，这条路径产生的是带下限的台账估计值，不能仅凭字段名称就当作当前预算预测。具体调用日期和所有写入路径仍待确认。

本次独立只读采集取得 FRA `+0xe38` 的两遍原值 `21104`，即21.104金币；它与此前上月经常性收入相同。两份原始记录分别保留，这个相等样本本身不证明它与界面预测相等。采集复用现有国家定位和清理流程，没有调用游戏函数或修改游戏状态。

下一步从已经定位的国家计算入口核对参数和返回值，优先复用引擎计算。公开当前预测前，还需证明显式国家绑定、计算口径与结果时效；本轮不扩大现有字段的完成状态。
