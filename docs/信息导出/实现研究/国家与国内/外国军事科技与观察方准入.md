# 外国军事科技与观察方准入

F02 支持目标国家的 `military_technology`、[外国人力](../../02-使用与接口/国家与国内/外国人力查询.md)、[外国陆海军统计](../../02-使用与接口/国家与国内/外国陆海军统计查询.md)和[军力质量](../../02-使用与接口/国家与国内/外国军力质量查询.md)。`visibility` 分别说明国家查看条件与各类军事字段的准入；六字段均为 **partial**。实际界面显示、缓存刷新时机和主线程原子性尚未验证。下文保留科技来源及此前实测范围。

## 查询哪个国家，从谁的视角查询

当前支持 EU4 1.37.4 的固定 B23 程序，逻辑观察方为非玩家法国（FRA）。查询对象中的 `country` 表示目标国家；例如 ENG 读取英格兰，而不是读取法国后换一个标签。法国自身军事科技继续使用 N03。

```json
{
  "request_id": "foreign-tech-query-example",
  "queries": [
    {
      "topic": "F02",
      "object": {"type": "country", "country": "ENG"},
      "fields": ["military_technology", "visibility"]
    }
  ]
}
```

读取先在完整国家表中解析 FRA 和 ENG，保留完整国家引用并核对槽号。它不局限于前256个槽，也不会把特殊的 `---` 占位条目当作普通国家。父读取器核对进程、会话、EXE、原生代码字节和游戏日期，并独立确认 FRA 的控制器类型为 AI；物理客户端当前国家只用于记录和一致性检查，不替代逻辑观察方。

## 准入条件的来源

静态证据已区分两条 UI 路径：原先本国技术证据来自单位选择界面；外交界面的 `mil_value` 则从所选国家读取 `mil_tech` 缓存。其数值写入位于后续本国专属分支之前，不能把那个后置分支当成外国科技的限制。

实际“查看国家”入口另有目标准入条件。读取器复现固定版本中对完整国家引用、特殊槽、关系缓存计数、标志及位图的判断，并用 FRA 的绑定重新索引。它计算的是 **法国视角的原生规则投影**，不是声称当前客户端已经为法国执行了该函数或打开了窗口。

该来源明确标记：

- `basis: native_country_view_predicate_projected_to_observer`。
- `actual_UI_observed: false`。
- `projected_observer_view: true`。

上述国家查看条件用于 `military_technology`；人力及陆海军另有同一原生军事统计条件。军事质量另行判断原生页面选项与发现条件，不能把通过国家查看条件解释成看见全部外国资料。

## 结果如何区分

| 状态 | 含义 |
| --- | --- |
| 科技 `known` | 目标绑定、两遍读取和准入投影均有效；返回目标的原生缓存整数及原始字节 |
| 科技 `invisible` | 该观察方的准入投影明确拒绝；不返回科技值或原始字节 |
| `unknown` | 绑定、代码字节、原始读取或准入条件不足，或两遍不一致 |
| `unavailable` | 当前会话或来源尚未就绪 |

科技值单位为 `technology_level`、scale 为1。它不是本国单位选择界面的“下一等级”预览，也不加1。真实零值保留为0，不用0代替未知或不可见。公开结果只保留字段值和必要来源说明，不输出进程地址、国家表行或准入计算的私有原始操作数。

## 已验证的范围

当前真实进程保持玩家 POR、非玩家观察方 FRA、raw56564448。两遍只读数据确认 FRA 槽122且由 AI 控制，ENG 槽46；读取英格兰军事科技为4，原始字节 `04000000`。FRA 的准入投影沿缓存计数0、标志分支和观察方位图到达允许结果。没有切国、保存、重启、注入或推进日期。

真实 MCP 在同一服务中完成一次主动查询、一次保存报告查询，以及两个独立周期：2秒任务交付2次，5秒任务交付1次。五次实际采集的字段一致，原始报告逐份归档，并以公开来源中的报告散列关联。订阅均已取消，服务 exit0。见[MCP收据](../../../work/runtime/information-foreign-visibility-20261029-001/mcp-live-001/receipt.json)和[原始读取](../../../work/runtime/information-foreign-visibility-20261029-001/private-live-probe-002/receipt.json)。

首次开发读取因解析器错误拒绝 `---` 特殊行而撤回；修正后才有上述成功结果，失败原件保留。这个修正没有改变普通目标的完整引用、槽号、重复项和指针校验。

国家解析、准入规则、两遍后台读取、父级原始记录重建和公共字段过滤共90项定向通过。630份选定来源在完整回归前冻结并在结束后复核；唯一full为3434项通过、106项失败、35项错误及2005个子测试通过，较75批无新增失败，整套仍非全绿。见[回归比较](../../../work/runtime/information-foreign-visibility-20261029-001/regression-comparison-001.json)。

[独立实采审计](../../../work/runtime/information-foreign-visibility-20261029-001/independent-live-audit-001.json)逐份重放5个原始capture，并核对规范散列、字段和交付关联。结果列表还保留两条主动查询的副本，实际周期交付为3条，不能把列表总数当作周期次数。字段覆盖仍按完整74主题397字段维护，本批仅将 F02 两个字段从 planned 推进到 partial。
