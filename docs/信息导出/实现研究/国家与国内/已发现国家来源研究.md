## 可复用内容与缺口

固定的 CWTools EU4 规则中，`triggers.cwt:2672`、`:2676` 声明 country-scope `knows_country`，参数为国家 scope 或国家标签，说明为“当前国家知晓国家 X”。这是比 `has_discovered` 更准确的语义入口。后者主要判断省份发现状态；`effects.cwt` 的 `discover_country`、`undiscover_country` 则在 province scope 操作视野，名称相似不能作为国家集合来源。

现有 `CwtoolsScriptParser` 解析规则结构，不执行 `knows_country`。已固定 Jomini/eu4save 的国家模型和本仓库存档适配器也没有直接返回观察国国家知晓集合的字段。现有 `country_view_admission_memory` 只投影 `mil_value` 使用的国家视图准入，不等于已发现国家谓词。独立复用审计固定了19个当前来源，原件为 `work/runtime/information-country-discovery-20261103-129-001/reuse-audit-001/report.json`。

`C02.related_countries` 还缺集合成员规则。战争、盟友/婚姻、保证/军事通行、属国等已有来源可分别复用，但没有依据把任何一种关系子集当成该字段的完整结果。
