# 原生港口谓词与河口来源

实时 `G04.ports` 可查询一个明确省份的引擎 `has_port` 谓词。它读取当前省份记录，不依赖海岸贸易中心、地图位置、历史初始配置或物理玩家视角。当前支持 EU4 1.37.4、逻辑观察国 FRA，以及已通过法国发现正位校验的省份。

```json
{
  "topic": "G04",
  "object": {"type": "province", "province_id": 227},
  "fields": ["ports"],
  "parameters": {}
}
```

已核对的结果形如 `{"province_id":227,"has_port":true}`。字段为 `partial`、`complete=false`，支持主动查询、报告和周期订阅。它不枚举所有港口，也不提供港口设施、泊船权、造船条件、行动资格或实际界面显示；国家和节点范围的完整港口清单仍未完成。无发现证据、读取失败、身份变化或双遍不一致返回未知／不可用，不能当作“没有港口”。

开启静态贸易数据时，`T06.targets` 的本页候选也复用同一个 G04 来源，填入 `classification.port`。港口读取与原 G02 属性是分别验证的读取，不是原子快照。一个港口读取失败不抹去其它已知注释；观察国、会话、世界、版本、EXE或日期在组合读取前后变化则撤回组合结果。同一页重复省份共用一次港口读取，不跨请求缓存。该谓词不代表目标值得扩张或能增加多少贸易收入。

## 本次验证与限制

实机逻辑 FRA、物理 POR，1456.7.26暂停。227 Lisboa 返回真；182 Vermandois、183 Ile-de-France、187 Barrois 返回假。每项均与原始8字节及公开结果核对，港口字段也与贸易候选的注释一致。主动查询、报告、2秒／5秒周期语义一致，短订阅取消后长订阅仍运行，最终全部取消，服务及读取线程退出。每次采集摘要独立核对，语义比较仅排除随采集变化的摘要，其余来源信息保留。

最初验收脚本错误地预期187是港口正例；原三份读取与投影实际都正确返回假，因此保留原结果，只对未读取的227补一次正例，没有重采原三省来修改结果。原字符串引用查询为空；直接数值搜索中的候选经小段解码确认只是栈偏移，已排除，未用于实现。真正映射来自既有工厂的比较和跳表。

本批没有执行游戏函数、外交动作、日期推进、保存、读档、重启或注入，也没有 UI 操作。REA始终复用已有只读静态库，不重新导入。新叶子、来源、目标集成与相关父级回归共145个唯一用例有通过记录；完整测试集未重验，`whole_suite_passed=false`。证据位于 `work/runtime/information-port-estuary-research-20261105-197-001/`。
