# 当前节点贸易收入重算

第209批在 T06 条件情景的 `assumptions.value.native_income_calculation` 中补充当前收入缓存的重算结果。仅当请求包含 `total_power_input_model=fixed_other_country_power` 时按需采集，普通查询及显式给定总量的情景沿用原有读取路径。

这项结果用于解释当前收入从哪些输入算出，并与同次读取的收入缓存比较。未来收入仍使用既有条件模型；当前重算没有证明取得省份后的份额、节点金额、国家修正或整个贸易网络会怎样变化。

## 计算规则

限定当前 EU4 1.37.4、EXE SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。以下地址都是相对于该二进制的 RVA；运行时按实际模块基址定位，不将静态 VA 当成实机地址。

原生收入写入函数 `[0xb58360,0xb58a7e)` 先将国家节点行 `+0x2c` 与节点 `+0xb0` 相乘，除以1000，写入行 `+0x38`；随后调用 `[0xb58a80,0xb58b30)` 取得倍率，再将行 `+0x38` 与倍率相乘、除以1000，写入收入行 `+0x34`。两次除法分别向零截断，商只保留有符号32位；不能把它们合成一次除法。

倍率计算先通过国家 `+0x2440` 指向对象的 `+0x20` 取得基础项，加上国家修正容器中索引14的值，再按有符号32位结果限制到10至2000，之后加1000。当国家槽位等于特定全局槽位，或该国家节点行 `+0xae` 非零时，另加全局附加项。

索引14必须在当前引擎加载的描述符中精确对应 `trade_efficiency`，且处理器指针为空。读取器复用已有稠密／稀疏容器解析，不执行处理器；国家修正缓存仅支持稳定的状态0或2。其它状态和处理器存在时返回未知，不能把原始数组值冒充完整原生 getter 的结果。

当前份额来自行 `+0x2c` 缓存。它的原生写入使用节点 `+0xd0` 作为分母，不能用本国力量除以节点 `+0xc8` 的结果替换。节点 `+0xb0` 的生产与刷新路径仍在研究，因此这里只使用当前复制值，暂不把它命名为已经闭合来源的未来节点价值。

## 采集与未知状态

新增读取与既有收入、力量和求和成员读取共用一次父采集及进程句柄，父级总预算仍为512 KiB。新叶子每遍最多64 KiB、4096次读取；不追加完整国家表扫描，不读取外国国家的力量值。

读取器复用已经验证的法国 NPC 身份和唯一求和成员证据，并重新读取规范国家单元、fullref、选中节点定义、国家行与输入。节点 `+0xd0` 为零，或原生空行／fullref 条件会跳过该收入写入时，重算返回未知。所有实际使用的输入字节都在叶子内再次读取，父级再进行两遍比较。

公开结果必须同时满足：请求中的节点标识一致、父级前后两遍与顶层子记录一致、每遍严格回放成功、子记录的逐读字节与该遍父日志一致。稳定的未知子项只影响当前收入重算；其它已有有效信息继续交付。父级真正发生两遍漂移时仍撤回整份观察。

成功结果分别保留 `inputs`、`outputs`、`cache` 和 `matches_cache`。缓存不相符时如实给出 `false`，不将算出的值改成缓存，也不据此宣称缓存一定已经过期。`period=current`、`complete=false` 继续表示范围与刷新限制。
