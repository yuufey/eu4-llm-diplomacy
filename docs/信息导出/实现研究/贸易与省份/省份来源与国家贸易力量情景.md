# 省份来源变化与国家贸易力量

第208批已增加[固定其它国家贡献的自动总量模式](../../02-使用与接口/贸易与省份/节点总力量自动情景接口.md)，在同次采集中核对法国的唯一求和成员和非玩家身份后推导总量；下文显式总量形式仍适用。

第206批为 `T06.expected_trade` 和 `T06.assumptions` 增加一种条件情景：调用者给出本国节点中省份来源的变化，接口按已确认的原生整数计算推导本国竞争力变化，再交给已有收入模型。原有直接给出 `country_power_delta_raw` 的方式继续可用，两种方式可以在同一请求内混合。

这个输入表示本国节点基础项中已明确假定的省份来源变化。取得某个省份是否产生该变化、控制国与所有者修正如何随之改变，仍需另行分析。候选省份当前的力量不能直接当作法国取得该省后的变化量。

## 请求与结果

```json
{
  "topic": "T06",
  "object": {"type": "trade_node", "node_id": "champagne"},
  "fields": ["expected_trade", "assumptions"],
  "parameters": {
    "scenarios": [
      {"id": "manual", "country_power_delta_raw": 0, "total_power_delta_raw": 0},
      {
        "id": "province-source",
        "power_input_model": "province_source_fixed_other_inputs",
        "province_power_delta_raw": 50000,
        "total_power_delta_raw": 50000
      }
    ]
  }
}
```

每条情景必须使用下列一种形式，不可混用：

| 形式 | 必填变化量 | 计算方法 |
| --- | --- | --- |
| 手工国家变化 | `country_power_delta_raw`、`total_power_delta_raw` | 直接使用给定的国家与总量变化 |
| 省份来源变化 | 上例中的固定 `power_input_model`、`province_power_delta_raw`、`total_power_delta_raw` | 推导国家变化；总量仍使用调用者给定值 |

变化量都是 signed i32；力量比例尺为1000，raw1000表示1点。原有1至8条情景、唯一编号、说明长度、输入64 KiB与输出4 MiB限制保持。选择 `costs` 时继续逐情景提供 `actions`，沿用当前行动预览，不执行行动，也不证明这些行动会产生给定的变化。只选择 `targets` 时仍不读取贸易基线，即使附带了有效情景参数。

收入结果的 `value.scenarios[]` 保留调用者的原始 `inputs`。省份来源情景另有 `power_transition`，其中给出国家力量前值、后值、变化量，基础项与限额的前后值，以及本次是否走限额刷新分支。不能计算时仅该情景的力量转换为未知，不把它填成零或影响有效的手工情景。

`expected_trade.native_power_scenarios[]` 单独保留每条省份来源情景的转换。因此，波尔多这类当前不收取收入的节点，也能提供条件国家力量变化；收入仍为未知。收入有效域检查独立进行，例如调用者给定的总量变化使新总量无效时，收入未知而力量转换仍可已知。

`assumptions.value` 返回原始情景、五个原生分量、本次固定输入和总量假设。新模式的 `native_power_components` 使用算术名称 `multiplier_raw`、`cap_raw`、`base_raw`、`subtract_raw`、`add_raw`；这些名称不把尚未确认的分量冒称具体游戏机制。新字段和收入结果均保持 `game_fact=false`、`complete=false`。

## 算术与证据边界

既有国家力量计算器使用国家节点条目的 `+44/+48/+4c/+50/+54`：倍率乘基础项后按1000向零截断，取商的低32位并夹为非负，再与限额取有符号最小值，最后加上“加项减去减项”，保留32位回绕。实现复用现有 `trade_power_memory._country_power`，没有另写一份国家力量公式。

省份来源情景只把给定变化加到 `base_raw`，保留32位回绕；倍率、减项与加项固定。随后按原生尾部的条件更新限额：若当前公式值不大于未限额的非负乘积商，则把限额改为该商，否则保留限额。再计算后值。国家前后值的差若不能用signed i32表示，转换为未知，不对差值静默回绕。

基线必须与既有国家力量公式一致，倍率至少为10，并且对基线执行上述限额刷新不能改变当前国家力量；不满足时返回明确未知。该检查是条件模型的输入要求，不证明采集发生在原生刷新流程的哪个阶段，也不证明后续会在何时执行同样刷新。

静态依据复用第205批保存的B23有界普通反汇编：省份当前力量加到控制国条目基础项，以及函数尾部 `RVA [0xb51f23,0xb51f88)` 的倍率与限额运算。EXE SHA-256为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`，静态映像基址为 `0x140000000`。这是普通静态证据，不能当作新的REA证据或本轮实际执行了该游戏函数。

第207批已确认[特定国家列表的总量求和阶段](节点总贸易力量更新依据.md)，但现有采集尚未保留这份列表，无法确认法国在其中恰好一次；刷新时点与完整网络反应也未闭合。因此本接口仍要求调用者明确提供 `total_power_delta_raw`，不会根据国家变化补造总量。收入继续采用[原有固定环境模型](../../02-使用与接口/贸易与省份/贸易竞争力条件情景接口.md)，贸易网络反应、实际行动效果和未来收入均未完成。

## 采集与验证

原生基线读取器只在新模式需要时保留分量，来源是同次T04已验证报告的compact provenance；不增加组件内存读取或第二次T05采集。默认读取仍返回原有形状。自定义旧读取器继续按原签名调用一次，缺少分量时仅新模式未知，不通过捕获参数错误再采集一次。
