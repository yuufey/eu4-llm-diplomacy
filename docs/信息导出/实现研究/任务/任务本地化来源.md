## 第七批：有限动态派生

第七批静态、运行与条件派生的总索引见[research-index-002](../../../work/runtime/information-dynamic-text-20261024-001/research-index-002.json)；旧 `research-index.json` 保留为未接入状态的历史索引。

第七批把动态来源研究落成一个边界明确的派生适配器。合同文件为[dynamic-localization-contract-002.json](../../../work/runtime/information-dynamic-text-20261024-001/dynamic-localization-contract-002.json)，SHA-256 为 `ea13b783902b9a5410aa808ae7956e03732fe57376383cd0d4ea094ac9f1a5f7`；固定游戏版本仍为 1.37.4，Root 绑定是显式查询的 FRA 观察方。派生过程没有调用原生函数、没有调用选择器，也没有读取游戏 UI 的 Root，因此报告中的 `ui_root_scope_verified` 保持 `false`。

方法白名单只有 `GetSelectableMissionTitle` 和 `GetSelectableMissionDescription`。运行时自定义记录必须是单一候选、零谓词、空权重修正、正权重小于 `2^31`、无内建同名项并满足 Root promotion 枚举 `3`；这些条件只支持“单个无条件正权重选项”的确定性派生，不能推广到多候选、一般 trigger 或其他国家/省份方法。`0xb78bc0` 的静态证据表明，模板处理会复制方括号标记前的字面前缀、追加标记结果并继续处理后缀；因此合同 002 允许一个受支持的 Root 标记带字面前后缀，保留原始空格和格式控制。前后缀混入其他 `[]` 或 `$` 标记、出现多个或重复标记、括号不平衡、缓存未明确编码或缓存仍是动态值时，适配器保留 `unknown`。这扩展的是模板匹配政策，不是内存布局或引擎算法的改写。

003 实采报告确认 61 个任务的 122 个键中派生 14 项、已知 116 项、未解析 6 项；名称字段为 `status=known`、60 个已知/1 个未知，说明字段为 `status=known`、56 个已知/5 个未知，两个字段容器均为 `complete=false`，顶层结果为 `partial`。主动逐项、单项和三次两秒周期均交付；POR 玩家槽189、FRA 观察方、暂停状态和 raw 游戏日保持不变。详见[003 live 报告](../../../work/runtime/information-dynamic-text-20261024-001/live-acceptance-003/report.json)和[003手工结果](../../../work/runtime/information-dynamic-text-20261024-001/live-acceptance-003/manual-result.json)。方法捕获 SHA-256 为 `b0608f11ba54c174dcb742bfeddbcfd77ddbc671802d27be834d786cd28c1e8f`，原生缓存 SHA-256 为 `985d1b5b8bb839d6295f91e7b19f8ad369ca278a651164d4ed8f27b5b06ca3c1`。002 的自动分项检查曾因期望值书写错误而失败，随后按独立逐字段期望重跑 003；该失败报告保留为历史审计记录。

## 历史静态调查

静态调查找到当前61个任务的122个 `_title`、`_desc` 候选 key，没有缺项或同层重复歧义。最终有效文本全部来自当前启用模组栈第0项的 `domination_l_english.yml`；文件 SHA、行号、语言头、原始值和覆盖来源保存在[机器报告](../../../work/runtime/information-loaded-tasks-20261024-001/localization-source-review.json)。补充模组没有 localisation 目录，桥接模组没有这些目标 key。

这项调查没有把名称和说明登记为已实现字段。原生 `0x487ae0` 已确认任务 ID 加 `_title` 的名称 key；提示函数 `0xfc0050` 复制任务 ID 后追加5字节常量，并将结果交给本地化函数。磁盘6字节读取确认该常量为 `_desc\0`，记录见本批 `description-key-constant.json`。当时的静态调查尚未证明运行语言和动态文本替换；003 只在合同 002 的有限范围内完成派生。实际静态文本含7类动态 token；原样文本不能自动当作最终显示字符串。

已有 `bridge/native_text.py` 的 eu4_escape 解码可作为中文恢复候选。调查中的 `fra_liberate_norm_title` 可静态恢复为“解放诺曼底”，但编码逆变换、当前语言及最终界面仍需独立验证。不得用 Latin-1 的成功解码证明得到正确中文，也不能把任务 ID 当作名称。

研究脚本为 [research_information_mission_localization.py](../../../work/research_information_mission_localization.py)。它检查有效版本与模组栈，有界扫描76,373,667字节的本地化文件并保留来源；没有读取游戏进程、存档或调用游戏函数。调查基于当时捕获根所对应的静态61任务；随后第五批的原生子任务读取独立确认当前也为61项，二者的证据类型继续分别记录。
