# 非玩家战报的独立名称行格式化

278批新增独立格式化路径。它在一场战斗的router作用域结束时，使用已经复制的名称原料和本地化模板，请求游戏格式器生成名称行。279批已部署v42，并取得陆战、海战各一条实际原生输出。

## 279批实机结果

唯一新窗口为1445.2.5→3.12，逻辑观察方FRA、物理玩家POR。实际陆战UTR/REB输出“上斯蒂奇战役”，海战KNO/HSK输出“纪伊水道战役”。原生独立格式器调用2次、复制2次、失败0次，旧title helper调用0次。两条记录的IFMT标志均为15，输入沿插件赋值前的派生名称字节，输出与同场NAME输入相等，符合当前`$NAME$`模板。

FRA均未参战，因此公开FRA战报交付为0。对这两条私有记录的正常B04查询均返回`BATTLE_RECORD_NOT_AVAILABLE_IN_OBSERVER_SCOPE`。原弹窗Line1及原始NAME赋值仍未取得，这两次独立输出的`native_line1_verified`、`is_native_raw_text`及完整战报状态继续为false。

安装器与入口预检已支持v42的150份自固定来源。原有平铺来源校验已能定位两个candidate头，直接复用。F03新增精确v42钩子资产及r7配置，Feb5准备阶段通过正常入口取得FRA贷款0、本金0与ENG贷款本金0.0ducats。该财政样本日期独立于Mar12终点。127项定向检查通过，旧v34/v41证明内容保持一致，完整回归沿270及后续定向收据。[279批收据](../../../work/runtime/information-independent-line-deploy-20261108-279-001/summary.json)

## 输入与调用

当前实现只处理`LANDBATTLEOVER_1`与`NAVALBATTLEOVER_1`的`$NAME$`模板。名称原料沿wire11的同场复制，定义键、模板和语言沿wire7的作用域结束复制。两组数据的序列、日期、战斗类型和语言须对应。

原始helper模式按前缀、全局名称、省份名称顺序组合。固定中文插件模式沿已有赋值前字节模型，先组合两项名称原料，去掉首字节，再追加前缀。插件模式的输入阶段仍记录为`plugin_pre_assignment_text`。原生NAME交接及插件String32赋值状态沿原有来源。

参数构建复用已验证的`format_input_builder.h`，使用一个type-2的NAME参数和工作区拥有的稳定C字符串。名称最多8188字节，给现有8192字节输出读取上限保留颜色包装余量。前缀带美元语法、正文模板不符、输入缺失、身份或语言冲突时保留具体失败，已有战斗内容继续保留。

原生格式器RVA为`0x14b33a0`，ABI沿已有固定B23的REA合同。新守卫另复制并核对RVA`[0x14b33a0,0x14b33c0)`的32字节前缀，属于普通PE字节依据。原有代码、线程、游戏对象、玩家和日期守卫继续执行，调用前、调用后及销毁后重读定义与本地化内容。输出先复制到自有记录，再销毁自有String32一次。

固定游戏SHA为`b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。以上地址均为RVA，运行地址由实际载入基址相加得到。[既有ABI合同](../../../work/runtime/information-diplomacy-state-20261028-001/battle-body-query-source-001/format-input-contract-001.json) [新增前缀依据](../../../work/runtime/information-battle-independent-line-20261108-278-001/formatter-prefix.json)

## 记录与正常入口

IBOW14完整嵌入原IBOW13，IFMT扩展保留序列、日期、战斗类型、失败阶段、名称来源模式、调用标记和五项原始字符串。五项分别为语言、定义键、正文模板、NAME输入和独立输出。

公开结果位于`B04.details.value.independent_line`，wire14的公开投影为31。Python投影再次对应原记录的模板、语言和名称候选，输出按`eu4_escape`解码。已知结果提供`native_formatter_invoked=true`、`native_output_copied=true`及输入来源。原生弹窗Line1的验证状态继续由其原有采集来源决定，独立输出的`native_line1_verified`、`is_native_raw_text`和整体完整性均为false。

结果组合器优先采用实际捕获的弹窗Line1，其次采用已知独立输出，随后采用现有名称行候选。独立请求失败时，原候选及其他控件内容继续可用。现有查询、事件报告、brief文字和完整结果读取均已接线。观察方准入继续要求完整参战向量包含观察国。
