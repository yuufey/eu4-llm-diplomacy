# 领土与贸易权转移接口

`G04.transfer_relations` 将指定省份或贸易节点与观察国当前的贸易权转出、转入记录关联。它复用 `StaticTradeSource.G04.trade_node` 的有效磁盘配置索引和 `NativeTradeTransferSource.T05.transfer` 的既有原生读取器，没有新增解析器、原生布局或游戏函数调用。

当前支持 EU4 1.37.4、逻辑观察国 FRA。指定省份需要同时启用 `--static-game-data`；直接指定贸易节点时可复用原 T05 节点选择器。字段为 `partial`、`complete=false`，支持查询、报告和现实/游戏时间周期订阅，不声明原生事件通知。

```json
{
  "topic": "G04",
  "object": {"type": "province", "province_id": 174},
  "fields": ["transfer_relations"],
  "parameters": {}
}
```

同一字段也支持：

```json
{
  "topic": "G04",
  "object": {"type": "trade_node", "node_id": "bordeaux"},
  "fields": ["transfer_relations"],
  "parameters": {}
}
```

省份查询先取得唯一的配置节点，再将该节点交给既有 T05 读取器一次。有效配置缺失、节点歧义或输入文件变化时，关联结果保持未知或不可用。配置指纹在读取前后核对，但磁盘配置是否与本进程启动时加载的内容相同仍未证明；结果通过 `selection.basis=effective_disk_trade_definition`、`loaded_membership_verified=false` 明示这一点。直接指定节点使用 `explicit_trade_node`，该选择不涉及省份映射，`loaded_membership_verified` 为 null。

返回值保留原 `to`、`from` 容器的方向、国家、原始带符号值和缺项。单位为 `trade_power`，实际数值为 `raw / 1000`；已核对的空容器保留 `known` 和空列表，不转换为未知。容器状态未知也继续保留，不能把外层节点已识别解释为全部关系已知。

第182批在当前 v37 会话的实际读取得到：波尔多节点中法国来自奥尔良（ORL）的转入原值为6725，即6.725点贸易权；转出容器已知为空。首个省份映射查询只调用一次旧 T05 读取及一次旧原生采集，耗时约0.515秒。实际 MCP 省份174查询约0.297秒，直接节点查询约0.281秒；这些是本次观测，不是延迟保证。

数量来自法国的节点缓存，不表示省份自身产出的贸易权，也不表示国家全部外交关系、商人引导方向、节点价值流量或预期收入。缓存新鲜度和其他观察国的可见范围沿用旧 T05 缺项，未扩大公开范围。原接口及单位说明见[贸易权转移只读接口](贸易权转移只读接口.md)。

实际 MCP 查询、报告、2秒/5秒周期均返回同值；取消短周期后长周期仍运行，最终两个订阅均取消、服务及读取线程结束。周期查询每次重新读取，未跨请求缓存旧原生快照。当前 `G04.trade_node` 仍由独立静态来源提供，其触发能力以发现结果中的字段声明为准。
