# 节点贸易金额汇总接口

T06 目标页的 `rows[].current_trade_power.node_cash_aggregate` 汇总当前加载节点成员的省份金额输入，并与同次读取的节点 `+0xb0` 缓存比较。它与原有力量、省份金额注释共用一次采集，提供当前金额来源的核对结果；取得省份后的收益仍需另行计算，`classification.expected_benefit` 保持未知。

## 返回内容

注释保留 `period=current`、`partial=true`、`complete=false` 和 `native_function_invoked=false`。`value` 中的字段分别说明以下事实：

| 字段 | 含义 |
| --- | --- |
| `node_id`、`center_province_id` | 本次读取的加载节点及中心省份 |
| `member_count`、`valued_member_count` | 成员总数、已能计算金额的成员数 |
| `unresolved_province_ids` | 尚不能计算的成员省份；不会按零参与求和 |
| `all_member_values_known` | 是否每个成员都有当前金额输入 |
| `province_input_sum_raw` | 所有成员输入按有符号32位回绕累加后的值；有未知成员时为 `null` |
| `calculated_node_cash_raw` | 完整合计统一除以12并向零截断后的值；有未知成员时为 `null` |
| `cached_node_cash_raw` | 本次复制的节点 `+0xb0` 值 |
| `matches_cache` | 完整重算与缓存是否相等；有未知成员时为 `null` |

金额按1000为比例尺，单位标为 `node_cash`。`current_only=true`、`cache_refresh_verified=false` 和 `future_income_claimed=false` 明确限定结果范围。比较相等只说明本次输入的算术结果吻合，不证明引擎何时刷新、所有后续调用都不会改值，或未来换属后金额不变。比较不等时保留 `false`，不会用缓存覆盖重算结果。

该重算只覆盖网络流动之前的省份成员输入，对比对象是当前节点总额缓存。第212批已在发现信息中补充这一范围，以及静态识别的月变更／初始化刷新路径；尚未验证输入与缓存属于同一更新阶段。详见[刷新条件与证据](../../实现研究/贸易与省份/节点贸易金额刷新条件.md)。

## 读取方式与可知范围

读取器复用既有节点分配结果中的加载定义、成员向量、规范省份数组及完整国家扫描，不重新列举节点图，也不追加全省份或全国家扫描。它重新核对节点键、中心、成员向量、每个规范记录的标识和节点引用。中心省份必须已被法国发现，才读取节点金额缓存。

每个成员都先读取法国的发现位。未发现的成员只保留结构标识和未知状态，不读取其所有者、商品或数值修正。已发现成员使用省份实际所有者的完整引用，按保留国家表重新核对规范国家，并验证国家视图准入及法国 NPC 身份。控制国不能替代所有者，物理玩家也不决定观察国。

省份公式复用[省份贸易金额输入接口](省份贸易金额输入接口.md)。六项描述符在一遍汇总中各核对一次；同一完整所有者引用的准入与两项修正、同一商品索引的价格也各读取一次。共享仅限本次遍历，不跨请求缓存，不将复用数据伪造成新的内存读取。

描述符处理器必须为空，所有者缓存只支持状态0或2。所有者缺失、准入被拒、商品或修正无法解释时，该成员保持未知。实际读取失败、输入字节变化、规范绑定或观察国角色失效会撤回组合观察。稳定的受限数值路径只使相应新注释未知，既有有效字段继续交付。

叶子每遍最多128 KiB、4096次读取，整个父采集仍受原512 KiB预算限制。所有实际读取字节再次读取比较，父级再做两遍核对；公开交付必须通过原有身份、代码守卫、严格逐读回放及句柄关闭检查。它不调用游戏原生计算函数，不保存或推进游戏。

## 原生依据与限制

适用目标为 EU4 1.37.4，EXE SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。这里列出的地址均为 RVA，运行时按实际模块基址定位。

复用的有界证据显示，`[0xb51370,0xb51fc5)` 遍历加载成员，在 `0xb516d0` 将省份金额 getter 的结果加到节点 `+0xb0`，随后在 `0xb51753` 统一换算。所有者／控制者的部分检查只决定力量分配，不能据此跳过金额计算。省份产出与金额公式已有第210批 REA 证据；本批的后续调用核对属于普通有界静态证据。

在本次保留范围中，`0xb52bd3` 和 `0xb584fa` 是节点金额读取，`0xb52837` 的 `+0xb0` 写入属于国家行，不能混作节点写入。未检查的被调函数仍可能修改整个节点，其影响与刷新时点保持未确定。新 profile 继承原有70项守卫，包括3157字节的节点累加函数，旧 profile 保留。

完整网络收入、真实领土变化、节点份额分母及其它原计划缺项继续推进。本接口不把当前成员汇总当成整个开发计划已经完成。
