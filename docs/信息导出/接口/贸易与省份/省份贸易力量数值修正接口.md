# 省份贸易力量的数值修正接口

第202批在贸易候选省份页接入三项当前数值输入，供后续贸易收益分析使用。查询仍用 `T06.targets`；当前贸易力量和这三项输入由同一个省份采集读取，沿用法国非玩家视角的准入、发现、日期、身份和双遍检查。没有新增独立的G02公开字段。

```json
{"topic":"T06","object":{"type":"trade_node","node_id":"champagne"},"fields":["targets"],"parameters":{"target_page":{"offset":1,"limit":1}}}
```

以已有live会话启动服务并启用 `--static-game-data` 后，结果路径为：

`fields.targets.value.rows[].current_trade_power.numeric_modifiers`

| 属性 | 单位 | 当前含义 |
| --- | --- | --- |
| `province_trade_power_value` | `trade_power`，scale=1000 | 省份 `+0x998` 数值修正对象的索引15 |
| `province_trade_power_modifier` | `ratio`，scale=1000 | 同一对象的索引16比例项 |
| `province_trade_power_further_modifier` | `ratio`，scale=1000 | 省份 `+0x2438` 对象的索引16进一步比例项 |

每项分别给出 `status`、`value`、`basis` 和完整性标记。已知值保留 `{raw, scale, unit}`，例如 `raw=250, scale=1000, unit=ratio` 表示0.25（25%的修正项），不是250点贸易力量。零和负数保留原值；无法验证的项返回未知，不补零。内部的指针、读取轨迹和对象地址不进入公开投影。

这些是计算输入，尚未组成取得省份后的完整收益。控制国和观察国的当前比例项已在第203批接入，见[国家修正接口](省份贸易力量国家修正接口.md)；节点国家分配、换属后的省份修正重建等仍未补齐。`acquisition_delta_evaluated=false`、`cache_refresh_timing_verified=false` 和候选页 `expected_benefit=unknown` 保持；现有条件收入模型也不会自动把当前省份值当作取得后的竞争力增量。

## 何时能够读取

本项仅支持EU4 1.37.4 B23，EXE SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。没有继承到1.37.5。

原生数值getter先读修正容器，还可能调用按索引配置的处理器。新读取器只在以下条件都成立时交付该项：

1. 规范省份身份、法国非玩家角色、视图准入和发现检查通过；
2. 原生描述符中的键精确匹配 `province_trade_power_value` 或 `province_trade_power_modifier`；
3. 该索引的处理器指针为NULL，且读取后的管理器、键头和处理器复核未发生变化；
4. 容器边界、数值类型、单位、两遍稳定性及原始读数严格回放均通过。

处理器非空时不会执行游戏函数，也不会把原始容器值冒充处理后的结果。原始数字读取复用 `modifier_storage.read_raw_modifier_object` 的稠密／稀疏遍历和边界检查，没有复制另一份遍历实现。原国家接口 `read_raw_modifier` 保留调用方式、读取标签和结果合同。

新省份profile为 `province-trade-power-inputs-memory-1374-v1.json`，SHA-256为 `5165cee39a6303bf0b0ad802ebc775f460f4b352a1530f59fe209405d665f170`。在原省份读取守卫上增加3段、2699字节的数值getter、计算器和缓存写入代码守卫，父级额度仍为512 KiB。原省份profile保留。国家共用代码的来源哈希变化另由 diplomats total v3、opinion decay v5 profile接续，原profile保留为历史；其原生布局、代码守卫和读取算法没有随这次Python共用核心提取而改变。
