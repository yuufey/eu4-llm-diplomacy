# 宗教组显示名与宗教定义复用

`S02.religion_group` 已支持读取国家当前主宗教所属组的显示名。逻辑观察方是非玩家法国，物理玩家仍为葡萄牙；当前法国、英国都返回“基督教”。字段保留 `partial=true`、`complete=false`：本次没有把显示名当作宗教组配置 key，也没有宣称读到了完整宗教规则或 tooltip。

## 查询与订阅

```json
{
  "topic": "S02",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["religion_group"],
  "parameters": {}
}
```

字段值示例：

```json
{
  "status": "known",
  "unit": "native_display_name",
  "scale": 1,
  "period": "current",
  "partial": true,
  "complete": false,
  "basis": "native_primary_religion_group_display_name",
  "value_origin": "copied_native_religion_group_name_string32",
  "value": {
    "religion_group_name": {
      "text": "基督教",
      "raw_hex": "10fa57106377105965",
      "encoding": "eu4_escape"
    }
  }
}
```

可以查询、加入手动报告和周期订阅，实际验证过 2 秒、5 秒周期。取消一个订阅后另一个保持活动，最终两个订阅均已取消，服务退出码为 0，读取线程已终止。法国和英国的四种交付结果分别与首次私有采集相同。当前字段不声明变化订阅；现有 `faith` 与新字段可由 Composite 组合，混合查询、报告、周期及取消后的停止读取另有离线服务测试。

国家绑定、逻辑观察方的非玩家身份和国家视图准入由原有只读 owner 核对；准入未知或不可见时不发布名称。公开值不含指针或私有读取日志。主线程原子性、缓存更新时间和实际 UI 显示仍未证明。

## 直接复用 CWTools

新增 `bridge.information.religion_definitions.ReligionDefinitionIndex`，使用已固定版本的 CWTools 解析器和现有游戏/MOD 文件覆盖解析器，处理有效的 `common/religions/*.txt`。宗教定义是顶层宗教组块的直接子块；`religious_schools`、`flag_emblem_index_range` 按固定 CWT 规则排除。

```python
from bridge.information.religion_definitions import ReligionDefinitionIndex

index = ReligionDefinitionIndex(game_root, user_data)
index.lookup("catholic")       # 已知定义：religion_group_key == "christian"
index.lookup_group("christian")
index.context()                # 配置、定义文件、解析器与 CWT 的来源摘要
```

实际配置目录通过 CWTools 解析了 28 个宗教、7 个宗教组。当前有效文件为 `common/religions/00_religion.txt`，53,266 字节，SHA-256 为 `609e2d235f3441c64b895d9faf3927bbf1399149cffa955137ab2d070b9645a6`。天主教、东正教等归入 `christian`，逊尼派、什叶派归入 `muslim`。不存在的 key 保持未知，不通过翻译名补猜。

索引支持同名文件的 MOD 覆盖、`replace_path` 和输入变更检查。重复宗教或重复宗教组造成歧义时返回未知；文件、解析器或配置变化使旧实例失效，须重建。它解析声明，不执行 trigger/effect，也不证明国家此刻使用哪个宗教。当前原生显示名接口没有用这个索引反查配置身份；后续取得准确宗教 key 后，可直接复用 `lookup()` 的映射。

CWT 固定提交 `a85622d368bbb7afca938ed70fdd5eda44aec769`；`common/religions_and_related.cwt` 为 22,541 字节，SHA-256 `bc7e80059f6b71acd12b8af9d8bf2d98850b891073326d845a1d62aa8760f1af`。上游 MIT 许可保存在 `third_party/cwtools-eu4-config/LICENSE`。

## 原生依据与边界

固定 EXE SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。下述地址均为 RVA；运行时 VA 必须加本次模块基址。

- 接受的缓存 REA：`c0b1d0`，Evidence `ev_7e7995c0c3e1218c7967630686c8f2c03bbde0c8b824ced5be18012ab44a88f6`。国家分支读取 `country+F30` 的主宗教，再以 `religion+D8` 的组对象进行比较。
- 普通 PE 证据：`[c0b260,c0b510)` 的组说明函数使用组对象 `+38` 的 String32 名称输入；ROM 表关联该说明函数与上述谓词。普通汇编不冒充接受的 REA。
