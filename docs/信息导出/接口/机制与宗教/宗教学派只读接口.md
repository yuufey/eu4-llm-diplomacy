# 宗教学派只读接口

`S02.schools` 读取准入国家当前学派的原始脚本 key，并附上该学派的有效游戏/MOD 配置声明。支持直接查询、保存报告和周期订阅。逻辑观察方为非玩家法国 `FRA`，目标国家可以另行指定；不会为读取目标国家而切换玩家国家。

```json
{
  "topic": "S02",
  "object": {"type": "country", "country": "TUR"},
  "fields": ["schools"],
  "parameters": {}
}
```

字段单位为 `religious_school_summary`、`scale=1`，覆盖状态为 `partial`。当前返回内容如下：

| 成员 | 含义 |
| --- | --- |
| `religion_key`、`religion_group_key` | 当前主宗教和宗教组的原生脚本 key |
| `has_school` | 游戏当前学派对象是否为有效学派 |
| `current_school` | 有效对象返回 `status=known` 和 `key`；原生空学派对象返回 `status=none`、`reason=NATIVE_SCHOOL_SENTINEL` |
| `configured_rules` | 当前学派对应的有效配置 AST，含来源校验值；没有当前学派时为 `not_applicable` |
| `uses_schools` | 已证明的原生分支返回 `status=known` 和布尔 `value`；依赖线程状态的分支仍为 `unknown` |
| `invited_scholars` | 观察方本国的学者修正及邀请冷却；外国目标的可知范围未核实，返回 `unknown` |
| `relations` | 当前学派对同组其他已加载学派的原生关系值；无当前学派时为 `not_applicable` |

空学派对象只说明该国家没有当前有效学派，不能据此认定学派机制未启用。机制启用状态单独读取：宗教组选择的默认学派定义对象原生返回 `false`；真实定义对象在两个全局标志满足原生条件时，以已加载学派数量是否非零判定。其他标志组合需要读取线程状态，当前返回 `RELIGIOUS_SCHOOLS_THREAD_GATE_UNRESOLVED`，不会调用线程初始化函数或假定它通过。未知对象类型或读取失败只使机制启用组件未知，不撤回独立验证的当前学派身份。

第172批当前会话的实测为：法国 `uses_schools={"status":"known","value":false}`，奥斯曼为 `true`。该结果来自当前内存的定义对象、全局标志和数量，不是根据宗教名称、学派是否非空或磁盘配置推测。学派数量的软件读取上限为64；超限保持未知。

`configured_rules` 复用 `ReligiousSchoolDefinitionIndex`、现有 CWTools 解析器和游戏/MOD 文件覆盖解析器。原生 key 与配置 key 必须精确对应，不能通过本地化名称或图标猜测。配置声明只说明磁盘上当前有效的规则；`conditions_evaluated`、`effects_executed`、`active_effects_proven` 均为 `false`。例如，邀请条件中存在某项修正判断，不代表该修正当前有效，也不代表已经邀请学者。配置不可用时只撤回 `configured_rules`，已经验证的原生身份仍可返回。

第175批补上组件级可知范围限制：只有查询目标等于已验证的逻辑观察方时，才公开 `invited_scholars`。当前这组适配器支持 `FRA` 观察方；查询外国目标时，该组件固定返回 `{"status":"unknown","reason":"SCHOLAR_VISIBILITY_UNVERIFIED"}`，不返回学者实例、冷却存在状态、原始日期或标志。学校身份、已验证的机制状态和关系值继续按原来的国家准入条件返回。这里是可知范围尚未证明，不宣称游戏明确禁止观察方知道所有外国学者信息。

第173批增加的底层读取复用国家修正实例列表，并读取原生条件同时检查的次级定义列表；只有两份列表均完整、稳定且以空指针终止时，才能确认修正成员关系。数据真实与观察方可知是不同条件。原有 N08 公开查询限于观察方本国；通用国家视图准入本身不能证明某一项外国修正、隐藏冷却或原始标志可公开。第173/174批的外国实例读取保留为数据来源研究证据，当前公开结果按第175批限制投影。

公开投影版本升为2。外国结果不再携带包含未公开修正的完整捕获摘要，而以 `public_projection_sha256` 标识实际公开的值；隐藏组件发生变化时，不改变该公开投影的内容或摘要。本国结果保留原有捕获证据摘要。

配置映射由 `ReligiousScholarDefinitionIndex.mapping()` 从所有有效宗教组的学派声明中取得。每个学校要求直接声明 `invite_scholar_modifier_display`，并在 `on_invite_scholar` 中存在同 key 的 `add_country_modifier` 声明。它不执行其中的条件或效果，也不硬编码七种原版学派；当前有效原版配置解析出七个对应项。歧义、重复、畸形声明、超限或配置变化会使映射未知。

`invited_scholars` 已知时包含以下内容：

| 成员 | 含义 |
| --- | --- |
| `scholars` | 每项包含宗教组、学校和修正 key，`present` 说明该 key 是否出现在两份原生列表中，`instances` 保留对应条目 |
| `invitation_cooldown` | 单独报告 `has_invited_scholar_recently` 的存在状态；它不代表某一所学校，也不等于已有学者修正 |
| `invitation_history` | 固定为未知，不能由修正存在推断由哪个国家邀请、何时执行邀请或命令是否成功 |
| `date_semantics` | `copied_raw_dates_expiry_and_timer_unproven`：只复制日期原值，尚未证明统一的到期及移除行为 |

实例来源为 `direct` 时复制 `start_date_raw`、`date_raw` 和四个原始标志字节；标志保留0–255整数，不擅自转换成布尔值。来源为 `secondary` 时只有定义成员关系，日期和标志为 `null`，不会补造实例数据。`present` 按完整列表中的 key 精确匹配判定，不根据日期、奖励数值或图标推测。`present=false` 仅表示当前完整列表中没有该修正，不是邀请历史证明。

原生列表读取或一致性检查失败时，`invited_scholars` 未知，其他已验证的学派身份仍可返回。配置映射不可用时，该组件返回 `RELIGIOUS_SCHOLAR_MAPPING_UNAVAILABLE`；不会把配置失败解释成“没有受邀学者”。修正列表和学派父身份分别前后复读，父身份变化会撤回整个字段。

第173批底层实采中，奥斯曼的当前学派为 `hanafi_school`，修正列表命中 `hanbali_scholar_modifier`，邀请冷却也存在。这个历史样本证明了读取与映射，并没有证明 `FRA` 观察方能获知这些外国修正；第175批起公开查询会将该组件标为可知范围未核实。法国本国的七种学者修正和邀请冷却均为 `false`。当前学派与学者修正分别读取，不能互相替代。两国次级列表当时均为空；次级非空、长 key 和失败路径另有字节级测试。

第174批增加 `relations`。`source_school_key` 是目标国家的当前学派，`religion_group_key` 必须与父身份一致；`entries` 按已加载学派数组给出同组其他学派，每项有目标 `school_key`、`status`、有符号整数 `value` 和对应四字节 `raw_hex`。自身不作为目标返回。原生查询把两校作为无序对匹配，因此 `symmetric=true`；关系行重复时取原生数组中的首次匹配。找不到某一对时，该项返回 `SCHOOL_RELATION_NOT_FOUND`，不会把原生的负索引结果当作0，也不会读取数组前方。

数值直接来自运行时关系缓存，不从配置或修正奖励推算。原生界面回调按 `value+1` 分组，标签构造器分别使用 `SCHOOL_HATE`（-1）、`SCHOOL_AMBIVALENT`（0）和 `SCHOOL_LIKE`（1）。这些键有静态代码证据，完整本地化和实际tooltip渲染仍未验证。其他有符号32位数值照常保留，不按配置的 -1..1 范围钳制，也不为它们补造标签。

本批实机中，奥斯曼 `hanafi_school` 对 `zaidi_school` 的值为 -1，对 `hanbali_school`、`maliki_school`、`shafii_school`、`ismaili_school`、`jafari_school` 均为0。法国没有当前学派，关系组件返回 `NO_CURRENT_RELIGIOUS_SCHOOL`；不会据此构造“中立”关系。关系图读取或稳定性检查失败只撤回关系组件，父身份变化则撤回整个字段。读取上限为64个学派、256以内的宗教组ID、2048条关系行，并受共享读取预算约束。

原生读取基于固定 1.37.4 B23 EXE。国家 `+0x28b8` 指向当前学派对象，真实学派的 `+0x150` 保存原始 key，`+0x18` 是另存的本地化名称。宗教组 `+0xa0` 指向学派定义容器；读取时核对容器与学派的所属宗教组、学派序号和对应数组成员。所有 RVA 都需要加上当前模块基址后才是运行时 VA；公开结果不包含进程地址。

读取复用现有会话、进程身份、非玩家观察角色、可见性准入和两遍采集检查。学派采集结束前再次读取所有依赖，包括主宗教和宗教组身份，拒绝同一日期内改宗造成的数据拼接。机制状态扩展保留第171批身份读取器及profile，另加有界读取和守卫；机制依赖变化只撤回 `uses_schools`，父身份依赖变化撤回整个字段。它仍不是游戏主线程的原子快照，也不保证采集结束之后的实时新鲜度。

本接口只执行进程只读操作，不调用游戏函数、发送外交命令或推进日期。原生语义、实际采集、独立原始字节核对及 MCP 交付的验收记录分别保存在 `work/runtime/information-religious-schools-20261104-171-001/`、`work/runtime/information-religious-schools-state-20261105-172-001/`、`work/runtime/information-religious-scholars-20261105-173-001/` 和 `work/runtime/information-school-relations-20261105-174-001/`；批次交接和 `summary.json` 记录各项实际结果。

第175批的范围审计和投影修复记录保存在 `work/runtime/information-school-visibility-20261105-175-001/`。原信息目录没有明确要求 S02 提供邀请者身份或邀请历史；保留的 `invitation_history=unknown` 是附加提示，后续按原目录的必要信息安排开发。
