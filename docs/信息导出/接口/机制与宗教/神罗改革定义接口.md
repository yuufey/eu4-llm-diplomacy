# 神罗改革定义接口

第118批起，默认实时 `reforms` 是当前记录中的通过标识；本页的 `--empire-game-data` 显式选择静态声明来源，两者不同时拥有该字段。当前记录的时间、单位和验证范围见[当前改革记录接口](神罗当前改革记录接口.md)。

本接口读取当前安装和已启用模组中的改革定义，提供 S01 的 `reforms` 字段。返回值是声明列表，`period=static_definition`、`unit=imperial_reform_definition`、`complete=false`。它不表示当前已通过改革，也不判断条件真假、执行效果或确认引擎当前载入的定义集合。实时通过记录的私有研究仍见[改革采集研究](../../实现研究/机制与宗教/神罗改革实时采集研究.md)。

## 启用与查询

启动时增加 `--empire-game-data`。路径参数复用已有静态数据配置；省略路径时使用本机配置。

```powershell
python tools/serve_information.py --empire-game-data --observer FRA --database work/runtime/reform-rules/information.sqlite3
```

需要绑定当前游戏并使用周期任务时，再指定经过核对的 `--operator-session <installation.json>`；不能沿用已结束进程的安装身份。`--static-game-root` 和 `--static-user-data` 可显式选择配置。`--empire-rules-parser-manifest` 是操作者提供的 CWTools 清单，必须与 `--empire-game-data` 一起使用；它与历史存档所用的 `--empire-parser-manifest` 用途不同。

静态改革入口不能与 `--empire-save`、`--province-interest-save`、`--mission-save` 或 `--recorded-manifest` 组合。这些冲突在访问相应存档前拒绝。未启用新开关时，原有实时皇帝/选侯来源和历史神罗来源保持各自的行为。

通过 `information_query` 查询：

```json
{
  "queries": [{
    "topic": "S01",
    "object": {"type": "country", "country": "FRA"},
    "fields": ["reforms"],
    "parameters": {}
  }]
}
```

`country` 和 `session` 都选择全局神罗规则，不按国家过滤定义，也不表示该国存在或属于帝国。未绑定游戏时可以读取静态定义；有游戏版本时必须与该定义索引一致。当前 Source 仅声明支持已验证的 1.37.4。定义可用于报告，并通过通用服务建立周期导出；周期订阅仍须满足服务的会话绑定要求，不会自行推进游戏日期。

每条声明含 `reform_id`、明确的 `empire=hre`、相对文件名、源行号及 `declarations`。后者保留有序脚本节点的名称、运算符、值和嵌套结构；重复条件与未知命令保留原结构，不在此执行。结果另有 `conditions_evaluated=false`、`effects_applied=false`、`current_passed_reforms_observed=false` 和 `loaded_definition_set_verified=false`。

## 来源与变化处理

`ImperialReformDefinitionIndex` 复用已有模组解析器处理覆盖顺序与 `replace_path`，再由固定 CWTools 解析全部有效 `common/imperial_reforms/*.txt`。只按明确的 `empire` 声明区分神罗与中国改革，不按文件名猜测；缺失、未知或歧义的帝国声明留在索引 gaps 中，不混入神罗列表。

索引固定 CWTools EU4 config 提交 `a85622d368bbb7afca938ed70fdd5eda44aec769` 的 `common/imperial_reforms.cwt`，SHA-256 为 `1119acad950d86c6d2f1e7dc1799a0f5f52d4d4636128c5d5e64b369abc883dd`。这提供类型和字段合同，不代表已完成整个 CWT schema 校验。目录最多 4096 个成员、512 个有效文件，单文件最多 4 MiB，总输入最多 16 MiB；Source 另限制记录、节点、深度和输出大小。

配置、模组描述、目录成员、有效文件、解析器或 CWT 变化后，旧索引返回不可用，需构造新实例。查询还会核对前后定义身份和游戏上下文，变化时撤回本次定义结果。异常不把私有指针或任意错误文本传给调用者。快照不是原子读取，也不证明静态配置与当前引擎载入集合完全相同。
