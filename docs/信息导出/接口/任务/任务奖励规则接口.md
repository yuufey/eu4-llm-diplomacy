# 任务奖励规则的分类查询

M04 当前提供五个部分支持的分类字段。`claims`、`casus_belli`、`trade_modifiers` 保留原有的字面奖励命令分类语义；`duration` 投影命令声明的期限数值与单位，`unlocks` 投影字面解锁及任务变更请求。它们都从当前任务定义中提取规则，不表示当前国家已经获得奖励，也不表示条件已满足。

```json
{
  "request_id": "mission-reward-rules-001",
  "queries": [{
    "topic": "M04",
    "object": {"type": "country", "country": "FRA"},
    "fields": ["claims", "casus_belli", "trade_modifiers", "duration", "unlocks"]
  }]
}
```

可用 `parameters.task_id` 或 `parameters.root_id` 缩小范围。任务必须属于捕获的根；原生来源若提供实际加载子任务，则还按实际成员筛选。存档来源只确认保存的根，再连接当前文件中的任务定义；它没有证明保存时加载的子任务或过去使用的定义与当前文件一致。

| 字段 | 当前索引的命令 | 仍未求值的内容 |
| --- | --- | --- |
| `claims` | `add_claim`、`add_permanent_claim` | 实际省份、作用域、条件与已获得状态 |
| `casus_belli` | `add_casus_belli` | 实际对象、类型适用性、当前有效性与到期时间 |
| `trade_modifiers` | `add_trade_modifier` | 实际对象、叠加规则、当前生效情况与到期时间 |
| `duration` | 命令专属 allowlist 中带期限参数的效果；另单列 `add_permanent_claim` 声明 | 仅记录静态命令数值与有依据的单位；不计算执行结果或实际到期日 |
| `unlocks` | 显式解锁、完成任务及重建任务树的字面请求 | 条件、实际作用域、重建后的任务与实际解锁结果 |

`unlocks` 已提供部分静态声明查询，实际解锁结果仍未知。原有 `rewards` 继续返回完整原始 `effect` AST，分类字段不替代它。启用方式仍为 `--mission-game-data`；未启用任务来源时，目录保留 planned。

## `unlocks`：解锁与任务变更的字面声明

该字段复用同一CWTools AST及已加载任务成员，不执行奖励。当前命令范围为 `unlock_cult`、`swap_non_generic_missions`、`complete_mission`，以及实际法国脚本出现但缺少固定CWT规则的 `unlock_government_reform`。

| 当前法国任务 | 脚本声明 | 结果边界 |
| --- | --- | --- |
| `fra_ducal_lands_avignon` | `swap_non_generic_missions=yes` | 任务树重建请求；不知道重建后的任务列表 |
| `fra_raise_slave_ships` | 在if/PRO作用域中 `complete_mission=emp_pro_toulon` | 保留条件与PRO作用域；不表示该任务已完成或后续任务已解锁 |
| `fra_movement_centralization` | hidden_effect中 `unlock_government_reform={government_reform=absolutist_france_reform}` | 仅保留语法标识；固定CWT无此命令规则，schema验证未知 |

当前61个任务中共三条声明，没有直接 `unlock_cult`。字段已知表示读到了这份字面声明清单；`evaluated=false`、`applied=unknown`、`actual_unlocks=unknown`、`complete=false`。已识别的普通字符串是 `known_literal`，不表示实际作用域对象已解析；ROOT、PREV、event_target、变量等动态引用保持unknown。政府改革参数只标 `syntax_only`，不推断未验证的引擎语义。

仅保留命中任务或AST未知任务；无命中的合法任务单独计数。每条声明保留来源SHA、行号、路径、原始节点及其引用的条件上下文；不携带无关任务的全部条件表。当前模组文件含保留的C1字节，来源编码标为structural_only，本字段只使用结构与标识，不解释本地化正文。输出上限512KiB；缺失AST、规则文件变更和预算超限不能冒充已知空集合。普通旗标和提示文字不自动解释为解锁。

第131批当前151项定向全过。实机查询与任务筛选已取得声明；报告和独立2秒/5秒周期与direct一致，取消short保留long，POR在字段级拒绝。首轮检查器提前结束后，只补做未执行的报告/周期；后续命令集合、路径基准差异仅离线修正，原失败及两份collector源码保留。验收为两阶段收集加保存结果审计，不称一次全绿。原件 `work/runtime/information-mission-unlocks-20261103-131-001/summary.json`；完整回归仍126，不覆盖本批。

## `duration`：命令特定的期限项

`duration` 读取捕获任务中直接写出的效果命令及其参数，并保留每条规则的任务 ID、来源文件、行号、AST 路径和条件上下文。它只投影固定 CWT 规则明确支持的数值和单位；不会把不同命令的参数统一换算为天数，也不会推断某条效果已经执行。

当前固定 CWT 对部分命令给出了单位，对另一些命令只声明参数类型。投影器按命令分别处理：

| 命令参数 | 固定规则中的单位 | 当前投影方式 |
| --- | --- | --- |
| `add_country_modifier.duration`、`add_province_modifier.duration` | 天 | 非负整数可作为带单位的数值项；负数语义未知 |
| `add_casus_belli.months`、`reverse_add_casus_belli.months` | 月 | 保留为月，不转换为天 |
| `add_opinion.years/months`、`reverse_add_opinion.years/months` | 年、月两个独立分量 | 分别保留，不合并或换算 |
| `add_loan.duration` | 月 | 保留为月；不据此计算贷款实际到期日 |
| `add_ruler_modifier.duration`、`add_trade_modifier.duration` 等未注明单位的参数 | 未注明 | 保存原始数值并标为 unknown，不猜单位 |
| `change_price.duration = -1` | 该命令注释明确表示无限 | 仅对 `change_price` 识别这个命令专属哨兵 |

`-1` 不会跨命令解释。固定规则只为 `change_price` 声明 `-1` 表示无限；例如修正器命令中的 `duration = -1` 仍为 unknown。`add_permanent_claim` 单独记录为永久宣称声明，不形成数值期限项或到期日期。`add_permanent_province_modifier` 的“永久”说明的是省份更换所有者后保留修正器，不等于期限无限。

字段 envelope 使用 `information.mission_reward_duration.v1`。字段状态 known 表示至少有一项带 CWT 单位的非负数值，或一个仅对此命令有效的已知哨兵；其它项仍可 unknown。`value.complete=false`、`evaluated=false`、`applied="unknown"`、`start_time="unknown"`、`expiry_time="unknown"`、`scope_targets_resolved=false`。没有期限匹配不会返回已知空集。明确的 `add_permanent_claim` 声明另由 `known_permanent_claim_declaration_count` 统计，不使数值期限变为 known。

## 结果如何阅读

原有 `claims`、`casus_belli`、`trade_modifiers` 三个字段的 `value.semantics` 为 `declared_literal_effect_rules`。新增 `duration` 字段的语义为 `declared_command_specific_effect_time_terms`。四个字段均不执行效果，且 `evaluated=false`、`applied="unknown"`、`scope_targets_resolved=false`、`complete=false`；规则字段也可能带 `scripted_effects_expanded=false`。公共字段状态为 known 只表示取得了相应静态规则或期限项，不表示获得了完整奖励事实。

`value.rules` 按任务分组；每条规则保留命令、原始节点、AST 路径、父作用域和文件 SHA/行号。每任务的 `context_table` 保存控制结构和原始条件，规则通过 `context_refs` 引用。`if`、`else_if`、`else`、随机结构与未知包装作用域保留位置和顺序，条件内容不执行；调用方也不能据一条字面命令自行认为分支已生效。

`limit`、`trigger`、`potential`、`allow` 等条件子树中的同名键不会计入奖励。未展开脚本效果；未知包装中的字面出现会保留 unresolved 上下文。已验证 AST 没有匹配命令时，`literal_inventory="empty"` 只表示没有直接字面匹配，不能解释为没有间接奖励或没有已有宣称。

解析畸形、来源变化或超过预算时，缺项和原因单独保留；已经取得的其他任务或字段仍可返回。字段的部分成功不提升整体完整性。

## 来源与验证边界

当前安装及启用模组决定静态定义栈。接口在读取前后核对定义状态和指纹，变化时撤回规则字段；已确认的任务状态不因此改写。当前代码为 [mission_reward_rules.py](../../../../bridge/information/mission_reward_rules.py)、[mission_reward_duration.py](../../../../bridge/information/mission_reward_duration.py) 和 [missions.py](../../../../bridge/information/missions.py)。
