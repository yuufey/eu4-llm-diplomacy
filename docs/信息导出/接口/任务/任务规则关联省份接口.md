# 任务规则关联省份

`G01.task_targets` 把所选任务及其前后依赖任务中的条件规则，与静态地图中的省份成员对应起来。它复用已有 `M05.linked_targets`、M03 规则投影、CWTools 官方解析器和 `StaticMissionScopeIndex`，没有新增原生内存布局或脚本解析器。

查询对象是逻辑观察国。目前实时任务来源支持 EU4 1.37.4 的法国非玩家国家；物理玩家国家不因此切换。启动信息服务时，需要已有的 `--operator-session`、`--observer FRA` 和 `--mission-game-data`。未启用任务游戏数据时，实时核心和宣称来源仍可单独使用，任务目标不因此变成可用字段。

```json
{
  "topic": "G01",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["task_targets"],
  "parameters": {
    "root_id": "french_missions_1",
    "task_id": "fra_burg_succession"
  }
}
```

实时 G01 各字段共用可选的 `root_id`、`task_id` 参数。核心、宣称、永久宣称查询可以继续使用空参数，也会保留合法的任务选择器，供混合查询统一校验。`task_targets` 必须同时给出两项；每项最多 128 个 ASCII 字符，只接受字母、数字和标识符中的 `_ . : -`。省份对象上的任务目标为 `not_applicable`，不为它读取国家任务。

共享参数也接受[结构化自定战略目标](../贸易与省份/自定领土战略目标接口.md)中的 `strategic_targets` 数组。任务与自定目标混合查询时，各来源保留完整查询参数用于统一校验；内部 M05 只接收 `root_id`、`task_id`，不会把自定目标当成游戏任务条件。

每条省份关联保留任务树和任务标识、该任务在依赖链中的角色、M03 字段、原条件规则，以及静态地图成员的来源。`trigger_contexts` 按任务和条件编号去重保存完整条件树，规则中的条件编号可以解引用；条件树冲突或缺失不会被悄悄忽略。前置任务、所选任务、后续任务和后续任务依赖的其他分支分别保留身份，同一省份在不同规则中的出现不会被混成一个无条件目标。

只有通过静态索引核对的字面省份和兼容地图作用域的成员才能产生省份编号。国家标签、`ROOT`、所有者、控制者等动态引用不会被推算成当前省份集合。静态地区的全部成员也不表示该国当前拥有、发现、可以征服或需要征服这些省份。规则的逻辑关系和原条件仍需保留；后续消费者不能把所有关联取并集后当成任务完成要求。

字段为 `partial`，结果始终保留以下边界：

- `runtime_conditions_evaluated=false`：没有判断当前条件是否满足。
- `full_target_set_resolved=false`：没有取得完整的运行时目标集合。
- 实际活动目标、可见性与条件满足状态仍未知。
- 当前磁盘定义与游戏已加载的定义内容尚未证明完全相同；已核对的是任务身份及本次读取前后的定义状态。

未取得有效静态省份关联、任务身份未核对或来源暂不可用时，返回对应未知或不可用状态；不会把它们当成已知空目标集合。部分规则能够关联省份时，仍保留其他规则和动态作用域的缺项。

主动查询、报告和周期订阅共用同一个投影。G01 任务读取会进入已有任务规则采集范围，一次读取复用一份任务状态，不额外读取条件进度；不跨请求缓存。当前仅声明 `query` 和 `periodic`，不把周期采样当作原生任务变化事件。

历史存档模式继续使用原有参数与来源，没有接入这项实时任务关联。完整目标求值、可见性、实际完成状态、战略可行性及自定战略目标仍按原计划继续开发。

本批取得法国 `french_missions_1/fra_burg_succession` 的实时只读结果：依赖链 11 个任务，14 条具备静态省份成员的规则关联，22 条未决引用，11 份完整条件树。14 条关联包含 7 条字面省份、6 条 area 和 1 条 region 规则；成员去重后涉及 66 个省份，这只是静态成员并集。验收保存同一次读取的 M05 输入，逐项核对任务角色、规则、条件树和省份成员，没有另行重读 M05 作为对照。

真实 stdio MCP 的主动查询、报告及 2 秒／5 秒周期结果一致，取消短订阅后长订阅仍运行，最后全部订阅取消，服务与读取线程退出。94 个唯一相关测试用例有通过记录，首轮 3 个集成 fixture 绑定错误的失败 XML 保留；修正后只补验失败用例，并重验其间有改动的投影器。完整测试集尚未重验，不能据此称全套通过。游戏仍为物理 POR、逻辑 FRA，1456.8.30 暂停，本批没有推进时间或执行外交行动。

输入与输出有界：最多 4096 个任务节点和规则关联，整体输出最多 4 MiB；超限返回未知。没有新增原生布局、REA 查询、DLL、游戏操作或真实存档研究读取。
