# 补贴到期事件接口

## H02查询

`H02.subsidy_expiry` 读取共同事件账本中已经采集的补贴自然到期记录。合同双方包含FRA，记录说明付款方、收款方、月额、合同起止日期及实际移除日期。

```json
{
  "topic": "H02",
  "object": {"type": "session"},
  "fields": ["subsidy_expiry"],
  "parameters": {"limit": 50}
}
```

`country` 按合同成员筛选，`country_pair` 按两国成员筛选。国家对选择器的顺序不改变合同支付方向，方向由每条记录的 `payer` 和 `recipient` 表示。

```json
{
  "topic": "H02",
  "object": {"type": "country_pair", "actor": "FRA", "recipient": "SAV"},
  "fields": ["subsidy_expiry"],
  "parameters": {"event_type": "subsidy_expired", "limit": 20}
}
```

字段值是最近采集记录优先的列表。每条业务记录包含以下字段。

| 字段 | 含义 |
| --- | --- |
| `event_id` | 共同原生事件的去重身份 |
| `event_type` | `subsidy_expired` |
| `payer` | 付款国 |
| `recipient` | 收款国 |
| `monthly_amount` | 合同月额，以ducats为单位，原生固定点比例1000 |
| `start_date` | 合同开始日 |
| `end_date` | 原生合同截止日 |
| `event_date` | 原生到期分支完成移除的实际帧日期 |

完整视图保留月额的 `value`、`raw`、`scale=1000`、`period="month"`，日期使用 `game_date_raw` 包装。默认简洁视图显示月额数值和可读日期。

`limit` 默认50，范围1至1000。字段包装器中的 `next_cursor` 指向下一页。国家筛选应用于已读取的事件页，因此筛后空列表仍可带有下一页游标。`complete` 和 `gaps` 沿用共同事件账本的采集覆盖信息。

显式 `request_id` 或 `case` 保留既有H02关联日志入口。事件初次投影和回放分别委托该旧来源的 `read_event` 和 `replay_event`。

## 事件与采集合同

公开事件类型是 `subsidy_expired`。订阅可以使用 `recipients` 过滤收款方。自动到期记录没有执行行动的actor，带 `actors` 的过滤器返回 `unsupported_event_filter`。

```json
{
  "types": ["subsidy_expired"],
  "recipients": ["FRA"]
}
```

Python准入要求B23 EXE身份、ACK整数版本62、63或64、顶层 `native_subsidy_expiry_observation=true` 和整数 `native_subsidy_expiry_wire=1`。复制到 `caps` 数组中的名称不授予该能力。目录中的 `native_source_available` 表示当前安装是否通过准入。

原生wire1包含以下12个键。

```json
{
  "event": "native_subsidy_expired",
  "session_id": "current-session",
  "sequence": 1,
  "date_raw": 56692920,
  "payer_ref": "0x100007a00415246",
  "recipient_ref": "0x100008100564153",
  "observer_ref": "0x100007a00415246",
  "start_date_raw": 56684136,
  "end_date_raw": 56692896,
  "monthly_amount_raw": 3750,
  "source": "subsidy_record_expiry_remove_return",
  "wire": 1
}
```

双方引用必须编码有效国家标识和有界国家槽，观察方完整引用必须与其中一侧完全相同并编码FRA。日期及月额遵循有符号32位合同，实际发生日还需非负且严格大于截止日。原生截止日沿既有补贴来源的 `start + years * 8760` 有符号32位结果。

只有已证明到期判定后完成移除的原生生产方可以写出该source。普通取消和宗属变化移除继续沿各自来源处理。

原生生产方观察B23补贴记录移除函数RVA `0xa62df0`。处理外交记录清理循环的返回点 `0x4e1adb`，以及国家关系到期处理的返回点 `0xa6c9dc`。后者按原生日期和关系条件调用记录的移除方法。捕获要求调用前合同有效、当前日期严格大于截止日，正常返回后原记录的移除标记已置位。双方完整国家引用在原生国家表中精确匹配。捕获使用固定64项队列，每帧最多写出32项，排队失败及写入故障沿现有健康与缺口通道交付。

`end_date`表示合同截止日，`event_date`表示原生维护实际完成移除的日期。原生维护的执行时机可能使实际移除晚于合同截止日，历史记录按实际发生日期交付。

构建开关为 `SubsidyExpiryObservation`，继承v61能力组合。新增能力通过安装ACK公布，H02历史适配器由正常服务工厂绑定共同事件账本。

## 接线接口

```python
from bridge.information.subsidy_expiry_history import NativeSubsidyExpiryHistorySource

adapter = NativeSubsidyExpiryHistorySource(base_source, history_reader=history_reader)
```

`history_reader(context, *, event_types, limit=50, cursor=None)` 返回 `events`、`next_cursor`、`complete`、`gaps`。事件为最近优先的标准原生快照，可以直接使用 `InformationService.observed_events`。

`ObserverSession.read_native_subsidy_expiry_events(after_sequence=0, refresh=True)` 复用既有日志游标及有界缓存。primary先推进共同日志，再以 `refresh=False` 取出新记录，使用独立 `subsidy_expiry_sequence` 水位。H02适配器没有第二次原生轮询，其事件投影和回放复用C04的有效快照验证。

采集缺口事件名为 `native_subsidy_expiry_capture_gap`，健康对象键为 `subsidy_expiry_source`，沿用共同collector的丢失和健康检查。
