# 持续承诺与经济支持证据接口

R07提供当前战争中的许诺土地标记，以及逻辑观察国FRA与指定国家之间的备战约定、有效补贴、战争赔款及其期限。适用于当前支持的EU4 1.37.4安装。

## 许诺土地

land_commitments读取当前参战国的promised_land标记，帮助判断议和时需要考虑哪些国家的土地承诺。

- country_pair中actor为FRA，recipient指定受益国，查询其在FRA当前战争中的标记。
- war中actor为FRA，recipient指定对手。沿W01选择具体战争，多场候选时可在object中填写war_id。
- 每条记录包含war_id、beneficiary、side、war_leader与observed_promisor。side为our_side或opposing_side，相对于FRA所在方。war_leader为受益国当前所属阵营的战争领袖，原生土地分配计算使用该国参与当前议和判断。尚无公共战争编号时war_id为null，并提供已知opponents帮助定位。
- observed_promisor为同会话、同公共战争编号和受益国对应的最近一次已观察许诺发送方。实际宣战或召盟命令返回后，原生观察器核对参战身份和土地标记，再记录发送国。接入前缺少记录时该值为null。
- 默认输出只保留业务值。确认没有标记时返回[]，受益国不可见或无法读取时返回null。war结果回显所选war_id。

```json
{
  "queries": [
    {
      "topic": "R07",
      "object": {"type": "war", "actor": "FRA", "recipient": "BUR"},
      "fields": ["land_commitments"]
    }
  ]
}
```

以下为存在标记时的输出示例。

```json
{
  "actor": "FRA",
  "recipient": "BUR",
  "war_id": "war_7c7934a294e6a3ee_00000001",
  "land_commitments": [
    {"war_id": "war_7c7934a294e6a3ee_00000001", "beneficiary": "SAV", "side": "our_side", "war_leader": "FRA", "observed_promisor": "ENG"}
  ]
}
```

示例中当前分配关联国为FRA，已经采集的许诺发送方为ENG。完整视图的land_promise_association保留对应事件编号、观察日期和历史覆盖缺项。尚未接受的参战召唤通过A04查询，已退出战争的参战记录会被排除。发送方事件及关联规则见[土地许诺观察接口](土地许诺观察与关联接口.md)。

## 备战约定

war_commitments提供country_pair双方当前有效的“要求备战”约定。country为备战国，for为请求方，until为截止日期。游戏以截止日大于当前日判断备战状态，因此截止当日该约定已结束。

```json
{
  "actor": "FRA",
  "recipient": "SAV",
  "war_commitments": [
    {"kind": "war_preparation", "country": "SAV", "for": "FRA", "until": "1472.10.18"}
  ]
}
```

以上为存在约定时的示例。当前没有约定时返回[]。备战状态表示国家接受了备战请求，实际召盟与加入战争沿游戏原生规则处理。当前已经参战的国家由W01.participants提供，待回应的参战召唤由A04提供。

## 当前经济支持

economic_support默认返回双方当前有效的补贴和战争赔款合同列表，包含付款国、接收国、开始和结束日期。补贴通过monthly_amount给出名义月额，战争赔款通过income_percent给出每月收入比例。月额单位统一为ducats。当前没有合同、合同已取消或已失效时返回[]，无法确定时返回null。

```json
{
  "queries": [
    {
      "topic": "R07",
      "object": {"type": "country_pair", "actor": "FRA", "recipient": "ENG"},
      "fields": ["economic_support", "war_commitments", "expiry"]
    }
  ]
}
```

以下为存在补贴和赔款时的默认输出示例。

```json
{
  "actor": "FRA",
  "recipient": "ENG",
  "economic_support": [
    {
      "kind": "subsidy",
      "payer": "FRA",
      "recipient": "ENG",
      "monthly_amount": 12.5,
      "start_date": "1471.10.18",
      "end_date": "1473.10.18"
    },
    {
      "kind": "war_reparations",
      "payer": "ENG",
      "recipient": "FRA",
      "income_percent": 10,
      "start_date": "1471.10.18",
      "end_date": "1481.10.18"
    }
  ],
  "war_commitments": [],
  "expiry": [
    {"kind": "subsidy", "payer": "FRA", "recipient": "ENG", "end_date": "1473.10.18"},
    {"kind": "war_reparations", "payer": "ENG", "recipient": "FRA", "end_date": "1481.10.18"}
  ]
}
```

补贴有效状态结合原生取消标志、期限及付款国从属类型规则判断，截止当日仍有效。开始日期、年数和月额沿已登记合同保留，实际历史收付款仍由财政接口提供。其他经济支持种类继续保留未实现状态。

战争赔款结合原生取消标志和期限判断，截止当日即失效。收入比例读取当前游戏运行值，10表示每月收入的10%。比例暂不可读时保留已知合同与期限，income_percent返回null。

完整视图的registered_subsidy_evidence和registered_reparations_evidence保留已登记条款，active_payment_obligations提供当前有效合同。只需业务结果时使用默认视图即可。

source字段需要取得已知组件后才给出实际basis、来源路径、观察游戏日期、会话、国家对范围及组件摘要。整次采集与上游结果摘要在结果provenance中；组件摘要随事实变化，不随采集墙钟时间变化。外层F03已知但补贴组件未知时，R07仍保留该组件的未知原因。

## 期限与订阅

expiry汇总所查国家对当前备战约定、有效补贴及战争赔款的结束日期。备战条目包含kind、country、for及end_date，补贴和赔款条目包含kind、payer、recipient及end_date。各类约定分别按上述截止规则判断。确认三类约定均不存在时返回[]。

economic_support、war_commitments、expiry及source支持country_pair。war对象提供land_commitments。补贴、赔款及经济期限共用一次当前国家对采集，登记记录随同读取。显式查询source时沿原F03来源说明读取。

查询、报告、周期订阅和采样变化检测共用对应字段的读器。变化订阅可选land_commitments、war_commitments、economic_support、expiry，比较已经确认的当前约定。source用于完整来源说明，可通过查询和周期报告读取。

N09纪律来源明细见[特殊外交机制与最终属性接口](特殊外交机制与最终属性接口.md)。历史批次及实际采样结果保存在logs与work/runtime。
