# 双向好感修正实时接口

第187批新增[逐记录年度变化接口](双向好感年度变化接口.md)，第188批新增[计划结束日期接口](双向好感计划到期接口.md)。这两个来源可与本字段在同一次查询中选取。计划日期只投射固定期限记录保存的日期，不表示修正已实际到期或移除。下文对日期、flags 和衰减的说明描述本字段本身，不取代两个独立来源的结果。

第185批接通 `R04.opinion_modifiers` 的实时查询、报告和周期订阅，覆盖仍为 `partial`。它返回所选国家对当前存储的具名修正及数值；综合好感还包含其他计算项，继续由 `R04.opinion` 单独提供。

## 使用方式

默认 live 服务启用此字段，逻辑观察国固定为非玩家 FRA，国家对必须包含 FRA。物理玩家仍可为 POR，不需切换为法国。

```json
{
  "topic": "R04",
  "object": {"type": "country_pair", "actor": "FRA", "recipient": "ENG"},
  "fields": ["opinion", "opinion_modifiers"],
  "parameters": {}
}
```

方向按请求的 actor→recipient 及其反向返回。修正记录包含 `modifier_id`、`current_opinion_raw`、`raw_hex`、精确的三位小数文本 `current_opinion_decimal`；单位为 `opinion_points`，原值 scale=1000。重复 key 可以有多条记录，保持原顺序。实际会话读到：

| 持有国 | 对象国 | 修正 key | 当前存储值 |
| --- | --- | --- | ---: |
| FRA | ENG | discovery_of_evil | -19.200 |
| FRA | ENG | had_war_with_us | -27.912 |
| ENG | FRA | declared_war_on_us | -54.124 |
| ENG | FRA | eng_supported_rebels_during_war_of_the_roses | -44.788 |
| ENG | FRA | had_war_with_us | -28.287 |
| ENG | FRA | aggressive_expansion | -39.574 |
| ENG | FRA | declared_war_on_neighbor | -8.287 |
| ENG | FRA | declared_war_on_enemy | 9.000 |

每个方向独立核对。零值与没有记录不同；未物化容器、超限、重复对象或结构变化返回未知。未知对象类型保留未知记录，其他已知记录仍可返回。每个方向最多256条，当前已分配的记录容器为空且原生 fallback 也为空，才返回已知空列表。

报告与周期订阅沿用已有接口。实际2秒、5秒周期返回同值，取消短周期后长周期继续，最终两个订阅均已取消。配置周期不是延迟保证。本字段尚未开放采样 `change`；只查询 `opinion` 时，原有变化订阅继续工作。

`--opinion-save` 仍是独立的历史快照方式，不因本接口启用而读取或重载存档。

## 可选配置声明

服务启用 `--static-game-data` 后，会按当前运行时读到的真实 key，附加 `definition` 中的磁盘声明。索引直接复用固定 CWTools 解析器和已有 mod 覆盖、`replace_path`、目录及文件指纹检查；当前有效3个文件有1023条声明、1022个唯一 key。跨文件重复 key 保留歧义，缺失、0和非字面值分别表达。

附注只表示当前有效磁盘配置，`loaded_membership_verified=false`、`conditions_evaluated=false`。其中的 `yearly_decay`、`years` 或 `months` 不等于当前生效衰减或到期日。声明不可用或输入变化时，仅撤回声明，已验证的原生数值仍保留。

## 原生依据与限制

固定 EU4 1.37.4，EXE SHA-256 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。静态 image base 为 `0x140000000`；运行时地址使用实际 module base 加 RVA。

- 当前关系容器遍历复用既有 `insult_query_state`：国家 `+0x1510`、对方 slot×`0x48`、manager `+0x308/+0x314` 和24字节内层容器。
- 本版本实际记录的 vtable 为 RVA `0x1ccf388`，serializer slot2 为 `0x9494a0`；两者同时核对，未用旧版本 vtable 或未解释的 `+8` 字段作类型依据。
- 新 accepted REA `ev_1867d8ff5251f5ec8d425cc57f3c70f1311a77ba4edc396521d93066b0a73c2d` 确认 definition `+0x10` 的名称字符串与对象当前值 `+0x20`。263字节代码守卫及实际重定位目标检查均通过。
- 新 accepted REA `ev_f6185f56732dda1aab8adf5597bf5b72eda93ee5c3d369ba134af94e95774a6c` 确认原生综合好感会限制到-200至200，并从其他计算入口取得年度变化汇总；该汇总尚未接入本接口。

本字段的日期、倍率和 flags 只在私有采集中保留原始字段，不对外解释为生效日、到期日或实际衰减。计划结束日期由独立 `R04.end_date` 字段按已验证的固定期限模式投射；非固定期限模式返回 `not_applicable`，不据此判断记录永久有效。完整原生提示中的其他计算因素也尚未覆盖。

沿用逻辑 FRA 的国家选择准入投射和非玩家角色核对，完整 UI caller 链、实际绘制及引擎缓存新鲜度仍有缺口。采集只使用只读句柄、身份/代码守卫、双遍和严格原始读取记录验证，不调用游戏函数。

## 验证与研究记录

正式采集与先前私有类型核对的8条 key/value一致，严格重放通过，篡改投影数值会被拒绝。实际 MCP 正向查询1.281秒、反向1.437秒、混合查询1.985秒、报告2.031秒；报告与双周期同值，源码 pin不变，最终server退出0、reader退出。223个当前相关测试有通过记录，另有22个subtests，完整测试集的继承问题仍保留。

新增来源曾使原综合好感的单字段比较失去日期与来源证明。`CompositeSource` 已修复为：请求只涉及一个有效来源时保留它的原结果；多来源请求仍合并。专属回归和既有比较范围测试均通过。

验收后补强单方向读取失败处理，避免一方向的读取异常撤回另一方向。仅修改错误处理分支，正常读取主体不变；原始实采在当前代码下严格重放通过，没有重做成功采集或MCP交付。

第185批曾通过较小的 JVM 初始堆及代码缓存上限，完成两个小函数查询。较大的 `0x3d32e0` 全函数查询即使过滤返回字段，仍触及1 GB监控上限，未产生新 Evidence，之后没有重试。停止后发现577,765,376字节暂存文件；逐文件核对证实原分析库文件未变，仅有该次查询窗口新增的文件。它已保留移出工程目录，锁归档后数据库/manifest/loader指纹恢复原值。该暂存文件不可整文件加载分析。这些是第185批历史结果。
