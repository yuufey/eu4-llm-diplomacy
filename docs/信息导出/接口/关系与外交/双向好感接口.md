# 双向好感接口

第184批接通 `R04.opinion` 的实时查询、报告、周期订阅和采样变化订阅，覆盖为 `partial`。数值取自原生双向好感控件使用的缓存，每次请求重新采集，不跨请求复用快照；缓存由引擎何时更新、完整界面调用链和实际绘制仍未证明。

## 查询

默认 live 服务指定当前安装身份与逻辑观察国 FRA 后即可使用，不需要新增功能开关。观察国必须是非玩家国家，国家对必须包含 FRA；物理玩家不必是法国。当前验收会话的物理玩家是 POR。

```json
{
  "topic": "R04",
  "object": {"type": "country_pair", "actor": "FRA", "recipient": "ENG"},
  "fields": ["opinion"],
  "parameters": {}
}
```

两个端点必须不同，`parameters` 必须为空。方向按请求顺序返回，首先是 actor 对 recipient，然后是 recipient 对 actor。实际 FRA/ENG 查询得到：

```json
{
  "status": "known",
  "value": [
    {"holder": "FRA", "target": "ENG", "status": "known", "opinion": -200, "raw_hex": "38ff"},
    {"holder": "ENG", "target": "FRA", "status": "known", "opinion": -200, "raw_hex": "38ff"}
  ],
  "unit": "opinion_points",
  "scale": 1,
  "period": "current_cached",
  "complete": false
}
```

好感点数直接使用有符号16位整数，不除以1000，不在适配器中重新钳制。0是有效值；缺少表项不当作0。两个方向分别核对，一方向未知不会删除另一方向的已知值。准入明确拒绝时返回 `invisible`，准入无法证明或读取不稳定时返回 `unknown`；都不附加未知方向的数值。

第185批已另行接通 `opinion_modifiers` 的实时存储记录，可与本字段混合查询，见[双向好感修正实时接口](双向好感修正实时接口.md)。`decay`、`end_date` 仍未实现。`--opinion-save` 提供的是独立的历史修正快照来源，其日期、精度和查询限制保持原样。

## 订阅

查询可放入现有报告，再创建 `periodic` 或 `change` 订阅。实机2秒、5秒周期均通过，取消其中一个不会取消另一个。配置间隔不是交付延迟保证；调度沿用已有合并规则。

变化订阅只在两个方向均为已验证的 known 值时比较，以国家对为比较范围。首次建立基线，同值不发送，值变化才生成结果；未知或不可见样本不生成变化，并保留已有基线。它是周期采样比较，不是引擎逐条事件流。离线服务测试验证了基线、同值、单向值变化和未知四种情形，未为制造变化而修改游戏状态。

## 来源与可知范围

固定 EU4 1.37.4，EXE SHA-256 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。静态 image base 为 `0x140000000`，运行时使用实际 module base 加 RVA。

复用第183批的 accepted REA：`0x4eb2c0` 直接读取关系接受度中的 `DIPLO_OPINION` 表项；`0xeda880` 把同一表项格式化为 `opinion` 文本。本批新增的是普通 PE/Capstone 窄反汇编，不冒充新 REA Evidence：

- `0xef3be0` 将 RDX、R8 分别保存到对象 `+0x140/+0x148`；`country_opinion` 以后一端选国家表、前一端选槽位，`country_opinion_2` 方向相反。
- 国家对象 `+0x2380/+0x2388` 给出 signed-i16 向量。两个读取守卫分别为 RVA `[0xef3d55,0xef3da4)` 的79字节、`[0xef405f,0xef40a6)` 的71字节；此处没有数值缩放。
- 相邻 `+0x150/+0x154` 比较用于跳过相同值的重复格式化。在这段控件代码中未发现额外隐藏分支。

本字段据此复用既有 `0xf016e0` 国家选择准入，并将观察方参数投射到逻辑 FRA，同时核对非玩家角色。这是对已有准入逻辑的复用与静态推断；未把物理 POR 的视角直接授权给 FRA，也未证明完整 UI caller 链。公开结果保留 `partial`、新鲜度和实际绘制缺口。

采集器复用现有只读句柄、EXE/进程创建时间/session 绑定、国家 fullref 解析、双遍与原始读取记录验证。表头、国家身份、上下文或守卫变化会撤回相应结果；不执行游戏函数，不写世界变量。公开结果不包含内存地址或私有读取记录。

## 验证

当前 PID6472/session `6472-1dd6caf31db41bd` 实采通过准入、非玩家角色与严格记录重放；篡改一处表项会被拒绝。实际 MCP 查询约0.406秒，反向查询0.375秒，报告0.344秒；报告与两个周期结果同值，最终两订阅均 cancelled，server退出0、reader线程退出。

133个当前相关用例有通过记录，包括新读取、采集、投影、factory、历史修正来源及共用服务。最终测试 wrapper 首次漏写 Windows multiprocessing 的主入口保护，使一个并发用例失败；修正 wrapper 后仅补跑该失败项，原记录保留。首轮还修正了一处测试把 `invisible` 误断言为 `unknown` 的错误。完整测试集仍有继承问题，`whole_suite_passed=false`。
