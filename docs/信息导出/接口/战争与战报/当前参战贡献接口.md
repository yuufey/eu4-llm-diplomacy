# 当前参战贡献接口

W04.contribution提供原生战争总览的参战贡献百分比，用于比较盟友在本方的投入及议和分配。当前支持EU4 1.37.4/B23和FRA逻辑观察国，复用现有战争索引与参战记录读取。

## 选择战争

war对象使用actor=FRA与对手recipient选择战争，多场候选时填写W01返回的war_id。默认结果回显实际选择的编号，并按FRA所在阵营分组。

```json
{
  "queries": [{
    "topic": "W04",
    "object": {"type": "war", "actor": "FRA", "recipient": "BUR"},
    "fields": ["contribution"]
  }]
}
```

以下数值用于说明默认输出格式。

```json
{
  "actor": "FRA",
  "recipient": "BUR",
  "war_id": "war_0123456789abcdef_00000001",
  "contribution": {
    "our_side": {
      "FRA": {"percent": 75.0},
      "SAV": {"percent": 25.0}
    },
    "opposing_side": {
      "BUR": {"percent": 100.0}
    }
  }
}
```

## 选择国家

country对象按国家筛选其在FRA当前各场战争中的贡献，每场分别列出war_id、side及percent。当前没有相关战争时返回[]。

```json
{
  "queries": [{
    "topic": "W04",
    "object": {"type": "country", "country": "FRA"},
    "fields": ["contribution"]
  }]
}
```

## 数值与采样

百分比沿原生总览的同侧归组、累计参与值、整数截断和零总值规则计算，精度为0.1个百分点。已退出国家从当前成员列表排除，原生保留记录仍按游戏自身规则参与统计，当前成员之和可能受这些记录及截断影响。

无法读取的成员保留在完整视图的缺项中，已知成员继续输出。国家视图按所选国家的可读性处理。默认输出只包含业务值，完整视图保留原始比例、状态、采样与来源证据。

查询、报告、周期订阅和变化订阅使用同一读取实现。战争中的厌战值及土地标记可在同一W04查询中选择，组合入口沿已解析的war_id读取各字段。

相关字段见[国家厌战](../国家与国内/国家厌战信息接口.md)和[当前土地标记](当前战争土地标记接口.md)。
