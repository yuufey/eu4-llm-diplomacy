# 战争参战名单只读接口

W01 现在可返回选定战争两侧的参战国家。来源为当前游戏的国家引用向量；查询直接读取战争对象，不构造或提交议和。需要安装确认中的 `native_war_participants_query=true`，旧安装仍能发现战争编号，但名单返回未知。

```json
{
  "request_id": "war-participants-query-unique",
  "queries": [{
    "topic": "W01",
    "object": {"type": "country_pair", "actor": "FRA", "recipient": "BUR"},
    "fields": ["war_id", "participants"],
    "parameters": {}
  }]
}
```

当前国家对只有一场战争时自动选择。若有多场，结果的 `objects` 提供可选编号；将当前编号放入下一次查询的 `object.war_id`，或 `parameters.war_id`。同时提供时必须一致。编号只在当前 observer 会话内有效，重新载入后应重新发现。

`participants` 已知时，其值包含：

| 字段 | 含义 |
| --- | --- |
| `side_a`、`side_b` | 原生两侧国家标签数组，保持读取顺序 |
| `actor_side`、`recipient_side` | 请求双方分别属于 `side_a` 或 `side_b` |
| `source` | `native_war_side_vectors` |
| `status`、`complete` | `available`、`true`，只说明两侧国家名单的读取完整性 |
| `reason` | 已知名单为 `null` |

两侧标签不表示进攻方或防御方，也不表示领导人。`leaders`、`join_dates`、`co_belligerent_roles` 仍返回未知。只查询已知的战争编号和名单时，结果可以完整；请求全部 W01 字段时，缺失的三项使整体保持部分结果。

读取器每侧最多接受256国，逐项核对国家完整引用和国家对象，并比较两次读取的向量头、元素及身份。重复、跨侧重叠、双方未唯一分属对侧、读取中变化或输出超限时，名单返回未知，保留已确认的战争编号。未知名单不会以空数组冒充“没有参战国”。公开结果只含国家标签，不返回地址或原生句柄。

完整空战争集合表示这个国家对当前没有匹配战争；枚举不完整、旧编号未找到与多场待选择使用不同状态。国家对查询只覆盖该对关联的战争，不表示全世界战争或全部可见信息。

报告、周期订阅与变化检测使用同一查询。第67批在新 observer 会话取得两侧8国和10国：主动查询、同服务后台周期结果与独立只读内存快照一致。订阅已取消，日期保持1456.12.9。该样本没有验证领导人、角色、跨读档身份或完整可见范围。

证据位于 `work/runtime/information-war-context-forces-20261027-001/`；当前运行身份以 HANDOFF 顶部为准。旧65批的战争发现与66批的战争分数证据仍按各自安装和会话解释。
