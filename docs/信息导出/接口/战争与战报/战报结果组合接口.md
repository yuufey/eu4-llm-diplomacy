## 可读战报简报

252批在`brief`结果的`items[].presentation.battle_text`中提供按同一场记录组装的文字。通过`information_manage_report`创建简报配置，再用返回的报告编号查询即可读取。

```json
{
  "name": "指定战报简报",
  "detail": "brief",
  "queries": [{
    "topic": "B04",
    "object": {"type": "battle"},
    "fields": ["details", "raw_text"],
    "parameters": {"event_id": "替换为实际事件编号"}
  }]
}
```

用于逐场事件订阅时，可以省略查询中的`event_id`，由既有事件投影关联当场记录。结果列表也可为以前保存的简报生成这一文字视图。

`battle_text.text`包含名称行、当前配置分支的文字控件和按钮文字。每段以控件键标识，未知文字显示具体原因。`sections`保留对应字段路径、来源依据和`derived`标记，重复控件键按不同路径分别记录，原有转义、颜色和空文字沿来源保留。数值帧及图标控件的路径在`non_text_controls`列出。

段落顺序沿静态绑定声明顺序，`is_native_raw_text=false`、`complete=false`及原有完整显示缺项同时返回。复制文字和派生候选分别标记，完整原文采集仍是独立缺项。正文最多256KiB，达到上限时通过`omitted_section_keys`列出省略的段落，原业务字段继续保留。

这层呈现通过已有查询、事件简报、列表和外部交付入口使用。完整持久结果仍可通过`information_get_result`取得，原业务字段和事件载荷按原合同保存。实际历史法国“讷韦尔战役”的文字视图有29项已知文字和1项未知，见[历史样例](../../../../work/runtime/information-battle-readable-20261107-252-001/recorded-text.txt)。该例来自224批已留存记录，本批没有新采游戏战斗。
