# 当前战争土地标记接口

W04.land_commitment复用R07.land_commitments，提供当前参战国的promised_land标记，帮助判断议和分配需要考虑哪些受益国。当前范围为逻辑观察国FRA正在参与的战争，支持EU4 1.37.4。

## 对象与查询

war对象填写actor=FRA及对手recipient，沿W01选择具体战争。存在多个候选时，先查询W01，再把其返回的war_id填入object。结果回显实际选择的公共战争编号。

```json
{
  "queries": [
    {
      "topic": "W04",
      "object": {"type": "war", "actor": "FRA", "recipient": "ENG"},
      "fields": ["land_commitment"]
    }
  ]
}
```

country对象按受益国筛选其在FRA当前战争中的标记。country=FRA可读取本国受益标记，其它国家也使用相同筛选规则。

```json
{
  "queries": [
    {
      "topic": "W04",
      "object": {"type": "country", "country": "FRA"},
      "fields": ["land_commitment"]
    }
  ]
}
```

## 业务值

默认land_commitment返回已确认的当前标记列表。每条包含war_id、beneficiary、side、war_leader及observed_promisor。beneficiary为受益国，side为相对于FRA的our_side或opposing_side，war_leader为受益国当前所属阵营的战争领袖，也是原生土地分配计算使用的当前议和关联国。

observed_promisor为同一会话、同一公共war_id和受益国对应的最近一次已采集许诺发送方。其依据为实际宣战或召盟执行后确认成立的土地许诺，接入前缺少记录时返回null。该字段记录已经观察到的发送方事实，历史覆盖范围与事件编号保存在完整视图的land_promise_association中。当前土地标记的complete继续说明参战国标记的可读范围。

确认没有所查标记时返回[]，所选受益国不可见或读数未知时返回null。完整视图保留status和complete。战争视图若仍有不可见成员，列表保留已知条目，complete为false。国家视图先核对所选受益国的可读性，其它成员不可见时仍可提供该受益国的已知标记。

尚无公共战争编号的国家视图记录保留war_id=null及已有opponents，避免据旧记录推定战争关联。已退出战争的历史参战记录被排除，待回应的参战召唤通过A04读取。

## 报告与订阅

该字段支持普通查询、报告、周期订阅和采样变化检测。国家视图比较已经确认可读的所选受益国标记，战争视图在成员范围完整可读时比较整场列表。已采集许诺支持C04事件查询与land_promise_established订阅。待回应召唤沿A04读取，接入前的发送方保留未知。

NativeWarLandCommitmentsSource(commitments_source)只拥有W04.land_commitment。战争视图调用正常R07.read，国家视图通过NativeCommitmentsSource.read_land_for_country共用相同捕获与筛选。与其它W04字段联合查询时由CompositeSource组合各字段所有者。

R07的经济支持、参战约定及土地标记说明见[持续承诺接口](../关系与外交/持续承诺与经济支持证据接口.md)。

发送方观察条件及历史关联见[土地许诺观察接口](../关系与外交/土地许诺观察与关联接口.md)。
