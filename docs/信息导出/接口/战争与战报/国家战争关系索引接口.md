# 国家战争关系索引接口

默认实时模式通过 `R03.wars` 返回指定国家的当前战争索引。`NativeWarRelationsSource` 与 F01 共用同一个 `NativeCountryScaleSource` 实例，只委托读取 `F01.wars`，不另建读器或原生配置。逻辑观察国仍是非玩家 FRA，物理客户端国家 POR 不会替换观察国或查询对象。

```json
{
  "queries": [{
    "topic": "R03",
    "object": {"type": "country", "country": "FRA"},
    "fields": ["wars"],
    "parameters": {}
  }]
}
```

国家对象也可指定其他三字符 TAG，由 F01 原有国家准入规则决定是否可导出。未获准的国家和成员不会因这个接口而公开。`country_pair` 战争视图尚未实现，返回 `unsupported`，不触发委托读取。

## 返回内容与限制

字段使用 `unit=native_country_wars`、`scale=1`、`period=current`，始终 `partial=true`、`complete=false`。其 `value` 保留 F01 的公开结构：

- `at_war`、`war_count` 和 `wars`：当前国家 opponent index 的投影。
- 每场战争的 `target_side`、`side_a`、`side_b`：本次核对的成员及身份状态。未核对身份保留 `unknown` 或 `invisible`，不补猜 TAG。
- `war_id`：已匹配观察会话登记时返回会话内标识；否则保留未知。它不证明原生对象生命周期。
- `enumeration_scope=current_country_opponent_index`、`global_membership_verified=false`、`lifetime_verified=false`：不能把索引当作完整战争枚举。

`side_a`、`side_b` 不表示进攻方或防守方。索引为空时可以返回已知空索引，但仍不保证完整枚举。来源未知或读取失败时没有 `value`，不会返回空列表代替失败。

接口只复制战争字段和经过筛选的来源摘要，并保留原捕获报告哈希。不会带出 F01 的发展度等其他字段、原生指针或私有捕获内容。会话、日期、观察国、DLL 或客户端身份在读取中改变时，结果不保留战争值。

## 报告与订阅

支持直接查询、手动报告和周期导出。完整性不足，变化订阅返回业务错误 `unsupported_trigger`；不生成原生战争开始或结束事件。

R03 的 `rivals` 继续由原宿敌来源读取。一个查询可以同时选择 `rivals` 与 `wars`，组合来源分别路由到各自所有者。`truce_until`、`coalition_members` 和 `targets` 仍未实现。显式历史存档和 recorded 模式不添加本实时来源。
