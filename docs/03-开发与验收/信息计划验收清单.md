# 信息计划验收清单

本页规定信息模块的交付标准。功能范围遵循[信息导出与订阅开发计划](../信息导出与订阅开发计划.md)及用户确认的宏观战略用途。当前完成状态、实际缺项和证据入口统一见[当前开发状态](../../logs/CURRENT.md)。原有批次经过及验收数字保存在[历史验收记录](../../logs/文档迁出记录/2026-11-15-信息计划验收清单-历史验收记录.md)。

## 核心信息交付

| 决策用途 | 需要取得的信息 | 验收依据 |
| --- | --- | --- |
| 确定当前事务 | 本国、日期、战争、重要提议、任务目标及已有承诺 | 正常查询或报告能读取相关对象，待处理状态与实际回应结果可复查 |
| 判断承受能力 | 财政与债务、军力与后备人力、主要质量指标、外交资源和国内压力 | 数值及适用范围可理解。最大人力、水手等已要求的上限可读，稳定度和厌战度等范围清楚 |
| 比较外交关系 | 盟友、宗属、保障、停战、宿敌、包围网、好感、人情与承诺 | 当前比较对象的方向、关系成员和期限正确，外国信息符合观察国的可知范围 |
| 选择战略方向 | 当前任务条件与战略奖励、核心与宣称、相关领土兴趣、贸易网络及本国收益 | 已确定的信息条目通过正常入口可读，足以比较有关国家、地区和节点 |
| 比较具体行动 | 宣战、召盟、议和及其它外交行动的合法性、成本、接受原因和后果 | 正常预览对应具体对象及方案，执行结果能与预览及后续状态对应 |
| 决定何时重评 | 战略战报、提议与回应、宏观变化及关键自然到期 | 事件能采集、持久化并交付匹配订阅，完整记录可按需读取 |

详细字段范围沿用主计划。精确待补员人数、任意任务条件穷举、精确贸易反事实、逐槽来源归因及战报逐控件还原按既定扩展分类处理。

## 战报与事件

逐场战略战报交付日期、地点、参战双方、观察国所在侧、胜负和双方损失。已有规模、攻守角色及战争关联继续使用。真实陆战和海战样本须经正常简洁查询及通知核对，损失单位和双方对应关系明确。

宏观事件按规定类型分别验收，包括宿敌变化、宣战、关系变化、本国修正新增、非到期移除、自然到期和任务进展。H02沿既定范围提供停战、宣称、外交派遣冷却、补贴、修正及提议生命周期历史。

每类事件保留捕获入口、观察范围、实际发生日期、排序、去重、断档及持久化依据。新增、移除和自然到期分别核对。已有来源满足选定任务或外交场景时，沿其适用范围继承证据。

“撤回”对应外交官召回或取消外交任务，验收所选任务停止后的状态、返程状态、执行结果及通知。提议生命周期须正确影响待办和回应消费者，明确到期沿对应业务来源分类，通用队列删除按提议失活导出。原始提议与终态记录保持同一公开身份和正确顺序。

## 共享机制

| 项目 | 完成条件 |
| --- | --- |
| 能力发现 | 当前主题、字段、对象、参数、观察范围和支持的触发方式可发现，目录与实际字段所有者一致 |
| 一次性查询 | 通过正常工具读取所选信息，结果属于正确国家与会话，未知原因可复查 |
| 默认输出 | 返回简洁业务数据及必要数值范围，单位和统计口径在接口定义中说明，内部来源与诊断通过完整视图读取 |
| 多频率报告 | 不同周期及字段集合独立运行，重叠来源可共享采集，修改或取消一个订阅不会影响其它订阅 |
| 自主配置管理 | 支持创建、读取、列出、版本化修改、暂停、恢复及取消，运行中变更生效，无效配置原子失败 |
| 事件采集与交付 | 捕获在记录消失前完成，事件和游标可恢复，匹配订阅按顺序交付，去重、断档及交付状态可查 |
| 历史查询 | 定时和变更报告能读取共同账本的新记录，分页及筛选符合字段合同，历史采集与主动通知各自按配置运行 |
| 观察方与会话 | LLM使用指定非玩家国家视角，外国可知范围正确，会话变化时重新解析对象及游标 |
| 时间推进 | 正常查询可在游戏运行时使用，跨日采样按已有字段合同保留可用数值及采样范围 |
| 持久化与恢复 | 服务重开后配置和已保存结果可读，游戏暂停、载入、重启及会话变化的调度状态可解释 |
| 并发与取消 | 并发查询、重叠订阅和运行中取消保持已有隔离合同，已取消订阅不会继续生成新的采集任务 |
| 读取与输出失败 | 已确认的部分结果、失败原因、重试状态及持久交付状态一致，故障不会丢失已经提交的事件 |

## 验证节奏与证据

已有验收按版本、观察方、配置与场景继承。代码、来源、协议或语义改变，或出现具体矛盾时，补受影响检查。叶字段改动选择该字段及必要公开入口，共享调度、恢复和取消按功能组验证。

完整回归 `python -m pytest -q bridge/tests` 安排在交付整合里程碑。保留收据并区分当前功能故障、历史工件缺失和陈旧合同，按其对核心交付的影响处理。相关检查通过时记录实际覆盖范围。

每项证据说明适用配置、版本、观察国、对象、来源、日期及结果。静态推断、自有夹具、历史回放和当前游戏观测分别登记。批次经过、测试数字、临时进程及路径写入日志和原始收据。

涉及游戏时继续遵守原no-repeat、资源及自动化规则。保存由实际恢复需要触发。测试临时目录及诊断捕获按[工作区维护规则](日志文档与工作区维护.md)收尾。

## 整体使用验收

既定信息条目和事件补齐后进入P3。使用完整输入比较指定非玩家国家的实际外交方案，通过正常入口读取行动预览并复查执行前后状态，记录输入体积、总体耗时及具体信息缺项。

完成依据为既定战略信息与事件能持续通过正常入口使用，LLM能据此作出可解释的外交比较，执行前后结果可复查，已有证据和剩余缺项可追溯。
