## 功能概览


### 信息导出

模型可以按需查询游戏信息，例如本国还有多少人力、与邻国的停战何时结束、某个任务还缺哪些条件。也可以把常用查询组合成定期报告，或订阅已经接入的事件，例如战役结束和停战到期。查询外国时，可读内容取决于观察国可见的情报和接口支持的范围。

- [国家与国内](信息导出/接口/国家与国内/) — 国库、月度收支、陆海军、人力和治理容量。
- [关系与外交](信息导出/接口/关系与外交/) — 双向好感、停战期限、包围网、外交官和收到的外交提议。
- [战争与战报](信息导出/接口/战争与战报/) — 参战名单、战争分数、参战贡献和历次战斗的损失。
- [任务](信息导出/接口/任务/) — 任务树分支、前置条件、目标省份和任务奖励。
- [贸易与省份](信息导出/接口/贸易与省份/) — 省份归属、核心与宣称、贸易节点的价值和各国贸易竞争力。
- [机制与宗教](信息导出/接口/机制与宗教/) — 统治者与继承、神圣罗马帝国的选侯和改革、教廷与宗教学派。

### 外交操作

模型可以替获授权的国家预览外交行动是否符合当前游戏规则，对适用的行动查看影响对方接受意愿的因素，然后提交行动并回查实际结果。

- [关系与外交](外交操作/接口/关系与外交/) — 提议结盟、改善关系、王室联姻、建立间谍网、赠送礼物和使用人情。
- [战争与战报](外交操作/接口/战争与战报/) — 选择宣战理由和参战方、查询战争分数、预览议和条款的影响并提出议和。

### 政治地图

模型可以从观察国视角查看总览、区域和局部政治地图，并根据图上的坐标查询对应省份及其所有国。游戏进行时，服务还可以按游戏月份定期导出三种尺度的地图图片和省份归属数据。[地图导出接口使用说明](地图功能/地图导出接口使用说明.md)

### 定期决策与游戏时钟

测试环境可以按游戏日生成本国战略简报，并交给同一个 Codex 会话继续决策。启用时钟权限后，模型也可以暂停游戏或切换速度。[战略简报实机记录](../logs/2026-11-21战略简报触发Codex回合.md) · [统一游戏服务使用说明](共用开发/统一游戏服务使用说明.md)
