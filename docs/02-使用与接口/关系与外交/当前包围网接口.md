# 当前包围网接口

R03提供所选国家当前包围网的两个方向，适用于1.37.4、逻辑观察国FRA。country对象可指定FRA及通过现有国家可见性检查的相关国家。

- coalition_members列出当前针对所查国家的包围网成员。
- targets列出所查国家当前加入的包围网所针对的国家。原生国家记录同一时刻至多保存一个目标，因此该列表长度为0或1。

```json
{
  "request_id": "coalitions-fra",
  "queries": [
    {
      "topic": "R03",
      "object": {"type": "country", "country": "FRA"},
      "fields": ["coalition_members", "targets"],
      "parameters": {}
    }
  ]
}
```

默认结果返回按国家标签排序的列表。已确认没有成员或目标时返回[]，不可见或无法确认时返回null，完整视图保留状态与原因。

成员读取核对国家完整引用、双向关系与当前链表。游戏迭代期间可能保留已标记删除的节点，输出将其排除。两遍采样之间发生变化时，受影响字段保留未知，其它可确认字段继续返回。成员和目标涉及的国家均使用现有观察方可见性准入。

查询与报告、周期订阅、采样变化订阅共用正常信息接口。变化订阅反映采样到的状态差异，短于采样间隔的变化沿共享调度机制处理。P05.coalition继续提供具体和约方案的潜在包围网后果。

完整证据保留在view=full，默认结果仅输出国家和业务列表。读取使用普通只读进程内存，不调用游戏函数。
