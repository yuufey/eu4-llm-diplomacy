### 结果与单位

`F03.subsidies.value`是mixed结果，单位`subsidies_information`、scale为1、period为`mixed`，basis为`native_subsidies_independent_scopes`。它分别保留两种含义不同的数据：

- `received_previous_month`来自目标国上一月收入缓存，单位为杜卡特、scale为1000、period为`month`、reference为`previous_month`。它表示上一月收到的金额。
- `observer_involved_contracts`观察当前FRA财政关系中，FRA与本次目标国家这一对是否登记了补贴对象。其scope为`observer_target_pair_only`，单位为`bilateral_subsidies_relation`、scale为1、period为`current`。它不枚举目标与第三国的合同。

合同中的`monthly_nominal_amount`是约定的月度名义金额，不代表上一月实收金额。若两边都没有该pair的匹配项，公开结果只报告这对国家未匹配；`complete_country_contracts`固定为false。

### 准入与公开内容

父层必须先允许FRA查看本次目标国家，并确认逻辑观察方FRA是非玩家角色。任一父层条件拒绝或未知，整个目标结果都不发布可用字段。父层通过后，上一月补贴收入使用`income_comparison`权限；FRA财政关系使用独立的`observer_fiscal_bilateral_subsidies`权限。收入权限或缓存漂移只撤回`received_previous_month`，pair权限、双方关系行或其绑定日期漂移只撤回`observer_involved_contracts`；通过自身检查的另一项不随之消失。采集器还会核对pair权限中的signed日期与同一capture context日期。

`private_native_fra_own_fiscal_subsidy_pair`描述FRA自身财政关系的pair范围，不证明FRA界面实际渲染。公开合同对象只保留双方tag、观察方角色、signed月度名义金额及其杜卡特值、起始日历日期、signed年数，以及派生显示截止日和公式。公开结果不包含完整国家引用、内存指针、私有读取trace或source路径；日期原始值也不会进入公开合同对象。

`current_payment_obligations`、`active_contracts`、`term_legality`、源对象`+0x28`旗标语义和原生关系生命周期仍为`unknown`。派生截止日期只说明所用数值公式，不证明关系处于活动期或正在付款。当前静态配置仍为62 available / 192 partial / 143 planned、48个callable主题和74主题/397字段。第93批实际discovery为74主题/397字段、56 available / 156 partial / 185 planned、43个available主题。
