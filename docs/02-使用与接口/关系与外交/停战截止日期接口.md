# 停战截止日期接口

默认实时模式可查询 `R03.truce_until`，返回选定方向的直接停战记录截止日期。逻辑观察国为非玩家 FRA；国家对必须包含 FRA，另一端由原有国家准入规则核对，不会切换玩家国家或回应外交请求。

```json
{
  "queries": [{
    "topic": "R03",
    "object": {"type": "country_pair", "actor": "FRA", "recipient": "ENG"},
    "fields": ["truce_until"],
    "parameters": {}
  }]
}
```

`actor` 指定关系记录的持有方，`recipient` 指定另一方。反向查询使用 `actor=ENG, recipient=FRA`；两方向独立读取和选择，不推定日期相同。`country` 对象的完整停战枚举仍未实现。

## 值与缺项

已知结果示例：

```json
{
  "status": "known",
  "value": 56615880,
  "raw": 56615880,
  "date": "1463.1.1",
  "hour": 0,
  "direct_record_flag": true,
  "unit": "eu4_hour_tick",
  "scale": 1,
  "period": "current",
  "partial": true,
  "complete": false
}
```

`value/raw` 使用游戏的小时日期编码，`date/hour` 是同一固定365日历的展开表示，不是现实时间。日期由经过核对的原生规则及当前配置计算，计算本身在 Python 中进行，查询不会调用游戏函数。

直接记录标志未设置时，字段返回 `not_applicable`、原因 `DIRECT_PAIR_TRUCE_FLAG_NOT_SET`，没有 `value`。这不表示所有主属国关联路径都没有停战。不可见、未知或读取失败也不会被改成零日期。

目录和结果保持部分实现，因为关联国家停战、完整可知范围及实际 UI 绘制尚未验证。读取得到的是本次稳定采样的缓存输入，不保证原子快照或即时更新。参考日期之前的日历行为及日期溢出尚不支持，返回缺项，不外推日期。

## 查询、报告与订阅

支持直接查询、手动报告及周期导出。多个周期仍由通用服务独立管理。变化订阅返回 `unsupported_trigger`；本接口不生成停战开始或结束的原生事件。

R03 的宿敌和战争索引继续由原来源处理，组合查询按字段和对象视图分别路由。包围网、目标和完整停战枚举仍在计划中。显式历史存档与 recorded 模式不添加本实时来源。

## 来源与验证

`NativeTruceDatesSource` 使用独立 `truce_capture` 和新增 v1 配置，复用现有只读身份、国家解析、非玩家角色、准入、双遍读取及保存 trace 重放。旧配置与旧读器未改动。新增配置锚定 B23，并加入停战标志、日期计算、日历辅助函数及月份表的守卫；加上基础配置共25项。返回结果只包含选定日期和来源摘要，不公开原始关系行、指针或另一方向的私有输入。

第125批当前 PID45688、会话 `45688-1dd6b3ed674d8d0`、日期56556984下，两个方向的原始记录均为直接标志真、调整字节23、日期输入56551344；两处运行时配置为10与5。两遍记录、角色与身份一致，严格保存重放通过，句柄关闭。这里不把调整字节另行命名为战争分数。

为独立核对日历计算，在自有测试进程的私有内存中加载提取的日期代码、月份表和测试配置，先校验调用与分支闭包，再执行62个样例。结果与纯模型全部一致，覆盖月末、跨年、负向月份调整和小时保留；测试内存已释放。这是离线复制代码重放，没有在 EU4 中调用函数。

实际 MCP 验收 `FRA→ENG`：一次查询、手动报告、2秒及5秒周期均返回上述1463.1.1结果；取消短周期后长周期继续 active，最终两订阅取消，服务返回0、reader停止，前后来源与会话日期一致。反向选择有独立单测及双向原始采样，本批没有另发反向 MCP 查询。公共 `paused` 仍为 null。

当前205项定向整合测试通过，覆盖新来源、原始输入、日期算法、R03旧来源及通用服务。最初发现的反向查询角色门已修复；测试夹具与旧“停战字段planned”预期的失败原件保留。离线执行器最初把请求窗口长度当成有效解码前缀的校验错误也已修正，未为此重新采集游戏数据。

证据位于 `work/runtime/information-truce-expiry-20261103-125-001/`：`private-inputs-001/`、`private-inputs-audit-001/`、`native-parity-001/`、`integration-tests-002/` 和 `mcp-001/`。最近完整回归仍为第121批，不覆盖本批新增生产代码，205项定向不能代替当前完整回归。
