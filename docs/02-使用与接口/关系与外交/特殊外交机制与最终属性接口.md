## 第164批：已知受支持属性的变化订阅

已修复第163批记录的变化基线缺口。`N09.final_value` 仍是 `partial=true/complete=false`，但当本次受支持属性全部已知、单位与原始值合同一致、来源/对象/上下文和原采集证据均有效时，可以建立变化比较基线。当前范围为纪律、陆海军士气、外交声誉、外交官总容量和外交关系容量，共六项。

变化订阅的报告查询必须仅选择 `final_value`。其他 N09 字段可以查询或周期读取，但不能混入这项变化订阅；不支持的混合范围在创建时以 `unsupported_trigger` 拒绝。配置仍需提供 `enabled`：

```json
{
  "operation": "create",
  "config": {
    "name": "最终属性变化",
    "kind": "change",
    "enabled": true,
    "report_id": "已创建的仅含N09.final_value查询的报告ID",
    "schedule": {"basis": "real", "every": 2, "unit": "seconds", "missed": "coalesce"}
  }
}
```

基线只比较受支持的公开属性值和明确范围，不比较每次采集变化的报告摘要。属性未变时静默；数值变化才产生变化结果。任一属性未知、缺失、单位错误或上下文变化时，保留旧基线及最后结果；恢复后再与旧值比较。受支持属性集合或固定 profile 改变时，只重新建基线，记录 `baseline_scope_changed`，不把范围改变当成数值改变。

变化结果继续保留 `complete=false` 和部分覆盖状态，不声称覆盖全部最终属性、不把独立采集视为原子快照，也不承诺捕获两次采样之间的每次变化。`source_breakdown` 和 `modifier_effects` 的变化比较仍未实现。

服务的原有完整样本比较方式保持原语义。部分样本必须由实际字段来源提供 `information.change_comparison.v1` 合同：schema、稳定 scope 和与已采样字段完全一致的 fields。服务对协议错误或来源异常拒绝比较；Composite 只向独占整个查询的单一所有者转发，战报包装层转发普通来源但不替战报部分记录授权。其他没有明确合同的不完整来源继续不能更新变化基线。

177 个当前唯一相关测试按最新同 ID 结果归并通过，覆盖实际值变化、未知/恢复、无变化静默、范围重建、取消、完整样本兼容与错误协议拒绝。实机只检查基线和数值未变时静默，没有修改游戏值来制造变化：2秒/5秒均建立基线并进入unchanged，摘要独立匹配第163批冻结的六项值；取消短订阅时长订阅仍active，最终全部cancelled，server exit0、reader退出、源码前后摘要一致。

# 特殊外交机制与最终属性接口

当前部署支持逻辑FRA国家视角。两个入口复用已有只读来源；其他国家、其他字段的范围仍待开发。

```json
{
  "queries": [
    {
      "topic": "S05",
      "object": {
        "type": "country",
        "country": "FRA"
      },
      "fields": [
        "trade_league"
      ],
      "parameters": {}
    },
    {
      "topic": "N09",
      "object": {
        "type": "country",
        "country": "FRA"
      },
      "fields": [
        "modifier_effects",
        "final_value",
        "source_breakdown"
      ],
      "parameters": {}
    }
  ]
}
```

S05.trade_league返回country、active、leader和members。active取原生入盟谓词；members保留全成员及其顺序，包括FRA自身。空partner列表不能单独证明未入盟。当前实机FRA未入盟，active=false、leader=null、members=[]；活跃关系只做了离线真实结构验证。
