# 贸易节点价值只读接口

`T03` 为 EU4 1.37.4 的非玩家观察方 FRA 提供指定贸易节点的当前价值缓存及流出明细。四个字段共用一次只读采集，随后重放原始读取记录，核对会话、日期、节点身份和逐字段双遍一致性。

| 字段 | 当前返回内容 | 覆盖 |
| --- | --- | --- |
| `local_value` | 节点的本地产生价值缓存 | partial |
| `incoming_value` | 原生流入向量各项的有符号32位累加值 | partial |
| `total_value` | 按原生界面填值算式计算的本地＋流入－流出，保留32位回绕 | partial |
| `outgoing_value` | 原生流出总额，以及按目标节点列出的流出价值 | partial |
| `collected_value` | 原生留存提示中的节点金额，采用各国贸易效率计算前的口径 | partial |

当前 `total_value` 对应实际界面控件的填值算式；该版本的本地化提示将总值描述为本地＋流入，两者存在差异，不能把提示文字当作实际算式。流出总额与方向明细采用各自的原生来源，接口不强制明细相加等于总额。节点整体价值与 `T05.income` 的国家收入分别记录。

`collected_value` 对应原生 `TRADE_RETENTION` 提示中的货币金额。该提示与 `total_value` 数框使用相同算式，所以当前两项数值相同；它们分别保留数框与留存提示的来源语义。留存金额采用各国贸易效率计算前的口径，各国实际收入仍由 `T05` 提供。留存提示的显示门也保留：先按有符号32位相加两类竞争力，再除以1000截零；商为零时原生显示“无贸易”，本字段保持 `unknown`，不补成零。

## 查询

使用 `information_query`：

```json
{
  "request_id": "trade-node-value-001",
  "queries": [{
    "topic": "T03",
    "object": {"type": "trade_node", "node_id": "champagne"},
    "fields": ["local_value", "incoming_value", "total_value", "outgoing_value", "collected_value"],
    "parameters": {}
  }]
}
```

`node_id` 是定义中的稳定 ASCII 键，长度不超过128字符；参数必须为空。查询其他观察方、无效字段或对象形状会被拒绝。只查询 `collected_value` 时也执行一次采集、严格验证和投影；与其它字段一起请求时共用一次采集。

报告配置与现实时间周期订阅可使用相同查询。当前来源声明 `query` 和 `periodic`，没有声明逐场事件捕获。该接口不会推进游戏时间。

## 数值、身份与可知范围

标量字段的 `value` 与 `raw` 都保留原生整数，`scale=1000`、`unit="ducats"`、`period="current"`。例如原始值6689表示6.689杜卡特。`outgoing_value.value` 为：

```json
{
  "total_raw": 4409,
  "routes": [
    {"node_id": "genua", "raw": 0},
    {"node_id": "english_channel", "raw": 4409}
  ]
}
```

采集先从原生节点定义管理器解析标识和中心省份，再核对该中心省份的运行时节点指回同一定义。只有实际核对 FRA 为非玩家、自身读取准入成立、中心省份的 FRA 发现位为正之后，才读取金额。发现位为零或缺失时保持未知，不能推断为不可见。各字段独立比较完整原始输入；流出明细失败不会撤回仍稳定的本地值等独立字段。

这个路径仍未覆盖完整的原生贸易界面可见性判定，也没有观察界面实际绘制、证明缓存新鲜度或核对各国实际入账。因此五个字段均保留 `partial`、`complete=false`。CWTools 配置只提供脚本作用域别名及父级元数据，不授予运行时读取权限。

当前使用 v2 capture 和独立留存 profile。v1 文件保持原样，v2 验证器可显式重放 v1 原始记录；旧记录中的未知 `collected_value` 继续未知。

公开结果不包含原生地址、私有原始输入或目标省份地址；私有采集材料单独保存供重放。游戏构建固定为 B23，EXE SHA-256为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。
