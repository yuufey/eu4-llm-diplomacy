# 自定领土战略目标

`G01.strategic_targets` 导出调用者明确声明的领土战略目标。目标通过查询参数提供，也可以随报告配置保存，由 LLM 使用已有报告管理接口创建、读取和修改。它不读取 C03 的自由文本，不从描述中猜测省份，也不推断原生 AI 当前正在追求什么。

```json
{
  "topic": "G01",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["strategic_targets"],
  "parameters": {
    "strategic_targets": [
      {
        "id": "normandy-plan",
        "intent": "acquire",
        "target": {"type": "area", "name": "normandy_area"},
        "description": "示例：规划诺曼底地区"
      }
    ]
  }
}
```

每项声明有唯一 `id`、目标意图 `intent` 和明确对象 `target`。意图可选 `acquire`、`return_core`、`protect_subject`、`weaken_country`、`other`；可另附说明。这些词描述调用者的意图，不触发征服、归还核心、保护属国或任何外交动作，也不证明相关行动当前合法。

| 目标对象 | 必填字段 | 静态解析的含义 |
| --- | --- | --- |
| 省份 | `type: province`、整数 `province_id` | 核对该编号是否出现在地图定义中 |
| 地区 | `type: area`、标识 `name` | 核对 area 定义并列出静态成员省份 |
| 区域 | `type: region`、标识 `name` | 核对 region 定义并列出静态成员省份 |
| 国家 | `type: country`、标签 `country` | 核对静态国家标签；不展开该国当前属地 |

来源始终标明 `source_kind=caller_input`、`game_fact=false`，字段保持 `partial`、`complete=false`。已知声明与已知地图成员是两层信息：没有地图索引、定义发生变化或对象无法解析时，仍可以知道调用者声明了什么，但成员解析保持未知。静态地图成员不表示当前归属、发现范围、任务要求、条件满足、实际可执行性或引擎已加载的完整目标。

缺少 `parameters.strategic_targets` 表示未声明，返回未知；显式提供 `[]` 表示这次查询明确声明了空列表，可以返回已知的声明空集合。它不证明游戏没有其它战略目标。

国家查询对象必须等于当前逻辑观察国。省份查询用于筛选该观察国声明中涉及此省份的目标；不能把未解析的地区或国家目标当作“与此省份无关”。有未决成员关系且没有已知匹配时，结果保持未知，不能返回已知空集合。

实时信息服务默认注册这项声明能力。启用 `--static-game-data` 或 `--mission-game-data` 后，使用已有 CWTools 解析器和 `StaticMissionScopeIndex` 核对静态对象；同时启用任务信息时，两类 G01 来源共用同一个静态索引。单次读取批量解析去重后的目标标识，不逐项重复读取地图配置。未启用静态数据时不会自动读取游戏文件。

G01 各实时来源共用参数 schema。原有 `root_id`、`task_id` 仍为可选参数，核心与宣称查询仍接受空参数；同时查询 `task_targets` 时才要求完整任务选择器。内部 M05 只接收任务选择器，不会收到自定目标声明。历史存档来源与 C03 文本输入合同保持原样。

将上述查询保存为报告后，可使用 `information_manage_report` 更新目标数组，使用 `information_query` 的 `report_id` 读取，并由多个周期订阅共用。目标修改沿用报告配置的版本校验和整体生效规则；不需要额外的手工输入文件，也不会改变游戏世界。当前支持主动查询、报告和周期订阅，未声明原生战略事件或变化订阅。

每个查询最多 64 条声明；标识最多 128 个 ASCII 字符，说明最多 2048 字符，完整 G01 参数最多 64 KiB，输出最多 4 MiB。重复标识、未知字段、非法对象或超限输入在读取前拒绝。验收示例目标只保存在本批独立验证数据库中，不作为用户的实际战略配置。

本批 113 个唯一相关测试用例取得通过记录：94 项兼容检查、19 项新增来源与集成检查。新增测试首次有 4 项在服务参数 schema 校验处失败；补齐 schema 的基础对象类型和属性约束后，仅补验这 4 项，原失败 XML 保留。完整测试集尚未重验，不能据此称全套通过。

正式只读验收保存了同次静态索引返回，逐项核对 5 条示例声明：省份 183、`normandy_area` 的 4 个静态成员、`france_region` 的 66 个静态成员，以及 BUR、ORL 的静态标签。国家目标的当前省份成员仍未知。任务与自定目标共用同一索引，单次声明读取只批量查表一次，任务状态读取次数为 0。

真实 stdio MCP 另外核对了仅启用静态数据的启动路径、未声明与显式空数组、报告目标从 5 条更新为 4 条，以及 2 秒／5 秒周期订阅使用更新后的声明。短订阅取消后长订阅仍运行，最终全部订阅取消，服务与读取线程退出，源码校验值未变。逻辑观察国仍为法国、物理玩家仍为葡萄牙，游戏在 1456.8.30 暂停；没有推进、外交操作、保存、重启、注入或原生任务采集。
