# 实时已发现省份接口

默认实时服务通过 `NativeProvinceDiscoverySource` 提供 `C02.discovered_provinces`，支持主动查询、手动报告和现实时间周期导出。结果来自观察国的发现位图，不要求把客户端切换到观察国。当前支持逻辑观察国 FRA，其非玩家身份由原生控制器数组校验。

## 查询与结果含义

```json
{
  "topic": "C02",
  "object": {"type": "session"},
  "fields": ["discovered_provinces"],
  "parameters": {}
}
```

也可用 `{"type":"country","country":"FRA"}` 选择同一观察国视角。其他国家选择器返回 `not_applicable`，不会导出那个国家的地图。会话选择器可带当前 `session_id`；不匹配时拒绝读取。查询参数必须为空。

`value` 是升序、不重复的正省份编号列表，`unit="province_id"`、`period="current"`。当前逐项检查管理器正索引范围 `1..count-1`；通过 `candidate_count` 和 `candidate_id_range` 明确返回本次范围。编号 0 的公开地图语义及完整可知范围尚未证明，因此字段保持 `coverage="partial"`、`complete=false`、`domain_complete=false`。它不表示完整世界地图，也不授予读取其他省份字段的权限。

`bitmap_words_native_length_bounded=true` 表示每次读取先检查位图类型、word 长度、容量和存储范围，再读取观察国对应的 word。长度外、指针无效、短读、身份不符或任一候选未知，都撤回整次列表并返回未知。所有候选有效且发现位均为零时，才返回已知空列表。两遍结果及位图头部必须一致，但两遍采样仍不是原子快照。

`C02.discovered_countries` 和 `C02.related_countries` 仍为 planned。混合请求保留这些字段的未实现状态，不用已发现省份推算它们。

## 报告与周期订阅

把上述查询放入报告配置的 `queries`，即可手动执行报告或创建 `kind="periodic"` 订阅。现实时间周期使用现有调度配置，例如：

```json
{"basis":"real","every":5,"unit":"seconds","missed":"coalesce"}
```

当前不支持 `change` 或逐场事件触发，创建此类订阅返回 `unsupported_trigger`。周期执行不会推进游戏时间。不同周期订阅可独立取消，执行失败可通过订阅状态检查。

实时服务不需新增命令行开关，沿用 `--operator-session` 指定的当前安装会话。显式 `--province-interest-save` 仍选择独立的 [Jomini 历史快照来源](已发现省份快照接口.md)，不会注册这个实时读器；recorded 模式也不注册它。

## 实现与验证

独立配置 `province-discovery-memory-1374-v1.json` 固定原省份 v4 配置及新增布局/来源。25 段代码校验共 63675 B；实时采集使用既有只读句柄和严格保存重放，不调用游戏函数。原 G02 省份字段、v1 私有候选读器和历史解析器保持各自合同。

第128批生产配置首次实采逐项检查 4941 个正编号省份，两遍均取得 FRA 已发现的 1067 个省份；35296 次读取、488188 B，严格重放通过，句柄关闭。观察国 FRA 槽位 122、human_count=1、controller_type=0；物理客户端 POR，日期 raw56556984。随后实际 MCP 的 session 查询、FRA 查询、手动报告、2秒与5秒周期均返回同一列表；POR 视角拒绝，取消短周期后长周期仍有效，最终两条订阅取消、服务及读线程结束。

当前定向范围为 183 个唯一测试：首次 182 项通过，旧多进程测试因运行脚本未保护 Windows 子进程入口失败；修正运行脚本后仅重跑该项并通过。生产源码前后 pin 一致。MCP 收集没有业务错误；检查器对单来源包装及状态响应层次的误读仅通过保存响应离线修正，未重发成功查询。最近完整回归126尚未覆盖本批新代码。

原件：`work/runtime/information-live-discovery-20261103-128-001/`。位图布局与尚未闭合的范围见 [来源研究](../../04-实现研究/贸易与省份/实时已发现省份来源研究.md)。

独立审查另外保留共享离线重放器的一项限制：重放检查包内及会话数据的一致性，不单独认证任意被整体改写的 packet 来源。实时入口由采集器在同一句柄前后核对进程身份和模块基址，保存原件另由外部 SHA 固定；公共 C02 接口不接收用户提交的 capture packet。
