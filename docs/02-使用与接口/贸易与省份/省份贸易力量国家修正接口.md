# 省份贸易力量的国家修正

第203批为既有 `T06.targets` 候选页加入两个国家的当前比例修正。`controller` 是该省份的当前控制国，`observer` 是接口明确指定的非玩家法国（FRA）；二者可以不同。接口不会把物理玩家葡萄牙当作 LLM 观察国，也不会因国家控制了一个已发现省份就省略国家准入检查。

查询参数沿用[省份数值修正接口](省份贸易力量数值修正接口.md)。新增结果位于 `fields.targets.value.rows[].current_trade_power.country_modifiers`，例如：

```json
{
  "controller": {
    "status": "known",
    "value": {"country": "POR", "raw": 220, "scale": 1000, "unit": "ratio"},
    "basis": "native_country_province_trade_power_modifier_processor_absent",
    "period": "current", "partial": true, "complete": false
  },
  "observer": {
    "status": "known",
    "value": {"country": "FRA", "raw": 200, "scale": 1000, "unit": "ratio"},
    "basis": "native_country_province_trade_power_modifier_processor_absent",
    "period": "current", "partial": true, "complete": false
  }
}
```

`raw=220` 表示0.22，即22%的修正项，不是220点贸易力量。国家标签属于数值身份的一部分，即使两个国家恰好具有相同数字，也必须核对国家是否改变。零和负数保留，未验证的项返回未知。指针和读取轨迹只留在内部证据中。

这两个数值是完整收益分析的输入。当前省份贸易力量不会直接计作取得省份后的 FRA 收益；国家节点分配、换属后的修正重建和完整计算尚未完成，`acquisition_delta_evaluated=false`、`expected_benefit=unknown` 继续保留。

## 读取条件与复用

仅支持 EU4 1.37.4、EXE SHA-256 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。新 profile 为 `province-trade-power-country-memory-1374-v1.json`，SHA-256 `d9a4c87d17fead58d1aa74fa470648307400982b16ecab166e55ae998756ed0f`。它继承202的省份守卫，增加国家修正选择器 `[0x93d5c0,0x93d8a3)` 的739字节守卫；地址均为该版本的 RVA。旧 profile 保留。

国家数值复用共享 `modifier_storage.read_raw_modifier`，读取国家内嵌对象 `+0x28d0` 的索引17。每次读取都精确核对加载键 `global_prov_trade_power_modifier`，要求该索引的处理器为空，并在读取后复核管理器、键内容和处理器。非空处理器返回未知，不执行游戏函数。

选择器可能在国家修正计算过程中使用其它对象。因此本读取器仅接受 `+0x28c8` 状态为0或2且前后不变；这是保守支持范围，现有证据没有证明完整状态枚举。状态1或其它未支持状态均不交付数字。

组合器复用父采集保留的完整国家表，按 fullref 中的编号直接复核观察国和控制国的对应记录，不追加完整国家扫描。两国均核对国家视图准入，FRA 还核对非玩家角色。省份规范身份、发现、控制国引用和 FRA 自身准入在扩展读取前后再检查。父采集和扩展共用512 KiB额度；同一轮控制国也是 FRA 时复用该轮国家读数，不跨请求缓存。所有读取位于同一外层会话、日期和代码守卫检查之内，仍不声称原子快照。
