# 当前省份贸易力量重算

第204批在 `T06.targets` 的 `rows[].current_trade_power` 中新增 `calculation`。它根据同次采集的当前省份、控制国修正和计算条件重建原生缓存写入路径，再与当前缓存比较。查询参数沿用[数值修正接口](省份贸易力量数值修正接口.md)，控制国和观察国仍按[国家修正接口](省份贸易力量国家修正接口.md)分别处理。

```json
{
  "status": "known",
  "value": {"raw": 34104, "scale": 1000, "unit": "trade_power"},
  "basis": "native_province_trade_power_cache_writer_reconstruction",
  "period": "current",
  "partial": true,
  "complete": false,
  "argument_mode": "cache_writer_zero_additional_inputs",
  "native_function_invoked": false,
  "acquisition_delta_evaluated": false,
  "matches_cache": true

```

`value` 是重算值，原 `current_trade_power.value` 仍是直接读取的缓存。`matches_cache` 表示这两个当前数值是否相等；不同会保留重算结果并返回 `false`，不把缓存新鲜度视为已经验证。条件或输入未验证时仅将 `calculation` 标为未知，不补零。观察国角色或规范省份等共享身份发生变化时，整份采集撤回。

本接口未模拟取得省份后的效果。国家节点分配、换属后的修正重建和实际未来收入仍未完成，候选页的 `expected_benefit` 继续未知。

## 计算方式

计算依据为 B23 的 `[0xa20b10,0xa214b2)`，只复用已保留的有界静态反汇编。缓存写入包装 `[0xa214c0,0xa2150b)` 将三个额外数值输入和描述对象指针置零；当前重建仅适用于这条路径，不假定其它调用者也传零。地址均为 EU4 1.37.4、EXE SHA-256 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77` 的 RVA。

原生计算先将省份比例项、控制国比例项和附加比例项加到1000，再将相加结果乘以（1000＋进一步比例项）并除以1000，最后乘省份数值项并再次除以1000。所有比例项均以1000为尺。实现保留原生的32位回绕、64位乘法、向零截断除以1000，以及在商的低32位上进行的有符号夹限。不能用普通小数乘法或先对完整商夹限替代这些规则。

算术测试使用有符号乘法的高64位、常数 `0x20c49ba5e353f7cf`、算术右移7位及符号修正，独立对照生产实现的整数除法；包括固定边界和768组固定种子输入。浮点数、布尔值及超出有符号32位范围的输入会被拒绝。

## 条件与权限

以下条件在同一外层会话、日期和代码守卫检查内读取，并保持父采集及扩展合计512 KiB额度：

- 省份 `+0xe8` 指针为空，或其虚函数槽 `+0x40` 返回假时，原生结果为零。目前只被动识别常量真／假方法的三个指令字节，不调用虚函数；其它方法返回未知。
- 控制国 `+0x2440` 指向对象的 `+0x79` 字节为零时，原生结果为零。
- 省份 `+0x958` 按掩码 `0x04` 检查，置位时触发所有者关联检查。这是从零计数的第2位，历史合同中的“bit4”指掩码值4。它按 `+0x8a8` 容器的国家编号寻找首个条目；该条目 `+0x40` 非零时，读取全局 `+0x233f418` 的附加比例项。空列表或无匹配没有附加值。容器业务名称尚未确认，不能将 `+0x8a8` 称作贸易节点。

第三项需要时才解析所有者，并要求规范国家引用及国家视图准入。读取前后重新核对省份、发现条件、控制国／所有者引用和 FRA 非玩家角色。准入拒绝的分支同样进行后续共享身份复核；不会因本子项未知而跳过身份检查。
