# 省份核心与宣称实时接口

`NativeProvinceInterestsSource` 读取运行中 EU4 1.37.4 的省份核心与宣称成员，并通过 G01 提供查询、报告和周期订阅。逻辑观察方为非玩家 FRA；物理客户端保持 POR。两个字段都为 `partial`、`complete=false`、`period="current"`，不把成员列表解释成完整的核心类别、永久宣称或宣称到期信息。

启动服务时使用已有安装会话：

```powershell
python tools/serve_information.py `
  --database work/runtime/information-service/live-interests.sqlite3 `
  --operator-session work/runtime/diplomacy-observer-20261102-r76-static-straits-001/installation.json `
  --observer FRA
```

省份查询沿用原 G01 合同：

```json
{
  "request_id": "live-province-interests-example-001",
  "queries": [{
    "topic": "G01",
    "object": {"type": "province", "province_id": 186},
    "fields": ["cores", "claims"],
    "parameters": {}
  }]
}
```

已知字段返回按国家 tag 排序的列表，单位为 `country_tag`，`scale=1`。实时国家反向枚举尚未实现；原 `country` 对象仍保留，但相应字段返回 `unknown`、原因 `COUNTRY_REVERSE_ENUMERATION_NOT_IMPLEMENTED`，不会返回假空集，也不会触发省份采集。`permanent_claims`、`task_targets`、`strategic_targets` 仍为 planned，目录继续保留全部五字段。

## 读取与公开条件

采集器复用既有省份身份、国家完整引用和观察方守卫。两遍读取都必须确认 FRA 的国家表绑定、Human_count=1、FRA controller=0、自身身份准入，以及该省份对 FRA 的正向发现位。未发现省份保持 unknown，不向公开结果传出读取到的成员。前后会话、进程创建时间、安装身份或日期不一致时撤回结果。

核心使用省份 `+0x490`/`+0x498` 的完整国家引用序列；宣称使用 `+0x4C0` 链表头、节点 `+0` 的完整引用和 `+0x10` 的下一节点。每个引用都核对国家表位置、tag 和国家对象的完整引用回显。空序列或空链表在守卫通过时可返回已知空列表；坏指针、循环、重复成员、超过 256 个成员及两遍不一致保持 unknown。核心与宣称的局部读取错误分别处理，共同身份或发现守卫失败则共同撤回。

宣称节点 `+8` 的含义尚未建立，本接口不读取它，也不由它推断永久性或期限。新 profile 为 `bridge/information/profiles/province-interest-memory-1374-v1-r2.json`，SHA-256 为 `6745b391a1c35446d7ad81b0d9cd73d39513f27d4f5dfd8c52d79d1eb0f7e4f0`。它绑定 B23 EXE SHA-256 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`，沿用旧 v4 守卫并新增两段完整函数字节守卫。

新静态依据来自 cached REA：RVA `0xA26630` 的放弃核心条件，以及 RVA `0x1361020` 的宣称按钮条件。对应普通字节核对范围为 `[0xA26630,0xA267F3)` 和 `[0x1361020,0x1361246)`，共 1001 字节。这些依据支持成员结构及相关原生条件，不等于已观察原生 UI 绘制。RPM 采集完成后必须通过保存 trace 的严格重放，再投影公开字段；公开结果不含地址或原始内存。
