# 静态海峡连接只读接口

`G03.straits` 返回所选静态地图中与某省份相连的显式海上邻接记录。它回答的是“地图文件把哪些省份列在同一条 `Type=sea` 记录中”，不回答部队当前能否通行。该字段为 `partial`，结果的 `complete` 始终为 `false`。

## 查询

通过 `information_query` 查询 `G03` 的 `straits` 字段：

```json
{
  "request_id": "static-straits-001",
  "queries": [{
    "topic": "G03",
    "object": {"type": "province", "province_id": 333},
    "fields": ["straits"],
    "parameters": {}
  }]
}
```

`province_id` 必须是正整数，并且必须出现在所选地图的省份定义中。已知结果的字段形状如下：

```json
{
  "status": "known",
  "value": [{
    "from_province": 333,
    "to_province": 4559,
    "through_province": 1300,
    "source_lines": [2]
  }],
  "unit": "sea_connection",
  "scale": 1,
  "period": "static_rules",
  "basis": "effective_map_explicit_sea_adjacencies",
  "complete": false
}
```

记录保留 CSV 的 `From`、`To` 和原始行号。查询任一端点或 `Through` 省份时都会返回匹配的记录；端点顺序不表示单向通行。CSV 中 `Through=-1` 会表示为 `through_province: null`。实现按无序端点对去重，并合并相同记录的来源行号；`canal`、`lake`、`river` 与 `impassable` 记录不会作为海峡返回。

`country_pair` 可以通过请求形状校验，但当前适配器没有国家到省份集合的依据；该请求返回 `unknown`，原因是 `COUNTRY_PAIR_STRAITS_NOT_IMPLEMENTED`。G03 的 `bordering`、`distance`、`fort`、`island`、`land_connection`、`access` 和 `supply` 仍未由此适配器实现。

## 数据来源与状态

`StaticStraitsSource` 使用 `StraitDefinitionIndex` 读取已配置的 EU4 1.37.4 安装与启用模组层。它从选定层的 `map/default.map` 解析 `definitions` 和 `adjacencies` 路径，再读取相应 CSV；读取前限制文件大小，并记录配置文件及地图输入的指纹。查询期间输入变更、路径无效或版本不受支持时，字段返回 `unavailable`。有效文件中没有匹配记录时，返回空列表；省份不在地图定义中时，返回 `unknown`。实现分别见 [`straits.py`](../../../bridge/information/straits.py)、[`strait_definitions.py`](../../../bridge/information/strait_definitions.py) 和 [`strait_csv.py`](../../../bridge/information/strait_csv.py)。

CSV 使用分号分隔。B23 安装中的 `adjacencies.csv` 以 Windows-1252 解码；解析器先尝试带 BOM 的 UTF-8 或 UTF-8，再回退到 Windows-1252。解析器单独识别文件末尾的全 `-1` 哨兵行，只把 `Type=sea` 的普通记录放进结果。解析规则把 `Through=-1` 映射为 `null`；本次核对的 B23 普通记录没有 `Through=-1` 值。

这是一份从安装目录和启用配置解析出的静态地图数据。它没有检查当前游戏进程是否已加载相同地图，也没有读取存档或运行时省份控制权。因此，即使字段为 `known`，也不能据此断定连接当前可用。

## 范围与限制

- 结果不推断连接方向、移动权限、通行权、运河控制权、国家拥有权或实际可行军性。
- `Through` 只保留 CSV 中的数值；`-1` 转成 `null`，不会解释为“无阻挡”或“允许通行”。
- `country_pair` 仍为 `unknown`，因为本字段没有解析观察国或目标国拥有的省份集合。
- 目录声明 `query` 和 `periodic`。周期读取仍依赖现有服务中的就绪会话；静态源本身不推进日期，`poll_events` 也不产生事件。
- 当前字段固定为 `period="static_rules"`、`complete=false`。它描述选定文件中的规则，不是当前世界状态或完整地理关系。
