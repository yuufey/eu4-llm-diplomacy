# 战报退却接口

## 当前补充

第362批增加已验证原生全歼时的适用性判断。对有效 wire10 及后续记录，如果 RETR 明确未捕获退却状态，而既有全歼投影确认败方原生 overrun 标志为1，`B03.retreat` 返回以下结果。`combat_side_index` 对应全歼的败方。

```json
{
  "status": "not_applicable",
  "reason": "RETREAT_NOT_APPLICABLE_AFTER_NATIVE_OVERRUN",
  "basis": "native_combat_side_overrun_marker",
  "scope": "whole_combat_side",
  "combat_side_index": 1
}
```

判断复用双方完整参战引用、观察国参战、结果侧映射和胜负校验。只有原生全歼正例适用，剩余兵力为零不足以触发。已捕获的退却状态与全歼标志冲突时仍返回 `RETREAT_OVERRUN_CONFLICT`。wire1–9 缺少 RETR 的兼容行为继续返回未知。

新增来源标记为 `retreat_projection_version=2`。356批保存的法国富瓦战役已通过普通查询、事件订阅、去重和持久结果冷重开验证，使用历史记录离线回放，游戏操作为0。该记录的原生 Line1 和战争编号仍未知。详见[362批结果](../../../work/runtime/information-battle-core-20261110-362-001/retained-replay.json)。

## 既有退却正例与历史证据

`B03.retreat` 提供观察国自有军队或舰队对象的退却正例。当前支持普通战斗结束路径，字段为 `partial`、`complete=false`。观察国来自服务的可信上下文及采集绑定，查询参数不能改写观察国。

```json
{
  "topic": "B03",
  "object": {"type": "battle"},
  "fields": ["retreat"],
  "parameters": {
    "event_id": "battle-observation:5bf7578d15ec27e2:01dd6caf31db41bd:6"
  }
}
```

这个具体事件在第181批的 **LNA 历史记录上下文** 中返回已知正例：

```json
{
  "status": "known",
  "value": {
    "observer": "LNA",
    "combat_side_index": 0,
    "retreating": true,
    "observed_unit_count": 2,
    "count_is_lower_bound": true,
    "unit": "native_army_or_fleet_objects",
    "scope": "observer_owned_units_at_regular_battle_end",
    "identity_scope": "captured_operation_not_persistent_unit_id",
    "destinations": {
      "status": "unknown",
      "reason": "RETREAT_DESTINATION_NOT_CAPTURED",
      "partial": true,
      "complete": false
    },
    "arrival": {
      "status": "unknown",
      "reason": "RETREAT_ARRIVAL_NOT_CAPTURED",
      "partial": true,
      "complete": false
    }
  },
  "partial": true,
  "complete": false
}
```

数量按已核对的原生军队或舰队对象计，只给出本国观测下限，不换算人数、团数或舰船数。只有单位完整 owner 引用与观察国完整引用相同时才计入。同阵营其他国家的单位不计入；同一标签但不同代次的国家引用也不能替代。

第181批实际陆战序号6含三个退却单位对象，分属不同国家；LNA 接口只返回其自有的两个。海战序号5的 NHX 上下文也返回两个自有对象。两例均来自新采集的真实记录，已通过实际 MCP stdio 查询、报告、事件订阅交付、去重和取消。它们明确为 `recorded`，不授予 LNA 或 NHX 实时控制权限。

当前实时逻辑观察国为法国，物理玩家为葡萄牙。这批15条战报没有法国参战，法国查询上述事件返回 `BATTLE_RECORD_NOT_AVAILABLE_IN_OBSERVER_SCOPE`；没有把历史正例转换成法国可知信息。

已知结果要求同事件序号、日期、战斗类型、双方完整参战向量、结果侧映射及败方一致。单位状态三个已定位字节必须为 `0/1/1`；第四个字节保留在私有证据中，不赋予退却含义。已知的败方原生 overrun 标志为1时，退却投影返回冲突未知。

缺少 RETR 的旧 wire1–9 记录返回 `RETREAT_NOT_CAPTURED`。未观察到本国单位返回 `OWN_RETREAT_NOT_OBSERVED`；这些结果均不输出 `retreating=false` 或已知数量0。外国退却状态保持 `FOREIGN_RETREAT_VISIBILITY_UNVERIFIED`。

wire10 的公开来源使用 `projection_version=18`，哈希只计算观察国可见字段。完整私有载荷哈希用于接入校验，避免将外国单位字节变化透露给观察国。wire9 继续使用投影17，旧 wire1–8 继续使用投影16；新解码器保留旧载荷解码形状。

接口支持主动查询、报告和既有战斗事件订阅。事件 ID 标识采集记录，不保证对同一场战斗的所有来源去重。目的地、到达、持久单位身份、手动退却及其他结束路径仍未完成，完整战报正文也未因此完成。

实现依据见[退却采集研究](../../04-实现研究/战报/战报退却采集研究.md)。实际证据见 `work/runtime/information-battle-retreat-20261105-181-001/summary.json`；正确的历史绑定为 `recorded-LNA-battle-stream-002.json`、`recorded-NHX-battle-stream-002.json`，初版字节序错误文件仅保留作失败记录。
