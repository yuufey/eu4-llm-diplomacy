# 加载任务根中的实际子任务

实时 M01 `task_id` 现在直接读取国家任务根中的子任务对象。它沿用 `--mission-game-data`，没有新增服务启动参数；主动查询和周期报告共用这一来源。当前仍仅支持已经核对的 FRA 观察方与固定 1.37.4 EXE。

每个返回条目包含 `root_id`、`task_id` 和 `branch_visibility="unknown"`，字段另有 `membership_source="captured_loaded_task_objects"`。子任务存在于加载根中，不代表该任务当前显示或能够完成。本接口没有调用游戏函数、执行奖励或推进日期。

## 与当前文件定义的关系

任务 ID 来自实时子任务向量，前置和奖励规则仍来自当前有效文件。两者按根 ID 和任务 ID 对应；结果的 `task_definition_comparison` 分别列出“实时任务没有当前定义”和“当前定义没有加载任务”的条目，不能用文件中的额外任务补齐原生列表。

实时任务 ID 不依赖当前定义读取成功。定义文件缺失或采集期间变化时，已经确认的原生任务 ID 和完成记录仍可返回；对应规则则给出缺项或过期。按 `task_id` 筛选时，必须先确认该 ID 在实际捕获列表中；静态文件里存在同名任务不能替代这项检查。

任务读取失败、两遍子任务内容不同或任务专属守卫不匹配时，任务 ID 保持未知，已独立确认的根和完成记录保留。基础身份、原根守卫、根双遍比较或句柄关闭失败仍拒绝整份原生快照。指定存档的来源继续使用当前静态文件对应保存根，provenance 标为 `current_definitions_for_captured_roots`；存档没有提供原生子任务对象证明。

## 原生读取合同

EXE SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`，静态基址 `0x140000000`。下列代码和虚表地址均为 RVA，运行时地址使用当前模块基址。

| 对象 | 已核对的布局与检查 |
| --- | --- |
| 根 | 虚表 `0x1cc2048`，`+0x20` 指向解析器 `0x8d7430`；任务指针向量为根 `+0x128`，capacity/count 为 `+0x130/+0x134` |
| 子任务 | 虚表 `0x1cc2008`，`+0x20` 指向解析器 `0x8d5070`；任务 ID 为对象 `+0x10` 的 String32 |
| 文件与内存 | 两个解析器的代码字节和两张虚表均须匹配；磁盘虚表保留静态 VA，运行时表项按当前基址与期望 RVA 比较 |

根解析器的既有 REA Evidence 为 `ev_a1e99d7ae4552bc25a825fa26cc0b9dc269149403bf5fa46cdd2eadb5a888068`。有界普通文件字节、已保存根头 RPM 与这份静态 Evidence 分别列为来源，机器 SHA 保存在 `bridge/information/profiles/mission-task-memory-1374.json`，该配置 SHA 为 `3f855893f34a2203c4f77f885e2d68ebcf4e4d76ca33d8eea3ba9a6e9c648fd6`。生产读取不要求本机研究目录存在。

`mission_memory.capture(..., include_tasks=False)` 的默认路径不额外导入任务模块或读取任务字段；命令行研究入口另有 `--include-tasks`。信息服务的实时任务来源显式启用该项，因此根、完成列表与子任务在同一次双遍采集中核对。所有读取共用每次512 KiB的总 RPM 上限；每个根及全体最多4096项，单项字符串和每次读取仍有单独上限。对象指针、容量、数量、任务 ID、顺序和虚表参与两遍比较。它仍不是主线程原子快照，也没有证明世界代际。

## 实际验收

[真实 MCP 验收](../../../work/runtime/information-loaded-tasks-20261024-001/live-acceptance-001/report.json)将主动结果逐项与独立 RPM 列表比较，再核对单任务筛选和两次2秒现实周期交付。前后仍为同会话、POR玩家/FRA观察方，暂停1455.11.13/raw56553384；没有重新安装、业务派发、保存或推进日期。

原始观察已保存为 `bridge/tests/fixtures/information_loaded_tasks_live_1374.json`；离线测试使用时是 recorded 历史证据。测试还覆盖当前文件与实时列表不一致、空向量、任务守卫失败、子任务双遍变化及清理失败。复核前版本保存在本批 `task-source-before-review-001/`，没有覆盖成成功记录。
