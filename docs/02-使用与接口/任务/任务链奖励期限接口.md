# 任务链奖励期限接口

`M05.reward_timing` 提供指定任务奖励中声明的期限，供任务链分析使用。它复用 `M04.duration` 的 CWTools 解析和命令专属单位规则，不计算实际奖励到期日。

实时模式要求目标为逻辑观察国，并同时指定任务根与任务 ID。接口核对任务确实属于该国当前加载的任务；只在游戏或 MOD 配置中找到同名任务，不足以返回当前任务的期限。保存快照模式沿用上游来源的保存时点和身份标识，不代表当前对局。

任务身份由实时来源确认，奖励声明来自当前有效的磁盘配置；两者关联不代表已证明这些规则与引擎启动时加载的版本完全相同。

查询示例：

```json
{
  "topic": "M05",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["reward_timing"],
  "parameters": {
    "root_id": "french_missions_1",
    "task_id": "fra_burg_succession"
  }
}
```

服务器启用 `--mission-game-data` 时会注册此接口。当前默认 M05 实时模式支持查询、报告和周期订阅；旧来源继承的变化订阅声明没有对应的 partial 比较接口，第189批已撤回该声明。具体能力以 `information_discover` 为准。保存快照模式只支持查询。

已知结果的 `value` 包含：

| 字段 | 含义 |
|---|---|
| `candidate` | 本次指定的国家、任务根和任务 ID；不代表已验证方案可行 |
| `declared_timing` | 原有 `M04.duration` 投影，保留命令、期限参数、单位、来源及未知子项 |
| `conditions_evaluated` / `effects_executed` | 均为 `false`，没有求值奖励条件或执行效果 |
| `candidate_feasibility` | `unknown`，尚未证明候选方案可行 |
| `applied` / `start_time` / `expiry_time` | 均为 `unknown`，未证明奖励生效及实际起止日期 |

结果始终 `complete=false`。没有识别到期限不等于“没有期限”，会保留未知；未加载任务、任务标识不匹配、定义变化等情况也不会生成替代值。来源信息保留任务读取、定义文件、CWTools 规则和原期限投影的证据。

`M05.linked_targets` 和 `basis` 已接入[任务链关联目标接口](任务链关联目标接口.md)，可与本字段使用同一任务选择参数。它们支持查询、报告和周期订阅；混合订阅应遵循各字段共同支持的触发方式。第189批新增[候选成本接口](任务链候选成本接口.md)，需要额外提供显式候选方案，完整扩张方案分析仍需继续开发。

当前服务对M05混合查询共用一次任务状态采集，退出本次读取后清理，不跨请求缓存。规则查询跳过未使用的完整条件触发树，保留原生前置及其完成状态；M02完整条件查询保持原路径。第180批单次混合查询约4.93秒，公开字段与完整读取逐项相同；配置周期仍不保证同等交付延迟。
