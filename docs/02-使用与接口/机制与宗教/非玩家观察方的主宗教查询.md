# 非玩家观察方的主宗教查询

`S02.faith` 读取目标国家当前主宗教的名称缓存及图标帧请求。逻辑观察方为非玩家法国 `FRA`；目标既可以是法国，也可以是其他国家。实际客户端玩家与观察方分别绑定，不需要切换玩家国家。

```json
{
  "topic": "S02",
  "object": {"type": "country", "country": "ENG"},
  "fields": ["faith"],
  "parameters": {}
}
```

该查询可以直接执行，也可以放入报告并按既有周期订阅机制交付。把 `country` 改为 `FRA` 即可查询观察方本国。

## 字段含义

成功值的结构为：

```json
{
  "primary_religion_name": {
    "text": "天主教",
    "raw_hex": "10295911494e105965",
    "encoding": "eu4_escape"
  },
  "icon_frame_request": 1
}
```

`primary_religion_name` 是主宗教对象中的名称缓存，保留原始编码，并用项目已有的 EU4 escape 解码器严格解码。它不是宗教配置键或数值 ID。`icon_frame_request` 是原生图标控件收到的整数输入，不能据此声称画面上已显示某个图标。

字段标记为 `partial=true`，字段和结果均为 `complete=false`。完整提示、宗教组、第二宗教、教廷和宗教学派等仍需各自的来源。未知、不可见和真实数值分别保留；未知或不可见结果不附名称值。

## 来源及可见条件

固定 EU4 1.37.4 的国家查看页从所选国家的完整引用取得国家对象，再读取 `+0xf30` 的主宗教定义；该定义的 `+0xb0` 是被文字复制 helper 使用的 String32，`+0x570` 是图标帧输入。原生代码的静态证据与实际读取分别归档。

父读取器核对进程、创建时间、安装会话、EXE、代码字节和日期，单独核对法国控制器为非玩家。国家查看条件按法国绑定重索引，再读取获得准入的目标。该条件是观察方投影，不是实际打开外交界面或执行当前客户端的原生条件。

两遍读取比较完整目标绑定、准入操作数和字段原始输入。有序原始读取记录会在公开交付前离线重建；失败读取只保留其错误，不伪造字节。字段值变化撤回该字段，共享国家绑定或准入变化撤回整个采样。所有只读进程句柄在交付前关闭。

## 首轮实采纠正

首轮曾把 `+0xb0` 暂按配置键解释；实际读取取得九字节 EU4 escape 中文名称，原有 ASCII 校验因此返回未知，没有向公共接口发布错误键值。保留原 profile、两份原始采样和失败收据，修正后使用单独的 v2 profile，返回名称及编码，不把配置文件中的键名补成实采结果。

本接口不能证明非玩家国家普遍具有或缺少某类原生消息。战报仍须按实际的战斗数据、消息分派、窗口和文字路径分别确认。
