## 读取与证据

固定游戏 EXE SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。下列地址均为 RVA，运行时地址需要加当前模块基址。

接受的 cached REA `0xbfcf80`，Evidence `ev_e0a97d5d4dc5a59d296a5dc2ec481aa8e21aeb84582f86a4c3e3b0aa26c6c706`，确认以下原生路径：

1. 国家 `+0xf30` 指向当前主宗教对象。
2. 宗教 `+0x70` 的整数 ID 减一后，按十六进制 `0x50`（十进制 80）字节的步长定位记录。
3. 世界指针位于全局 RVA `0x233fe58`，世界 `+0x25a8` 指向运行时宗教管理器，管理器 `+0x30` 保存记录基址。
4. 记录 `+0x34` 保存守护者国家的八字节引用。原生条件只比较引用中的国家槽位。

普通 PE 反汇编 `[0x5c1d30,0x5c1df3)` 另行确认：记录 `+0x10` 的宗教对象用于与国家 `+0xf30` 比较。这是普通静态证据，不能标为 REA 或运行结果。

读取器要求记录的宗教对象与查询国家当前主宗教完全相同，并通过国家数据库验证守护者的完整引用，包括槽位之外的其他位。所有依赖指针、记录内容和国家引用在读取前后重新比较，父级再执行两遍采集和严格重放。公开结果不包含内存地址或私有原始记录。

宗教 ID 限于软件规定的 `1..4096`，地址运算检查溢出，读取受字节数和调用次数限制。这个上限不代表已经证明管理器实际有 4096 条记录；管理器 `+0x38/+0x3c` 的容量、计数语义尚未确认，不据此宣称数组大小。实际读取失败或记录身份不符时返回未知。也不调用原生虚函数或跟随无效宗教的回退记录。
