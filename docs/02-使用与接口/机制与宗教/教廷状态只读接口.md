# 教廷状态只读接口

`S02.papacy` 支持已准入国家的查询、报告和周期订阅。逻辑观察方为非玩家 FRA，查询对象与物理玩家身份分别处理。第170批已验证 FRA、ENG、PAP 和 TUR；字段仍为 `partial`，枢机、选举投入、年度影响力变化与完整说明文字尚未接入。

```json
{"topic":"S02","object":{"type":"country","country":"FRA"},"fields":["papacy"],"parameters":{}}
```

## 返回值

`value` 包含 `uses_papacy`、`papal_influence`、`curia_treasury` 和 `controller`。前者表示当前主宗教是否具有原生教廷定义指针；它不表示已经执行 `papacy_active`、`uses_papacy` 等脚本条件，也不判断某项教廷行动的资格。

影响力和金库采用现有定点数约定：`value` 与 `raw` 都是原生有符号整数，以 `scale` 指定单位。法国影响力的核心数据为：

```json
{"status":"known","value":48666,"raw":48666,"raw_hex":"1abe0000","unit":"papal_influence","scale":1000}
```

即 `48666 / 1000 = 48.666`。实际对象还包含 `period: current`、`partial: true`、`complete: false`、`basis` 和 `value_origin`；这些元数据也经过校验。金库的单位为 `ducats`，当前原始值2288989对应2288.989杜卡特。不会按配置中的通常范围钳制或丢弃负数。

控制者结构为：

```json
{"status":"known","country":"PAP","is_target_controller":false}
```

`is_target_controller` 比较查询国家与已经验证的控制者完整引用；查询PAP时为 `true`。无效、悬空或世代不符的控制者引用返回 `{"status":"unknown","reason":"PAPACY_CONTROLLER_UNRESOLVED"}`，不解释为没有控制者。

TUR当前没有教廷定义指针，`uses_papacy` 为 `false`，另外三个组件均返回 `{"status":"not_applicable","reason":"PAPACY_NOT_USED"}`，不读取或发布该国复用资源槽中的数值。未知、明确不适用和真实的零值分别保留。

## 来源与复用

固定EXE SHA-256为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。以下地址均为RVA，运行时需要加实际模块基址。

- 国家 `+0xf30` 指向主宗教；宗教 `+0x578` 指向教廷定义，空指针是原生界面的不适用分支。
- 定义 `+0x60` 才是所属 `CReligion`，不能把定义自身当作宗教对象。原有完整83字节 getter `0xa47c20` 先读取该指针，再取所属宗教 `+0x70` 的ID。
- 全局 `0x233fe58` 指向世界，世界 `+0x25a8` 指向管理器，管理器 `+0x30` 为记录基址。按 `(ID-1)*0x50` 定位，记录 `+0x10` 必须等于所属宗教，记录 `+0x40` 指向教廷状态。
- 影响力为国家 `+0xf50` 的四字节有符号定点数；控制者为状态 `+0x24` 的完整国家引用；金库为状态 `+0x100` 的四字节有符号定点数。控制者另经国家数据库、槽位及国家 `+0x20` 验证，不能只比较槽位。

接受的cached REA分别为：影响力tooltip `0x361e40`（`ev_2afcef0732559c52c0d3300ccd0ab485fd568de606b633043c320d2a1c67087b`）、控制者predicate `0xc88c90`（`ev_e676dcc70019377fdd1a645059af34d7c4be6130774f15d0f9d054193ddd154c`）、金库predicate `0xd22fb0`（`ev_ec312d655a666120556139290de672a9a6e5ee51e31695d6705208593ab2b96e`）。

数值单位复用已有type7包装器 `0x244db0` 及千分格式器 `0x1703780` 的接受证据（`ev_5b4e35b648d04e9ce6b39adfade26190edb0c3f9a0c49efa5d5078c5ed82833d`、`ev_9210ee8c7b5403b4e38c2b1b5b3b93c467e10d0aaa69062507f32e4919f427c7`），没有重查它们。原有国家绑定、准入、只读句柄、两遍采集与严格重放框架继续复用。CWTools和已保存配置AST仅提供静态声明；当前数值取自运行时。
