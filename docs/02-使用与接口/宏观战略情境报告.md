# 宏观战略情境报告

本页提供[任务、贸易和具体宣战方案配置](宏观战略任务与贸易情境配置.json)，与[宏观基础报告](宏观战略报告.md)配合使用。基础报告承担国家概况，情境报告围绕已选目标展开，分别使用已有报告保存、查询和订阅接口。

该配置使用[简报呈现](信息简报与完整结果.md)，保留任务规则、业务值及未知状态，并附完整采集记录的读取入口。

293批将M02既有`root_id`与`task_id`选择器传到动态采集层，先确认载入任务和前置绑定，再读取匹配任务的触发树。两轮选择器和状态必须一致，同次缓存不跨请求复用。无选择器时按原合同处理完整任务集合。

在同一1445.4.21暂停现场，读取“解放诺曼底”的`currently_completable`和`condition_progress`从29.86秒降至4.39秒，减少约85%。每轮动态任务61→1，省份97→4，两轮国家表解析388→16，两项完整业务字段逐字段相等。108个相关测试节点通过。

上述时间对应服务已初始化后的查询。带静态与任务数据的冷启动在这两次实测中仍约33–37秒，包括任务定义构建和CWTools解析。下方旧批次耗时保留当时的含义。[优化收据](../../work/runtime/information-mission-query-selection-20261108-293-001/summary.json)

## 当前条件与奖励的解释

报告中的M02增加`currently_completable`与`condition_progress`，沿用现有读取和投影。前者回答当前能否完成任务，后者提供未满足的条件及相关国家、省份。本例要求诺曼底地区全部省份满足`country_or_non_sovereign_subject_holds=ROOT`，当前四项均为false，因而任务当前不可完成。

M04的宣称规则描述完成任务后、相应限制满足时请求添加的永久宣称。条件化规则可以用于判断扩张方向，`applied=unknown`表示来源未观察奖励执行。任务当前尚未完成，报告分别提供当前条件和奖励声明。

接口的`complete=false`仍涵盖分支可见性等解释边界。对于本次所选任务，根条件已知为false，未知叶节点为0，具体结果可直接读取，保留来源的完整性标记。

## 任务宣称简报

272批为简报增加`presentation.mission_claim_summaries`。它把本次所选M04宣称声明与同一报告中的M01名称、M02可完成性关联，要求国家、日期、任务根与任务编号，以及来源模式、会话和观察方元数据一致。缺少或冲突的名称和状态保留unknown，声明本身仍可读取。

每条宣称保留命令、接收方表达式、声明作用域键及其条件上下文在完整结果中的路径。`applicability`与`applied`继续为unknown，任务当前可完成性分别列出。简报最多呈现64个任务、每任务128条规则，省略数量随结果返回。该层只处理本次已选字段，原字段和完整持久结果继续沿既有入口读取。

当前29892会话通过正常工具取得一份18.25秒的查询结果，正文显示“解放诺曼底。任务当前不可完成”，并列出`brittany_area`、`bourgogne_area`、`west_burgundy_area`三条条件化永久宣称声明。正常保存、完整结果读取和服务重开后的简报一致。奖励逐省适用性和实际执行仍缺少求值来源。[272批结果](../../work/runtime/information-mission-claims-brief-20261108-272-001/live-data-final-001/mission-claim-summary.txt)

## 奖励地区限制的当前判断

274批在`declared_area_candidates.current_limit_evaluation`中提供当前满足、不满足及未知的省份集合。判断使用已保留的地区`limit`脚本，支持ROOT对应的`is_core`、`owned_by`和`country_or_non_sovereign_subject_holds`，以及AND、OR和单子项NOT。其它脚本结构继续返回明确未知原因。

读取复用已有核心成员、规范国家引用与持有者来源，非主权属国条件复用固定版本的原生判断。两个原有来源配置按精确摘要加载，相关原生字节在文件与内存中核对。每个省份沿FRA非玩家身份与正向发现条件准入，两次输入读取一致后按原始读取轨迹回放。完整结果保留输入布尔值、配置摘要和当次日期，简报列出三个省份集合及原结果路径。

当前实机FRA查询中，上一节11个候选省份全部满足三条地区限制，未知0项。正常报告查询耗时32.89秒，完整结果和简报一致。本次只选M04，M01名称与M02可完成性由联合报告按已有合同关联。当前判断描述1457年5月17日的状态，任务完成时需要重新读取，实际奖励执行仍未知。原字面奖励声明的求值标记继续描述原声明层，新增当前判断单独列出。

每次最多采集64个不同省份，每条限制最多8层、64个节点，当前判断总输出预算512 KiB。超出范围、视角或日期不符、配置变化、未发现与读取失败各自保留未知。多个省份由独立只读采集取得，`snapshot_atomic_main_thread=false`明确其采集方式。[274批收据](../../work/runtime/information-mission-reward-limits-20261108-274-001/summary.json)

## 启动与使用

实时来源的启动参数需同时启用`--static-game-data`和`--mission-game-data`，并绑定当前安装记录、FRA观察方和所用数据库。路径配置沿[接口使用说明](信息接口使用说明.md)。

```powershell
python tools/serve_information.py `
  --database work/runtime/information-service/information.sqlite3 `
  --operator-session 'work/runtime/<installation>/installation.json' `
  --observer FRA --static-game-data --mission-game-data
```

当前实验场景的信息服务使用[279批实际安装记录](../../work/runtime/diplomacy-observer-20261108-independent-line-v42-278-003/installation.json)，将其路径传给`--operator-session`。该记录显式选择`eu4_escape`，绑定42880会话，逻辑FRA、物理POR，当前1445.3.12暂停。279批财政准备样本采于Feb5，FRA贷款0、本金0，ENG贷款本金0.0ducats。272–274批的任务、贸易和奖励报告保留各自当时的日期、会话与结果，实际查询按当前配置重新取得数据。272批的中文编码选择经过独立配置核对，记录继续用于追溯。[编码配置记录](../../work/runtime/information-mission-claims-brief-20261108-272-001/codec-configuration.json)

调用`information_manage_report`，将配置文件内容作为`config`，通过`create`保存。随后用返回的`report_id`调用`information_query`。更换任务、节点或行动方案时，以当前`expected_version`更新报告。订阅时沿用现有周期合同，周期根据实际决策频率设置。

只需读取某个部分时，可将对应查询单独交给`information_query`。任务清单与仅含完成状态、前置的查询使用已有轻量采集。配置中的M02包含动态字段，使用原条件采集路径，本次两项动态字段实读耗时约32.1秒。

## 具体宣战方案参数

D01–D06的`parameters.selection`声明与既有外交预览合同一致。`casus_belli`、`war_goal`及`call_allies`为必填项，另可提供`promise_land_to`和`co_belligerents`。

```json
{
  "topic": "D02",
  "object": {"type": "country_pair", "actor": "FRA", "recipient": "ENG"},
  "fields": ["legality_status", "legality_reasons", "stability_cost", "war_exhaustion_cost"],
  "parameters": {
    "action_id": "declare_war",
    "selection": {
      "casus_belli": "no_casus_belli",
      "war_goal": {"province_id": -1, "beneficiary": "FRA"},
      "call_allies": []
    }
  }
}
```

读取入口为`information_query`，内部复用`inspect_diplomatic_action`。参与方重复、承诺对象未被召集、主参战方混入盟友或混用多份选择上下文，会在保存报告或读取前校验。

稳定度和厌战字段从已匹配方案的原生成本条目投影，返回实际单位数值及`scale=1`。对应条目缺失、单位未核对、存在歧义或仍是默认未选方案时，保留unknown。旧有直接成本字段的读取合同继续适用。
