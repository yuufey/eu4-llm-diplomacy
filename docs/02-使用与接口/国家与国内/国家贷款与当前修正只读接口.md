# 国家贷款与当前修正只读接口

## 宏观贷款摘要
2026-11-07新增N01的`loan_summary`，复用同一次经验证的贷款记录读取，返回贷款数量、本金总额和未知本金记录数。总额按ducats、scale为1提供，存在未知或非标准本金时保留unknown和已知小计。该字段用于宏观财政负担判断，原`loans`明细接口继续提供已有结果。

本次暂停实采取得4笔贷款、本金合计521ducats。摘要及原明细的兼容检查、空列表和不完整本金检查已通过，见[宏观报告与收据](../宏观战略报告.md)。

## 早期接口记录

2026-10-27 第五十二批：本页8字段已通过真实MCP查询、报告及三条两秒周期交付，取消后无活动订阅，服务退出码0。完整回归为2873项通过、106项失败、35项错误，另1894个子测试通过；较51批新增失败节点0、解决0，全套仍非全绿。新增36个用例均通过，已包含在完整统计中。

本页记录批52已经闭合的原生读取合同。当前范围是 EU4 `1.37.4`、观察方和对象均为
`FRA` 的 `country`；八个字段是 N01 的 `loans`，N07 的 `modifier_id`、`target`、
`effects`，以及 N08 的 `modifier_start_date`、`modifier_end_date`、`remaining_days`、
`duration_type`。这些字段的结果都使用 `coverage="partial"` 和 `complete=false`。

独立原始采样已经确认了数据形状，但本页在公开 MCP 实测前不写“已验收”、周期交付数量或

## 字段和单位

### 修正新增的即时通知

316批将315的原生新增记录接入C04的 `country_modifier_added` 事件，正式v45已实际安装。来源只有在安装回执明确提供对应能力、wire1、FRA范围且EXE为已支持的B23时才进入发现结果。315的显式v44原型记录沿同一读取合同兼容。

事件载荷保存当时的 `country`、`modifier_id`、`change="added"`、`start_date_raw`、`end_date_raw`、`flags_raw` 和 `scope`。发生日期采用插入函数正常返回时的原生日期，收集日期独立保留。日期和flag保持原始值，默认哨兵也保留。事件描述一个新增记录，完整性限于这份记录。

该来源覆盖法国直接临时国家修正的已确认创建调用方。移除、到期原因、其它修正来源和最终有效属性仍待接入。N07/N08继续提供当前清单查询。C04这类事件的历史内容可通过已交付的 `result_id` 完整读取，持久重放沿用已保存快照。

先用 `information_manage_report` 创建报告。

```json
{
  "request_id": "modifier-report-001",
  "operation": "create",
  "config": {
    "name": "本国临时修正新增",
    "detail": "full",
    "queries": [{
      "topic": "C04",
      "object": {"type": "session"},
      "fields": ["event_id", "event_type", "event_date", "event_objects", "event_payload", "complete"],
      "parameters": {"event_type": "country_modifier_added"}
    }]
  }
}
```

再用 `information_manage_subscription` 创建事件订阅，将 `report_id` 填为上一步返回的编号。

```json
{
  "request_id": "modifier-subscribe-001",
  "operation": "create",
  "config": {
    "name": "本国修正新增通知",
    "kind": "event",
    "report_id": "上一步返回的报告编号",
    "enabled": true,
    "event": {"types": ["country_modifier_added"]}
  }
}
```

宿主的定时tick或主动 `information_tick` 消费事件。国家视角由观察方绑定，`actors`、`recipients` 过滤不适用于该类型。取消继续使用既有订阅编号和 `expected_version` 合同。

读取与入站外交通知共用一个日志字节游标和锁，每轮沿用原有8MiB读取上限。缓存最多保留1024份记录，落后于缓存保留范围的消费者会收到缺口。序号冲突、跳号、原生丢弃、日志截断、无效行和运输故障也会保留缺口，已知的单条记录仍可交付，批次完整性同时反映缺口。顺序按该原生来源的序号表达。

37项新增定向测试覆盖普通工具订阅、去重、取消、完整读取、持久重开和过去日期快照重放。315独立原生夹具的64条记录及一条丢弃通知也经解码验证。v45已部署，1467.11.5至12.10的新35日窗口中源保持健康、无丢弃和运输故障，但新增修正记录为0条，实际新增回调及C04实机交付正例继续缺少。[316收据](../../../work/runtime/information-modifier-events-20261109-316-001/summary.json)

### 修正移除通知

317批增加 `country_modifier_removed`。C04报告查询的 `parameters.event_type` 和事件订阅的 `event.types` 可使用该名称，字段沿用上一节。通知的 `event_payload.change` 为 `removed`，包含删除前复制的修正标识、原始起止日期和flags。`event_date` 使用原生删除返回时的日期，持久重放读取已存快照。

该能力要求受支持的v46、v47或v48安装回执明确提供 `native_country_modifier_remove_observation=true`、`native_country_modifier_remove_wire=1` 及原新增合同。新增与移除共用日志游标、连续序号、缓存和缺口报告。C04目录增加 `native_country_modifier_removal`，其中 `capture_available` 表示当前来源是否可用，`expiry_available` 表示该安装是否还通过了独立到期能力的准入。

318批已部署正式v46，F03 r15与安装/控制准入完成。实际C04发现新增/移除两类事件，订阅创建、调度及取消通过，源健康且无丢弃。当前12月10日暂停现场记录0条，实际修正变化回调及完整通知交付正例仍缺少。来源只接受已定位的条件筛选删除和国教变更清理调用点，自然到期来源继续缺少。[318收据](../../../work/runtime/information-modifier-deployment-20261109-318-001/summary.json)

### 自然到期通知

319批增加 `country_modifier_expired` 候选。来源读取原生日期筛选的闭包上下文，并在随后实际删除成功后生成通知。其 `event_payload.change` 为 `expired`，`event_date` 使用原生删除返回时的日期，内容来自删除前快照。解码和持久重放会拒绝截止日仍在未来的到期记录。

该类型要求v47或v48安装回执明确提供 `native_country_modifier_expiry_observation=true`、`native_country_modifier_expiry_wire=1` 及原新增、移除合同。启用到期能力后，每次自然到期交付一条独立的 `country_modifier_expired`。覆盖全部失效的事件订阅应同时列出 `country_modifier_removed` 和 `country_modifier_expired`。新增、移除和到期共用序号、日志游标、缓存及缺口报告。到期上下文不可读时，来源保留通用移除记录并报告采集缺口。

v47正式准入和F03已在320批完成，322的正式v48继续继承这组能力。离线C04交付和真实生产汇编入口ABI检查通过，实际游戏新增、移除与到期回调正例仍缺少。当前启动因图形设备错误未就绪，v48尚未安装，具体现场沿HANDOFF顶部。[322收据](../../../work/runtime/information-rival-delivery-20261109-322-001/summary.json)

### 当前清单

| 主题 | 字段 | `unit` | `scale` | 结果含义和边界 |
| --- | --- | --- | --- | --- |
| N01 | `loans` | `loan_records` | `1` | 按原生顺序返回本国贷款记录集合；每条记录另含本金、利率、到期原始值和 lender fullref。 |
| N07 | `modifier_id` | `identifier_collection` | `1` | 当前国家直接修正实例的原生稳定键，保留链表顺序。 |
| N07 | `target` | `object_collection` | `1` | 每个直接实例的当前 country 目标；不推断省份、理念或其他来源。 |
| N07 | `effects` | `modifier_effect_records` | `1` | 定义中的 `index`、`selector`、`raw` 和 `raw_hex`；每个 effect 的 `scale=1000`，业务单位仍为 `unknown`。 |
| N08 | `modifier_start_date` | `game_date_raw` | `1` | 实例开始日期原始值；默认哨兵值返回行级 `unknown`。 |
| N08 | `modifier_end_date` | `game_date_raw` | `1` | 实例到期原始值；尚未把它解释成日历日期。 |
| N08 | `remaining_days` | `days` | `24` | 原生到期值减当前游戏日期的原始差值；按 `raw / 24` 解释天数。 |
| N08 | `duration_type` | `state_collection` | `1` | 已观察到的 `fixed_term` 或其他可证明状态；不代替移除条件。 |

所有八个字段的 `period` 都是 `current`。N01 使用
`basis="native_country_loan_records"`、`value_origin="copied_native_country_loan_records"`；
N07 使用 `basis="native_direct_country_modifier_records"`、
`value_origin="copied_native_country_records"`；N08 使用同一 basis，
`value_origin="derived_from_copied_native_modifier_dates"`。公开结果还会保留
`raw`、`raw_hex`（适用时）和每个字段的 `gaps`，不会把这些当前快照写成完整业务模型。

N01 的 `loans` 是 `NativeCountryRecordsSource` 复制的原生贷款链表。独立参考中 FRA 有三
条记录，本金依次为 `128`、`131`、`131` ducats；三条记录的利率原始值均为 `2000`，按
`scale=1000` 为 `2.0%`。到期字段保留 `engine_date_raw`，例如当前三条原始值为
`56590344`、`56593392`、`56598528`，不把它们换算成日历日期。lender 的原始 fullref
仍保留在每一行；当前样本的 `2d2d2d0000000000` 没有已证明的银行或外国国家映射，返回
`status="unknown"`，不会猜 lender 名称。

N07 的两条当前直接修正按原生顺序为 `papal_sanction_for_church_taxes`、
`shady_people`。`target` 的行分别绑定 `FRA`。effect 的原始 pair 也不合并成最终属性：
前者为 `(index=26, selector=10372, raw=150)` 和 `(6, 10327, -100)`，后者为
`(100, 10591, 200)`；这些 raw 值的 `scale=1000` 已闭合，但每一项的业务单位、激活
条件和最终属性仍为 `unknown`。`effects` 不是 N09 的最终效果，当前没有公开 `name`、
`description` 或最终属性字段。

N08 对每个实例分别保存日期状态。当前两条的开始日期是默认哨兵，故行级状态为
`unknown`；结束原始值分别为 `56685912` 和 `56631240`。相对当前日期的差值分别为
`128184` 和 `73512`，所以按 `scale=24` 为约 `5341` 和 `3063` 天；`duration_type`
当前为 `fixed_term`。开始/结束日期的 epoch、默认开始哨兵的业务含义、移除条件和完整
生命周期都没有从 raw 值推导。

字段级 `status="known"` 只表示集合和原始槽位已经读到；集合内某一行仍可以是
`unknown` 或 `not_applicable`。例如 lender 映射和默认开始日期不会抹掉同一请求中其他
已知字段。任何上下文、代码守卫、链表边界或双遍比较失败都会返回 `unknown` 或
`unavailable`，不会回退旧结果或用默认值填充。

## 两种主动查询

只查询贷款：

```json
{
  "request_id": "country-records-loans-query-001",
  "queries": [
    {
      "topic": "N01",
      "object": {"type": "country", "country": "FRA"},
      "fields": ["loans"],
      "parameters": {}
    }
  ]
}
```

同时查询当前修正和期限：

```json
{
  "request_id": "country-records-modifiers-query-001",
  "queries": [
    {
      "topic": "N07",
      "object": {"type": "country", "country": "FRA"},
      "fields": ["modifier_id", "target", "effects"],
      "parameters": {}
    },
    {
      "topic": "N08",
      "object": {"type": "country", "country": "FRA"},
      "fields": ["modifier_start_date", "modifier_end_date", "remaining_days", "duration_type"],
      "parameters": {}
    }
  ]
}
```

这两个请求的对象参数必须是 `FRA` country，参数对象保持 `{}`。N01 的
`reference_recipient` 只在需要财政参考对象的混合查询时按服务契约填写；它不改变贷款
记录的 lender 映射。贷款和修正均支持主动 `query` 与 `periodic`，不声明 `event` 或
`change`。

## 报告和周期订阅

报告配置沿用 `information_manage_report`。可以把上面的三个查询对象放进一个报告，服务
返回 `report_id` 后用 `information_query` 引用它：

```json
{
  "request_id": "country-records-report-create-001",
  "operation": "create",
  "config": {
    "name": "FRA 当前贷款与国家修正",
    "queries": [
      {
        "topic": "N01",
        "object": {"type": "country", "country": "FRA"},
        "fields": ["loans"],
        "parameters": {}
      },
      {
        "topic": "N07",
        "object": {"type": "country", "country": "FRA"},
        "fields": ["modifier_id", "target", "effects"],
        "parameters": {}
      },
      {
        "topic": "N08",
        "object": {"type": "country", "country": "FRA"},
        "fields": ["modifier_start_date", "modifier_end_date", "remaining_days", "duration_type"],
        "parameters": {}
      }
    ],
    "detail": "full"
  }
}
```

```json
{
  "request_id": "country-records-report-query-001",
  "report_id": "report-replace-with-returned-id"
}
```

周期订阅复用同一报告。`report_id` 和 `session_id` 是占位值，实际调用时替换为报告创建
结果和当前 `information_discover` 会话绑定：

```json
{
  "request_id": "country-records-periodic-create-001",
  "operation": "create",
  "config": {
    "name": "FRA 贷款与国家修正每两秒",
    "kind": "periodic",
    "report_id": "report-replace-with-returned-id",
    "enabled": true,
    "binding": {
      "session_id": "session-replace-with-current-session",
      "observer": "FRA",
      "game_version": "1.37.4"
    },
    "schedule": {
      "basis": "real",
      "every": 2,
      "unit": "seconds",
      "missed": "coalesce"
    }
  }
}
```

周期读取只重复当前只读采样；不会推进游戏日期或触发贷款、修正、外交等业务动作。
订阅结果仍保持 `complete=false`，直到取消订阅或上下文失效。服务应在每次读取中重新
核对 session、日期、观察方、代码守卫和两遍原始字段；上下文改变时本次结果应为
`unavailable`，不能继续使用上一轮 known 值。

## 当前边界

当前公开的是本国直接贷款/修正记录。贷款 lender 的 fullref 到银行或国家标签的映射、
贷款日期 epoch、含利息金额 helper、修正的本地化名称、所有其他修正来源、激活条件、
业务单位、N09 最终属性和 `removal_conditions` 仍未闭合。历史保存数据或独立 raw 参考
只用于验证形状，不能冒充新的 live 快照；缓存刷新时机和主线程原子性也没有承诺。

本页的 MCP 验收结果待本批补入。调用方应以返回的 `status`、`reason`、`source`、
`complete` 和每行 raw 状态为准，不根据字段名或旧结果自行填充未知值。
