# 国家资源信息接口

`NativeCountryStateSource` 为信息服务提供五个已核对的本国字段，包括N01的 `treasury`、N02的 `manpower`、N05的 `diplomats_available`，以及N06的 `prestige` 和 `monarch_points`。实时宏观查询的国库、人力采用上述缓存路径，其余公共字段路径复用外交只读预览，点数由独立的有界纯 RPM 读取器采样。

这些字段描述的是一次受上下文保护的采样结果。`query`、`periodic` 和 `change` 触发方式表示可以重新采样或比较采样，不表示信息服务已经接收完整的外交事件流；`poll_events` 在本适配器中返回空页，完整外交事件仍由原有来源负责。

## 已核对的字段

### 国库（N01）

R74 真实查询记录 [r74_economic_queries_real.json](../../../bridge/tests/fixtures/r74_economic_queries_real.json) 的 `send_gift` 事件包含：

```json
{
  "native_gift": {
    "ducats": 25,
    "amount_raw": 25000,
    "resource_scale": 1000,
    "actor_treasury_raw": 208015,
    "recipient_treasury_raw": 6359,
    "complete": true
  }
}
```

现有 public projection `bridge/gift_influence.py` 只公开受控发起国的余额：

```json
{
  "gift": {
    "controlled_treasury": {
      "country": "FRA",
      "raw": 208015,
      "unit": "ducats",
      "scale": 1000
    }
  }
}
```

因此 `N01.treasury` 返回 `208015` 这一 raw 值，目录元数据声明 `unit="ducats"`、`scale=1000`；换算后为 208.015 ducats。适配器不会把 `recipient_treasury_raw` 转为本国字段，也不会据此推导收入、支出、结余、贷款或战争收支。内部使用 25 ducat 作为 `send_gift` 查询参数，是为了取得既有国库 projection；这个参数只进入 inspection，不会提交赠礼。

### 后备人力（N02）

R73 真实记录 [r73_favor_queries_real.json](../../../bridge/tests/fixtures/r73_favor_queries_real.json) 的人情换人力预览包含 `actor_manpower_raw` 和 `recipient_manpower_raw`。`bridge/favor_resources.py` 的 public projection 将它们放在 `favor_trade.manpower`，并声明 `unit="men"`、`scale=1`。例如 `men_FRA_PAP` 的发起国人数为 38705，对方人数为 10951。

`N02.manpower` 只取 public projection 中 `manpower.actor_raw`，返回实际人数的整数。适配器要求 projection 同时确认 actor、recipient、单位和尺度，避免把对方字段当成本国状态。部队数量、兵种构成、水手、兵力上限和缺额没有可复用的本接口字段，仍保持未实现。

### 可用外交官（N05）

R73 人情换人力的 public inspection 结果包含：

```json
{
  "resources": {
    "diplomats": {
      "native_requirement": true,
      "available_count": 1,
      "availability_verified": true,
      "allocation_verified": false,
      "source": "native_rule",
      "complete": false
    }
  }
}
```

`N05.diplomats_available` 使用 `availability_verified=true` 且范围为 0 至 256 的 `available_count`。`complete=false` 表示当前外交官没有逐项分配证明，并不否定已经核对过的可用数量；适配器只导出该数量。R73 的 `men_FRA_SAV_no_diplomat` 真实记录验证了零值仍是已知值：结果为 `0`，状态是 `known`。外交官总数、任务、归途、关系数量和关系上限没有来源证明，因此不在本适配器中提供。

### 威望（N06）

N06 复用 `offer_vassalization` 的公共投影，只读取顶层 `prestige_raw`。适配器要求返回结果同时满足以下身份条件：`action_id="offer_vassalization"`、`family="vassalization"`、`phase="initiate"`，并且 actor 是查询对象中的 observer。`prestige_raw` 必须是非 `bool` 的有符号 int32；`prestige_scale` 必须是非 `bool` 的整数 `1000`。负数和零均为合法的威望 raw 值，显示值按 `prestige_raw / 1000` 解释。

这个路径不读取 `cancel_prestige_delta_raw` 或取消附庸费用。`reference_recipient` 只用于构造同一次 country-pair 原生 inspection 的上下文，不把对方资源或取消费用变成本国字段。真实记录 [information_country_relations_live_1374.json](../../../bridge/tests/fixtures/information_country_relations_live_1374.json) 中，FRA→PAP 的公共投影为 `prestige_raw=-11643`、`prestige_scale=1000`，因此本接口返回 `-11643`，对应 -11.643 prestige。

N06 的目录字段元数据为：

```json
{
  "unit": "prestige",
  "scale": 1000,
  "raw": true,
  "raw_semantics": "prestige_raw / 1000",
  "paths": ["prestige_raw"]
}
```

### 行政、外交和军事点数（N06）

`monarch_points` 返回三个有符号 int32 整数：`administrative`、`diplomatic`、`military`，单位为 `monarch_points`，尺度为 1。本批 FRA 实采分别为 471、389、152；负数和零同样合法。三项作为一个字段整体校验，任何分量或守卫不满足时保持未知。

来源为 [country_resources_memory.capture](../../../bridge/information/country_resources_memory.py)，固定 1.37.4 EXE 与 FRA 作用域。它校验安装会话、创建时间、进程及模块身份、profile/辅助源码/REA 证据指纹、四段文件和运行代码，执行两遍有界读取并检查关闭结果。它不调用游戏函数；两遍相同不构成主线程原子快照或世界代际证明。偏移与标签的原生证据链见[国家点数原生来源](../../04-实现研究/国家与国内/国家点数原生来源.md)。

## 查询合同

四个主题都只接受本国对象：

```json
{
  "topic": "N06",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["prestige"],
  "parameters": {"reference_recipient": "PAP"}
}
```

`object.country` 必须等于来源上下文中的 `observer`。N01、N02、N05 和包含 `prestige` 的 N06 查询仍须提供三字母 `reference_recipient`，且不能等于本国。该参数用于原生 country-pair inspection 的上下文，不会扩大资源查询范围。

只请求点数时可以使用空参数：

```json
{
  "topic": "N06",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["monarch_points"],
  "parameters": {}
}
```

同时请求 `monarch_points` 和 `prestige` 时仍须提供参考国家；两个字段保留各自来源与尺度。一个来源失败时，另一个已经确认的值继续保留，整体为 partial。未绑定安装、recorded/save 来源或其他国家不会回填实时点数。

四个主题目前使用以下来源：

| 主题 | inspection action | public path | 返回尺度 |
| --- | --- | --- | --- |
| N01 | `send_gift`，内部金额 25 | `gift.controlled_treasury.raw` | `ducats`，1000 raw/ducat |
| N02 | `trade_favors_for_men` | `favor_trade.manpower.actor_raw` | `men`，1 |
| N05 | `trade_favors_for_men` | `resources.diplomats.available_count` | `diplomats`，1 |
| N06 | `offer_vassalization` | `prestige_raw` | `prestige`，1000 raw/prestige |
| N06 | 纯 RPM `country_resources_memory.capture` | `values.administrative/diplomatic/military` | `monarch_points`，1 |

信息结果仍遵循公共合同的字段状态。取得并通过身份、方向、单位、尺度和范围检查时返回 `known`；公共 projection 没有该字段或方向不一致时返回 `unknown`；会话未就绪、inspection 适配器缺失或调用失败时返回 `unavailable`。例如 N06 的结果字段为：

```json
{
  "topic": "N06",
  "fields": {
    "prestige": {"status": "known", "value": -11643}
  },
  "objects": [{"type": "country", "country": "FRA"}],
  "complete": true
}
```

来源说明中的 `provenance.public_path` 会记录实际读取的 projection 路径和 `reference_recipient`。结果对象仍只保留本国 country identity。

## 上下文、触发方式与边界

N06 在查询前、原生 inspection 返回后分别重新读取基础 context，并核对 `status=ready`、`mode=live`、游戏版本 `1.37.4`、EXE SHA-256 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`、`observer=FRA`、非空 `session_id` 和整数 `game_date`。查询前后的 `session_id`、游戏 SHA、observer 和 game date 必须相同；身份不完整、会话失效或日期改变时，N06 返回 `unavailable` 或 `unknown`，不会把旧 raw 值冒充当前值。N01、N02、N05 保持原有适配器的身份和方向检查。

国库、人力、外交官和威望查询会调用已加载 DLL 中的只读 native predicates；点数读取器使用纯 RPM。混合查询按字段记录这两种来源，没有业务提交。点数原始报告保存完整读取日志；对外 provenance 只保留紧凑身份、守卫和原始字节 SHA，以及完整 capture canonical JSON 的 SHA，避免周期结果反复携带代码和国家表。

当前信息字段登记为 `54 available`、`107 partial`、`236 planned`，其中35个主题已有部分可调用字段。这个统计包含独立N04适配器中已实机核验的稳定度、厌战和腐败；本页的国家资源适配器仍只发布上表五个字段，国内压力见[独立来源说明](../../国内压力原生来源.md)。

## 适配器 API

`NativeCountryStateSource(base_source)` 实现信息来源接口：

- `context()` 委托给包装的 `DiplomacySource`，保留会话、观察方、游戏日期和来源模式。
- `catalog()` 返回 N01、N02、N05、N06 的已实现字段子集；组合来源可以用这些条目覆盖原目录中同编号的 planned 字段，同时保留尚未实现的其他字段。
- `validate_query(query, context)` 检查 country 对象、观察方边界和 `reference_recipient`。
- `read(query, context)` 按字段选择原生公开预览或纯 RPM 来源；N06 执行前后 context guard。
- `poll_events(context, cursor)` 返回空事件页；本适配器提供采样状态，外交事件仍由原有来源负责。
