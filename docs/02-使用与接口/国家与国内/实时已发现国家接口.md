# 实时已发现国家接口

`C02.discovered_countries` 返回逻辑观察国法国（FRA）知晓、且通过原生存在判断的普通国家标签。默认实时服务已注册 `NativeCountryDiscoverySource`；查询、手动报告和现实时间周期订阅共用此来源。

逻辑观察国由国家控制数组确认为非玩家国家。物理客户端仍是葡萄牙（POR），采集不切国，也不把物理客户端视角当作法国视角。

## 查询

```json
{
  "topic": "C02",
  "object": {"type": "session"},
  "fields": ["discovered_countries"],
  "parameters": {}
}
```

也可以使用 `{"type":"country","country":"FRA"}`。选择其他国家会返回 `not_applicable`，不会采集该国的知晓集合。

当前验证会话的字段结果包含：

```json
{
  "status": "known",
  "value": ["..."] ,
  "unit": "country_tag",
  "period": "current",
  "complete": false,
  "candidate_count": 1369,
  "existing_candidate_count": 588,
  "country_existence_filter_applied": true,
  "domain_complete": false
}
```

上例省略了实际标签；该会话实际返回168个标签。`candidate_count` 是普通规范国家引用的候选数量，`existing_candidate_count` 是其中通过原生存在判断的数量，`value` 只包含进一步通过法国知晓判断的标签。标签按升序排列、去重，可能包含法国自身。

## 报告与订阅

将上述查询放入报告的 `queries` 后，可通过 `information_query(report_id=...)` 手动运行，也可创建 `kind=periodic` 的现实时间订阅。实际2秒、5秒订阅已分别收到结果；取消2秒订阅后5秒订阅继续工作。当前不支持 `kind=change`。

同一查询可以同时请求 `discovered_countries`、`discovered_provinces` 和 `related_countries`。前两项分别由国家、省份适配器采集并合并；`related_countries` 仍返回未实现，不会把盟友或战争参与方拼成未经定义的完整集合。

## 取值与限制

- 先验证当前进程、构建、会话、法国引用及非玩家身份，再采集两遍。国家索引、存在判断输入、知晓判断输入及上下文必须相同；缺读或漂移会撤回整份集合并返回 `unknown`。
- 对普通国家，原生存在判断以国家对象 `+0x1344` 的DWORD是否非零为依据。它是从实际 `exists` 触发器定位的输入，不将它另行解释为未经证明的城市计数。不存在的目标不会再读取首都知晓信息。
- 知晓判断使用目标首都的原生标志与法国槽位的发现位；不读取其他国家的知晓视角。
- 仅支持当前有界国家表中的普通规范引用。特殊引用、未分类行及完整UI可知范围尚未闭合，因此保持 `partial`、`complete=false`、`domain_complete=false`。双遍比较不等于原子快照。
- 已知空集合与读取失败不同；失败不会转成空集合。公开字段不包含内存地址、完整引用或原始读取轨迹。
- 显式历史存档和 recorded 模式不注册本实时来源。离线重放沿用共享限制 R128-001：验证内部一致性，不独立证明任意整体改写归档的外部真实性。
