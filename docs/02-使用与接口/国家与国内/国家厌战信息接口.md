# W04 国家厌战信息接口

`W04.war_exhaustion` 提供所选国家的当前厌战值，也可按具体战争列出双方参战国的当前厌战值。`NativeWarExhaustionSource` 复用N04本国和F04外国压力读器，沿用其国家、可见范围和采样校验。

目前支持固定EU4 1.37.4/B23下的FRA逻辑观察国。country对象可选择FRA或可读取的相关外国。war对象用actor=FRA和recipient选择对手，多场候选时填写war_id，所选编号会在默认结果中回显。厌战值描述各国当前的全国状态，双方按FRA所在阵营分组。

## 使用

默认 live/native 模式会注册这个字段。沿用已核验的安装清单启动 MCP stdio 服务：

```powershell
python tools/serve_information.py --operator-session work/runtime/diplomacy-observer-20261103-runtime-recovery-001/installation.json --observer FRA --database work/runtime/information-war-exhaustion-20261103-122-001/example.sqlite3 --journal work/runtime/information-war-exhaustion-20261103-122-001/example-journal.sqlite3 --tick-seconds 0.25
```

传给 `information_query` 的参数为：

```json
{
  "request_id": "country-war-exhaustion-example",
  "queries": [{
    "topic": "W04",
    "object": {"type": "country", "country": "FRA"},
    "fields": ["war_exhaustion"],
    "parameters": {}
  }]
}
```

同一个查询可以加入手动报告，或由独立的periodic、change订阅复用。周期支持现实秒，变化检测按配置间隔比较采样。正常游戏日期前进允许读器继续采样，完整视图保留采样时间范围。

历史存档、recorded等来源沿其原有能力。战争视图先由W01确定战争与实际成员，再只读取这些国家的厌战值。无法确定战争时保留对应状态；单个成员不可见时，该成员在默认结果中为null，其他成员的已知值继续返回。

战争查询示例使用以下配置。

```json
{
  "queries": [{
    "topic": "W04",
    "object": {"type": "war", "actor": "FRA", "recipient": "ENG"},
    "fields": ["war_exhaustion"]
  }]
}
```

默认输出包含数值范围，以下数值用于说明格式。

```json
{
  "actor": "FRA",
  "recipient": "ENG",
  "war_id": "war_0123456789abcdef_00000101",
  "war_exhaustion": {
    "our_side": {
      "FRA": {"current": 2.5, "min": 0, "max": 20},
      "SAV": {"current": 1.25, "min": 0, "max": 20}
    },
    "opposing_side": {
      "ENG": {"current": 9, "min": 0, "max": 20}
    }
  }
}
```

## 值和完整性

默认输出使用实际点数和0到20的范围。完整视图保留原生i32的value、raw、raw_hex、unit和scale。scale为1000，原生4349对应4.349点。零值保留为0，未知值为null。

国家视图沿所选读器的完整性。战争视图逐成员保留状态，全部成员已知时该字段complete=true。混入尚未实现的字段或某个成员读取失败时，完整视图会记录具体缺项。

本入口只选择war_exhaustion。来源保留所用N04/F04读器及W01参战名单的关系，完整视图可查原生值与缺项。成员范围随所选战争确定，原始整数、字节、单位及会话沿既有读器校验。
