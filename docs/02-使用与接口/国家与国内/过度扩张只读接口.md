# 过度扩张只读接口

本页记录第三十七批接入的 N04 `overextension` 当前缓存只读字段。

## 当前可用行为

固定 EU4 1.37.4 中，InformationService 现在支持显式请求 N04 的 `overextension`。读取器按当前国家对象的 `country+0xE48` 复制一个有符号 32 位整数，不调用游戏函数，不重新计算省份贡献，也不读取和约预览或存档字段。结果使用 `unit="fraction"`、`scale=1000`；消费方将 `raw / 1000` 解释为比例。游戏界面的百分数格式对应 `raw / 10` 个百分点，例如 `raw=1000` 表示 `100%`。

请求格式与其他 N04 国家字段相同：

```json
{
  "topic": "N04",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["overextension"],
  "parameters": {}
}
```

已知结果保留原始值和来源关系：

```json
{
  "status": "known",
  "raw": 0,
  "raw_hex": "00000000",
  "value": 0,
  "unit": "fraction",
  "scale": 1000,
  "basis": "native_ui_current_cache",
  "value_origin": "copied_native_ui_cache"
}
```

`value=0` 是本次 FRA 实机读取到的当前缓存值，不代表其他国家的值，也不代表所有场景的过度扩张都为零。当前可用范围固定为 1.37.4 和已核验的 FRA 观察国家；其他国家尚未经过同等运行核验。
