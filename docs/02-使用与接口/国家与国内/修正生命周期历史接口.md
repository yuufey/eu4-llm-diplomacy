# 修正生命周期历史接口

## 查询范围

`H02.modifier_lifecycle` 提供当前会话已经采集并持久化的FRA直接临时国家修正变化。支持 `country_modifier_added`、`country_modifier_removed` 和 `country_modifier_expired`，分别表示新增、移除和自然到期。

查询对象可使用当前 `session` 或本国 `country`。每条记录沿用C04原生事件的验证和发生日期。账本读取不触发额外原生采集，事件订阅沿用共同事件来源、游标及去重。

服务启用时，每轮调度先通过共同来源采集事件，再执行定时和变更报告。H02历史采集独立于事件订阅。手动历史查询读取最近一轮已保存记录。服务须持续调用 `information_tick` 或配置后台调度。

```json
{
  "topic": "H02",
  "object": {"type": "session"},
  "fields": ["modifier_lifecycle"],
  "parameters": {"limit": 50}
}
```

```json
{
  "topic": "H02",
  "object": {"type": "country", "country": "FRA"},
  "fields": ["modifier_lifecycle"],
  "parameters": {"event_type": "country_modifier_expired", "limit": 20}
}
```

`country_pair` 在原生修正历史视图中返回 `not_applicable`。`case` 或 `request_id` 显式关联的查询继续使用既有H02请求日志路由。对应的初次事件和回放分别沿用该来源的 `read_event` 与 `replay_event`。

## 业务记录

字段值是最近采集记录优先的列表，空列表表示该页没有符合条件的已登记记录。每条记录包含以下字段。

| 字段 | 含义 |
| --- | --- |
| `event_id` | 共同事件来源分配的去重身份 |
| `event_type` | 原生修正变化类型 |
| `country` | 修正所属国家，当前范围为FRA |
| `modifier_id` | 修正标识 |
| `change` | `added`、`removed` 或 `expired` |
| `event_date` | 原生变化实际发生日 |
| `start_date` | 原生记录中的开始日，未设置时为 `null` |
| `end_date` | 原生记录中的结束日，未设置时为 `null` |

完整视图的已知日期使用 `status="known"`、`value=<原生日期>`、`unit="game_date_raw"`。默认简洁视图显示可读日期。事件投影的顶层日期使用实际发生日，历史查询顶层日期使用查询上下文日期。

## 分页与覆盖

`limit`默认50，范围1至1000。默认响应有后页时提供`next_cursor.modifier_lifecycle`，继续下一页时将其填回`parameters.cursor`。末页省略`next_cursor`。完整视图的字段包装器保留对应游标。分页游标属于当前共同事件账本范围，无效游标返回`invalid_cursor`。

字段包装器的 `complete` 和来源的 `gaps` 保留共同账本的采集覆盖信息。可用记录在存在采集缺口时仍保留。查询覆盖已采集的直接临时修正事件，修正种类和会话开始前历史受既有原生来源范围约束。

## 适配器接线

```python
from bridge.information.modifier_lifecycle_history import NativeModifierLifecycleHistorySource

source = NativeModifierLifecycleHistorySource(base_source, history_reader=history_reader)
```

`base_source` 提供C04的 `replay_event` 和原有H02请求日志入口。适配器只拥有 `H02.modifier_lifecycle`，其 `poll_events` 返回空批次，事件由共同primary采集。

```python
history_reader(context, *, event_types, limit=50, cursor=None)
# 返回
{
    "events": [...],
    "next_cursor": None,
    "complete": True,
    "gaps": [],
}
```

`events` 是最近采集优先的标准原生事件快照。适配器逐条委托现有C04回放投影验证，再生成业务列表。`event_type` 未指定时读取三类修正事件，指定时读取对应单类。没有历史读取回调时，普通查询返回 `MODIFIER_LIFECYCLE_HISTORY_READER_REQUIRED`。事件和回放入口直接消费传入快照。
