# 逐场战报的类型与原始上下文

2026-10-25，第二十三批。上一批已取得18条自然入口原始记录，并将其中一条与游戏保留结果逐项核对。本批继续补充类型、原始参与侧和战争成员的复制合同，同时追踪传统、威望及占位符展开的静态来源。完整目标仍为74主题、397字段；B01–B04尚未完成，字段登记保持54 available、107 partial、236 planned。

本页仅适用于EU4 1.37.4，EXE SHA-256为`b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。函数地址使用RVA，静态映像基址为`0x140000000`；运行地址仍须重新核对实际模块。

## 类型可以怎样读取

已有REA证据中，路由`23A020`读取combat虚表`+0x60`方法的返回值：2进入使用`NAVALBATTLEOVER`的格式器`22E6B0`，1进入使用`LANDBATTLEOVER`的格式器`232A80`。这闭合了该调用路径中的陆海战类型对应关系。它不表示结果对象的`flag108`就是类型，也不表示所有combat子类使用相同布局。

新的[静态合同](../../../work/runtime/information-battle-business-20261025-001/context-source-contract-001.json)将原始分支、消息键、已知调用点和字段来源分别保存。拟用的复制组件读取虚表槽所指的六字节指令，只接受精确的`MOV EAX, 1或2; RET`，并检查它位于已审主映像范围且前后稳定。其他实现保留未知，不主动调用该虚函数。自然入口中的实际getter编码仍须验证。

## 原始侧、战争成员和可见性

[自有上下文复制组件](../../../work/native/information-battle-owned-context.h)接收受审的主模块范围、combat地址、完整物理玩家引用，以及只在已知调用者下允许使用的原RBX战争候选。组件不保留这些源指针。

| 取得的内容 | 复制口径 | 不能据此推出 |
| --- | --- | --- |
| combat的两条侧指针 | `+20/+28`所指原始side0、side1 | 结果重排后的attacker/defender、我方/敌方或胜负 |
| 各侧参与者 | `+100/+108`限定的32字节记录，每条复制`+10`完整国家引用，最多256条 | 每个参与国的具体兵力或当前可见性 |
| 六个整数槽 | 各侧`+118/+11C/+120/+134/+138/+13C`，保留有符号原值 | 海战单位、显示口径或完整结果框中的初始/损失/剩余数量 |
| 可选战争成员 | 检查内嵌历史根和两组成员向量，最多各256个完整引用 | 稳定公开war ID、战争进攻方/防守方或战争中所有战役可见 |
| 物理玩家是否在成员中 | 仅在战争上下文已核验时，以完整引用精确比较 | 观察方一定能看见该场战斗 |

战争候选缺失、无效和已观察分别表达；缺失或无效时，成员判断保持未知。该组件不把原生地址作为公开身份，也不将“不是战争成员”直接标成“战斗不可见”。同址同日读档、重入和实际对象有效期仍需上层生命周期守卫。

最终[自有复制测试003](../../../work/runtime/information-battle-owned-context-20261025-001/context-test-003/report.json)的87项检查通过，capture栈为9008字节。读取总预算64KiB、主映像上限512MiB，组件检查源与输出别名，并在全部复制结束后复核getter、侧指针、向量边界、引用及原始数值；失败保持输出不变。空向量同时允许空指针和合法对齐的已分配空区间。完整国家引用只检查非零及低三字节为大写ASCII或数字，其余位原样保留；这不是当前国家数据库有效性证明。前两版43项、72项报告及对应源码快照保留，不能替代最终来源指纹。

## v2上下文载荷

[原生编码器](../../../work/native/information-battle-context-wire.h)与[Python解码器](../../../work/information_battle_context_wire.py)采用IBOW v2。载荷先保存长度及完整、不变的v1 result/summary，再保存上下文存在标志；有上下文时才编码已复制的kind、物理玩家引用、原始双方及可选战争成员。最大32768字节，向量最多256项，整数按小端显式写入，不序列化padding、未用数组槽或原生地址。

解码器拒绝非规范布尔、错误长度、尾随字节、非法引用、kind与getter矛盾及不一致的成员判断。已观察war必须有完整成员向量和已知成员判断，存在的side必须有完整参与者向量。无论上下文是否存在，返回值都显式保留`business_complete=false`、`complete=false`、`overall_complete=false`、`visibility_verified=false`，公开war/battle身份仍缺。

最终[跨语言测试003](../../../work/runtime/information-battle-context-wire-20261025-001/context-wire-test-003/report.json)为42项原生和36项Python检查通过，包含实际自有capture→编码→解码、全部原始数值槽和256项引用的独立核对。旧001/002未覆盖；这些是自有fixture结果，尚无自然入口上下文实证，也未接入当前DLL、实际摄取和事件服务。
