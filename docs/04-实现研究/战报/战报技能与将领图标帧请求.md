# 战报技能与将领图标的帧请求

第75批为 B04 `details.display.controls` 增加技能星级和将领图标的转换结果。它回答的是：固定 EU4 1.37.4 的 popup 代码会如何把已复制的输入转换成控件调用参数。输入仍来自原事件；计算结果不表示游戏实际创建了窗口或显示了图标。

公开查询、保存的报告与事件订阅共用这份投影。适用记录为 wire4–7，`source.projection_version` 为13；wire版本、原始 payload 和当前 v33 DLL 均未改变。B04 的目录字段包含 `frame_requests_revision: 1`，用于识别这项附加能力。

## 如何读取

每个适用控件保留原有 `inputs`，新增 `native_frame_requests` 和 `declared_frame_asset`。同一个键出现多次时，输出逐项保留原始顺序和 `pair_index`，不猜测界面采用哪一次。

| 输入 | 转换规则 | 覆盖控件 |
| --- | --- | --- |
| 技能数字 | 按原生 signed-i32 十进制前缀规则解析，加1并保留32位结果，形成虚表偏移 `0xa8` 的参数 | 陆战双方火力、冲击、机动、围城；海战双方火力、冲击、机动 |
| 将领图标 | 解析值小于1时形成 `0x90` 的无参请求；否则向 `0xa8` 传原值 | `OURLEADERICON`、`ENEMYLEADERICON` |

例如，技能输入字节为 ASCII `3` 时，输出请求参数为4。图标输入为 `0` 时，输出无参调用请求；这一步的确切界面含义尚未确认，不能直接称为隐藏图标。

解析只信任 `value_raw_hex`：先取首个 NUL 前的 C 字符串，处理 ASCII 空白、正负号及连续十进制数字，遇到其他字符停止。没有数字时为0，溢出按 signed-i32 上下限钳位。前导非 ASCII 字节可能受进程 locale 影响，保留 `unknown`；坏 hex、越界或缺失输入也分别返回原因，不由已解码字符串补值。

`declared_frame_asset` 记录已固定散列的安装基础文件声明：`GFX_stars_small` 为13帧，`GFX_leader_types` 为7帧。`core.gfx` 中另一个7帧星级声明是注释。基础文件不是有效 mod/runtime 定义的证明；帧范围也不用于裁剪或改写原生请求参数。

## 状态与边界

`native_frame_requests.status=known` 只表示输入和上述转换规则足以确定请求。以下状态仍为 false：

- `native_call_observed`：未因此宣称原生调用实际发生。
- `runtime_widget_state_verified` / `actual_widget_state_verified`：未因此宣称控件实际显示。
- `active_runtime_definition_verified`：未确认运行时最终采用哪份图形定义。
- `full_display_complete` / `runtime_popup_verified`：完整战报和弹窗仍未验收。

这些控件的 `display_text` 仍为 `unsupported`，因为调用参数不是文字。原有 `raw_text`、缺失段、观察方筛选及双方身份也不因此提升。`WINORLOSE`、海战 `CAPTURE` 的来源已有静态清单，最终本地化及完整界面仍需各自证据。

## 验证记录

新增解析专项35项通过，并与已保存的36个独立 CRT 边界案例逐项一致；CRT 案例只在自有进程中运行，不能证明游戏实际 locale。两项集成测试分别使用历史自然捕获的法国陆战和 KEL 海战原始记录；KEL 只提供海战覆盖，不是法国正例。

真实 MCP stdio 在 recorded 模式下验证了上述两类记录：主动查询、报告查询和后台事件交付的字段一致，完成后订阅取消、两个服务均 exit0。原件见[recorded MCP 收据](../../../work/runtime/information-battle-control-text-20261029-001/mcp-recorded-001/receipt.json)。这次验证没有连接游戏、保存、重启或推进日期。

13条已保存的 wire7 战报另行只读投影，共得到102个技能请求和26个图标请求；数据库前后散列一致，FRA/POR直接参战均为0。见[逐记录读回](../../../work/runtime/information-battle-control-text-20261029-001/recorded-v7-frame-readback-001.json)。它验证新投影对真实字节的处理，不是新的法国实机正例。

唯一一次完整回归为3344项通过、106项失败、35项错误和2005个子测试通过，较第74批无新增失败；套件仍未全绿。611份选定来源在运行前冻结并在结束后复核；另一个修改过的测试漏入清单，在运行期间补存并在结束后匹配，记录明确保留这一时间边界。结果见[回归比较](../../../work/runtime/information-battle-control-text-20261029-001/regression-comparison-001.json)。

[独立投影审计002](../../../work/runtime/information-battle-control-text-20261029-001/independent-projection-audit-002.json)通过11项检查，复核了报告交付字段、订阅终态、归档投影及来源。首份审计的订阅关联和布尔字段筛选断言错误，原件保留；002只修正审计，没有重做游戏或测试。

非玩家国家的实际消息路径继续以[玩家与LLM的战报路径](玩家国家与LLM观察方的战报路径.md)的证据为准：非玩家法国的数据已有历史正例，法国事件的实际 popup 资格仍未确认，不能从 Line1 缺失推断 AI 没有消息。
