# 代偿债务只读报价

`take_on_debt` 查询非玩家法国对目标国的原生代偿报价。它包括本金和按原生公式计算的剩余利息，属于报价预览，不会支付款项或接手贷款。

当前支持操作国 `FRA`，目标国须与法国、物理玩家 `POR` 不同；只接受 `initiate` 和空参数。操作国不随物理玩家切换。

## 查询

外交接口：

```json
{
  "tool": "inspect_diplomatic_action",
  "arguments": {
    "action_id": "take_on_debt",
    "actor": "FRA",
    "recipient": "ENG",
    "phase": "initiate",
    "parameters": {}
  }
}
```

信息服务使用已有 A03，可由直接查询、报告和周期订阅交付：

```json
{
  "topic": "A03",
  "object": {"type": "country_pair", "actor": "FRA", "recipient": "ENG"},
  "fields": ["costs"],
  "parameters": {"action_id": "take_on_debt"}
}
```

外交响应的 `debt_quote` 包含 `status`、`total_raw_i32`、`value`、`scale`、`unit`、`basis`、`as_of_raw` 和 `complete`。金额按原生 signed32 逐笔累加规则保留，`scale=1000`、`unit=ducats`；不能将它当作不含利息的债务本金。可解码的原生描述另置于 `native_description`。

`list_diplomatic_actions` 在 `query_only_actions` 中列出此查询，原有 `actions` 目录保留原来的动作。`execute_diplomatic_action` 会在登记请求前返回 `DEBT_QUOTE_IS_READ_ONLY`。

## 取值条件

新会话必须明确确认 v34 查询协议。原生端先验证对应代码、动作虚表、操作国和目标国的完整引用、国家表、物理玩家和日期，再调用 selector 的可见性判断。

- 不可见：不创建报价对象，不读取贷款字段，返回 `invisible`。
- 可见且取值完整：最多核对 64 笔贷款，调用原生利息计算和描述方法，并比较调用前后的全部输入与会话上下文。
- 读取失败、前后变化、浮点控制位不符合条件或模型与原生数值不同：撤回数值，返回 `unknown`。

查询采集游戏帧线程的 MXCSR，不设置或恢复它。数值核对要求最近偶数舍入、浮点异常被屏蔽，且各次采样的控制位一致；已有异常状态位不会被误作控制位变化。纯算术模型自身仍不证明一次具体游戏采集有效。

公开响应只保留报价、日期、有限的浮点条件说明和可用描述文本。逐笔本金、利率、到期日、地址及原始读取记录仅供内部核对。查询不检查执行合法性，也不授予执行权限。

## 本次实机记录

R75/v34 在物理玩家 POR、逻辑操作国 FRA、1456.4.12（raw `56556984`）的暂停现场取得 FRA→ENG 报价 `1133703 / 1000 = 1133.703` 杜卡特。原生描述显示约 `1133.7`；六笔私有输入逐笔经过独立本地 C++ 算术对照，结果一致。四次 MXCSR 采样均为 `0x1FB7`。

该结果是原生描述函数与报价计算的实际返回，不声称观察了游戏界面渲染，普通 GUI 到描述方法的具体调用链仍未闭合。F03 的总债务本金与该报价分开；`bankruptcy_risk` 仍未开放。

原件位于 `work/runtime/information-debt-quote-query-20261101-001/live-quote-001/`。首次检查脚本因能力名称包含 `native_debt_quote` 而误判隐私泄露，失败原件保留；`reconciled-report-001.json` 以精确字段名检查恢复结果，没有重发原生查询。独立校正审计为 `independent-live-quote-audit-001/report-002.json`。
