# 破产风险私有计算模型

第96批恢复了固定 B23 EXE 中破产警报的计算方法，并实现了私有读取器。读取器只读取内存中的必要输入，在本地计算警报模型；它不调用游戏函数。F03 的 `bankruptcy_risk` 仍为 planned/unknown，生产 capture v4、projection 4 和 profile v6 不变。

当前模型还不能作为外国破产风险直接交付。已经确认的警报入口使用物理客户端当前国家，尚未证明法国能够获知任意目标国的同一预测。订阅不能扩大法国在游戏中的可知范围。此外，模型明确假设 SSE 使用就近舍入和屏蔽异常；本批没有读取运行线程的 MXCSR，也没有执行原生函数作对照。

## 警报预测什么

警报先计算一个财政余额。这个余额会重新计算贷款成本，与 N01 上一月经常性账本的 `monthly_balance` 不是同一个算式。余额经 float32 缩放后，若大于或等于原生 `-0.05f` 阈值，函数返回哨兵值1000，表示没有达到本预测的赤字条件。1000不能解释为预计1000个月后破产。

余额低于阈值时，程序根据贷款容量、特定贷款计数、国库和贷款金额因子估计剩余月份。每一步都保留原生 signed32 回绕、整数除法截零以及 float32 转换、加法和除法的顺序。最终整数小于12时显示警告；0使用“即将破产”文案，正数则由另一段日期函数生成预计日期。本批没有审计该日期函数，因此不返回日历日期。

这个预测并不证明国家已经破产，也不能代替原生的破产状态、冷却诊断或代偿报价。模型保留 `helper_return_i32` 这个名称：它来自原生 `0x33E3C0`，与按收入索引求和的变量分别处理，尚不对外声明其完整业务含义。

## 读取接口与边界

私有入口为 `bridge.information.bankruptcy_forecast_memory.read_state(reader, module_base, observer_binding, target_binding)`。双方 binding 必须包含可验证的国家完整引用，且观察方与目标不能指向同一国家。父采集器还必须核对进程、数据库、EXE代码、日期、非玩家观察方、外国披露条件和运行线程浮点环境；叶函数不会自行提供这些证明。

读取器取得26个账本整数、国库、两个因子，以及最多64个贷款节点。每笔贷款只读节点、原生判断用的 `+0x27`、`+0x35` 字节、`+0x28` 参数和 `+0x2C` 本金，不读取完整贷款方引用或到期日。它再次读取同组输入，要求节点、字段、表示方式、全局参数和国家完整引用全部相同；相同最终合计不能掩盖输入变化。两次观察不构成原子快照。

`bankruptcy_interest_memory` 只支持修正 processor 槽为空的路径。缓存状态为1时直接返回unknown；processor 非空、指针无效、稀疏项超过256或输入发生变化时也返回unknown。它不调用未知回调。稠密槽 `+0xF4` 与稀疏键 `0x1E` 是原生择一读取的两种表示，不能假定两处同时存在或数值相等。基础值与下限位于 EXE 的虚拟数据区，必须读取运行时值，不能把文件映射初始零填充当成当前配置。

外层读取预算为1024次、64KiB，每次最多1024字节；helper 自身限制为128次、16KiB、每次最多1024字节。预算同时约束成功和失败的读取尝试。所有结果固定 `publication_admitted=false`、`native_execution_observed=false` 和 `native_fp_environment_verified=false`。`status=known`只说明私有模型输入稳定且在已声明的数学前提下完成了计算，不表示外国披露或实际原生执行已验证。float转整数超出有效范围时，叶函数撤回整个模型结果。

上述四个算式的 REA 伪代码与普通 PE/objdump 核对分别保存，不把反汇编推断当成运行效果。权威普通报告为本批目录中的 `ordinary-bankruptcy-forecast-correction-002.json`、`ordinary-finance-projection-correction-002.json` 和 `ordinary-current-interest-001/report.json`。财政投影旧finding中关于helper命名和IDIV异常的说明已由 `finance-projection-stepwise-findings-correction-002.md` 更正，原件保留。

REA 的直接调用索引漏掉了已确认的警报分支。本批另以64KiB块流式检查固定 `.text` 范围内两个目标的 CALL-rel32 候选，没有全文件反汇编。四个候选分别位于小包装函数与警报更新函数；新增 `0xDF755C` 候选在警报 index10 的1024字节窗口内，调用前仍传递物理客户端国家。这些结果没有建立外国预测的披露权限，也不证明不存在其他间接调用或独立预测来源。
