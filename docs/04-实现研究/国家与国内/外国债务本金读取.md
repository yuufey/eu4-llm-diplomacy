# 外国债务本金读取与公开投影

第94批新增 `foreign_debt_principal_memory.read_state`，读取一个目标国家的贷款列表并计算本金合计。该批对英格兰实采6笔本金172、173、173、179、179、179杜卡特，合计1055杜卡特；外交理由所用缩放整数为1055000。双遍读取、保存后的严格重放及来源稳定检查通过。

第94批时，这个本金读取器只用于私有采集，尚未接入F03或MCP；当时公开债务中的`total_debt`保持unknown。第95批才将它接入生产查询、报告和周期订阅。第94批私有状态与第95批公开状态是不同证据，不能把早先的私有结果当成MCP交付。

## 当前F03契约

当前生产入口 `foreign_economy.py` 使用 `foreign_economy_capture_v7.py` 与 `foreign_economy_projection_v7.py`。capture schema仍为 `information.foreign_economy_capture.v4`，公开投影版本仍为4；模块文件名、profile版本与输出schema是不同标识。默认profile为 `foreign-economy-memory-1374-v7-r2.json`，104,956字节，SHA-256 `55118475efac5b4c491fdfec95df89c641f94cfd32acb304cecae65fbfbf2992`。它保留45段原生代码守卫和1段数据守卫，每个边界合计16,203字节；旧profile和归档原件保持原版本。

`F03.debt`现在把两个独立分量放在同一partial字段中：`loans_to_observer`继续报告FRA借给目标国的贷款子集；`total_debt`在自己的原生准入通过时，报告目标贷款列表中本金的外交理由缩放合计。两个分量可以分别为known或unknown。子集`record_count=0`只表示没有观察到FRA借给目标国的贷款，不能用来推出`total_debt=0`。

公开的`total_debt`只保留有符号32位缩放结果、scale、溢出标记和“不含剩余利息”的说明。它不发布私有leaf中的`loan_count`、`principal_total`、每笔贷款记录、地址或原始读取trace。`principal_total`是未缩放的替代计算，只留在私有采集及审计中，不与公开金额并列输出。对第95批英格兰样本，实际公开字段为1055.0杜卡特，原始缩放整数1055000，`overflowed=false`，`includes_remaining_interest=false`。

父层先验证B23 EXE、DLL、当前session与日期、FRA非玩家身份、country-view权限，以及observer/target国家记录。债务总额还需要一个针对FRA→目标国家的只读原生选择检查：只有目标不是宿主控制国家或物理玩家POR，且选择结果与当前会话、日期和已核对映射一致时，才公开本金合计。私有内存采集本身不调用游戏函数；每次请求债务本金的公开读取，在候选数据通过后至多进行一次`trade_favors_for_gold`、`initiate`原生检查；该检查不提交动作。native executor是否合法、FRA人情余额、外交官或冷却时间都不是本金读取门槛。

第100批的v34映射检查接受原生`0x8F440`谓词，或与已安装v34 bridge相匹配的1167字节转发函数`[RVA 0x59690, 0x59B1F)`。转发函数的有界SHA-256为 `766c88fe5209fd49507ace2ec822b555b9c9d8455ca56bb1d638208fe9cda4c5`；同时核对限定PE头、游戏基址全局和保存的原生函数指针。它不验证整个已装载DLL的hash，也不证明实际UI绘制。

以下v33映射说明属于第95批历史证据：当时映射检查接受原生`0x8F440`谓词，或与已安装v33 bridge相匹配的GUI转发函数。它核对已装载DLL的限定PE头、函数体`[0x56850,0x56cdf)`、游戏基址全局值及保存的原生谓词指针；只匹配这些字节和全局字段，不验证整个已装载DLL的hash。v33回调只在特定AI返回地址进入抑制分支；B23 GUI刷新函数`0xEF2B00`内的调用点不匹配该AI返回地址，因此落到保存的原生谓词。这个静态路径说明不能证明本次会话实际绘制了UI；公开结果仍标记`actual_UI_observed=false`。

第95批首次按v5映射读取时，运行时`+0xD0`槽指向v33回调而非预期的原生`0x8F440`函数，因此候选权限返回unknown（`CURRENT_VALIDITY_HELPER_MAPPING_MISMATCH`），本金字段随之撤回，没有把未知金额当作0。初次失败收据与修正前223项源码快照均保留。补入精确v33转发证据并建立v6 profile后，第二次私有只读采集通过，随后MCP查询、报告和周期结果都公开同一本金总额。具体样本与交付结果见下方证据链接和[外国经济承受能力查询](../../02-使用与接口/国家与国内/外国经济承受能力查询.md)。

## 两种金额的含义

下表中的`loan_count`、`principal_total`和`diplomatic_principal_total`是私有leaf的读取结果，不是F03公开字段；公开结果只保留缩放后的`total_debt`。

| 私有结果 | 算法 | 单位与缩放 |
|---|---|---|
| `loan_count` | 目标国贷款计数，与实际遍历条数一致 | 笔 |
| `principal_total` | 每笔有符号32位本金逐项相加，每次保留32位结果 | 杜卡特，scale=1 |
| `diplomatic_principal_total` | 每笔本金乘1000后保留32位，再逐项进行32位累加 | 杜卡特，scale=1000 |

两个金额分别复现原生本金提示与外交债务理由的整数运算。溢出时保留原生有符号结果，并记录 `overflowed=true`，不会改用无限精度结果冒充原生数值。它们都不包含剩余利息。

第90批追踪的 `TAKEONDEBTDESC` 属于代偿报价：它把本金与剩余利息相加。代偿报价与这里的本金合计是不同数值；剩余利息计算不作为读取本金的前置条件。

## 读取与一致性

接口为：

```python
read_state(reader, module_base, observer_binding, target_binding)
```

父层负责当前进程、EXE/DLL身份、数据库重新绑定、游戏日期、法国非玩家角色及country-view检查。leaf只读取双方完整国家引用、目标列表头与计数、每个24字节链表节点，以及贷款对象的4字节本金。它不读取贷款方、利率或到期日。

目标列表头位于国家对象`+0xDE8`，有符号计数位于`+0xDF8`；节点`+0`指向贷款对象、`+0x10`指向下个节点，本金位于贷款对象`+0x2C`。读取后重新比较双方国家引用、列表头、计数、所有节点和本金字节。出现漂移、环、重复对象、计数不符或读取失败时，整个结果返回unknown，不返回部分总额。

上限为64个节点、32KiB、384次调用，单次读取不超过1024字节。前后核对与父层双遍读取能发现这次观察中的变化，但不提供引擎原子快照保证。

## 原生依据与公开接入

目标为B23 EXE，SHA-256 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`；preferred image base为`0x140000000`。下列地址均为RVA，文件偏移另记。

- REA `ev_715a6d7f011cd9257dcca7ddbf089d2d67158cd68dd526d1a54813df38c97b2a`：`0x4F5E90`的外交理由独立金额循环遍历目标全部贷款，使用本金乘1000的32位和生成`DIPLO_LOANS`。该循环不使用另一个计数循环的`+0x27`比较。
- 普通PE反汇编核对精确`.pdata`范围`[0x4F5E90,0x4F65E4)`，1876字节，SHA-256 `3a4bc590eabcd3965f064d510394782d5ee07515571b2da25c5f327bb6c26bbf`，无函数体重定位或CHAININFO扩展。这是普通文件证据，不冒充REA或实测执行。
- REA `ev_96eb316b6f30c10c3bf64ef0a58d8b5f3fda7eae440b3df8c0ea86d84eeefb78`：本国经济提示`LAND_LOANS`另有未缩放本金的32位累加；它选择当前client，不能单独证明任意外国的公开可见性。
- B23的候选动作表`0x1C80980`中，`+0x120`指向上述理由函数，`+0x98`指向`0x4F5960`。后者普通6字节直线代码返回token15310；安装文件的`trade_favors_for_gold`字符串前紧邻同一整数。该组合用于关联“用人情换取金钱”，不声称恢复了C++ RTTI类名。

REA与普通PE证据还区分了提示金额读取和按钮合法性检查：B23 RVA `0xEF2050`处的AI accept提示路径，经动作对象`+0xB8`调用RVA `0x4EA210`，随后从动作对象`+0x120`读取`DIPLO_LOANS`；按钮启用状态另走`+0x90`。因此，“按钮当前不可执行”不等于原生债务理由不可见。v33安装审计与普通函数体分析进一步显示，GUI调用的返回地址不会进入只针对`base+0xB22A3`的AI抑制分支；这证明的是受限控制流和指针映射，不是实际渲染观察。

只读外交查询单独检查原生接受选择器，不要求动作当前合法；它仍排除宿主控制国家与POR目标，并将检查绑定到当前目标和日期。`acceptance.items[].native_value`是理由分值，不能当债务金额；`favor_trade.amount`是人情换金币报价，也不能当债务金额。若原生检查、hook映射、身份或日期不稳定，公开本金字段返回unknown，现有法国放贷子集仍可独立报告。
