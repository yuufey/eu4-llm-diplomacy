# EU4 LLM Diplomacy

本项目旨在为 **Europa Universalis IV** 提供MCP。LLM并不是代替玩家游玩，而是人类玩家可以与若干LLM游玩同一局游戏，并进行外交互动！

本项目的长期目标，是让 LLM 接管指定 AI 国家的外交决策，以及其他决策性强且并不繁琐的事务，同时继续由 Europa Universalis IV 原生 AI 负责剩余游戏系统。

玩家可以直接与由 LLM 控制的国家进行文字谈判：许诺利益、发出威胁、讨论联盟、谈判和平、欺骗对手、背弃承诺。总之，获得真实、丰富的外交体验！我们也期望LLM操控下的国家会拥有更强的战略规划能力。即便只是单单观看不同模型在同一局游戏中的表现，这样的斗蛐蛐想必也相当有趣！

我们确认了游戏本体对外的外交操作接口非常有限，为了将这些操作暴露给外部 LLM，我们确定了逆向 + DLL注入 + Hook的开发路线。

本项目已经基本完成技术上的开发，现已进入游玩测试并按需完善的阶段。有测试仓库（仍需克隆本开发项目才能使用）：https://github.com/yuufey/eu4-llm-diplomacy-tests

## 功能概览

### 信息导出

模型可以按需查询游戏信息，例如本国还有多少人力、与邻国的停战何时结束、某个任务还缺哪些条件。也可以把常用查询组合成定期报告，或订阅某些事件，例如战役结果和停战到期。查询外国时，可读内容取决于观察国可见的情报和接口支持的范围。

- [国家与国内](信息导出/接口/国家与国内/) — 国库、月度收支、陆海军、人力和治理容量。
- [关系与外交](信息导出/接口/关系与外交/) — 双向好感、停战期限、包围网、外交官和收到的外交提议。
- [战争与战报](信息导出/接口/战争与战报/) — 参战名单、战争分数、参战贡献和历次战斗的损失。
- [任务](信息导出/接口/任务/) — 任务树分支、前置条件、目标省份和任务奖励。
- [贸易与省份](信息导出/接口/贸易与省份/) — 省份归属、核心与宣称、贸易节点的价值和各国贸易竞争力。
- [机制与宗教](信息导出/接口/机制与宗教/) — 统治者与继承、神圣罗马帝国的选侯和改革、教廷与宗教学派。

### 外交操作

模型可以替获授权的国家预览外交行动是否符合当前游戏规则，对适用的行动查看影响对方接受意愿以及影响接受意愿的因素，然后提交行动并回查实际结果。

- [关系与外交](外交操作/接口/关系与外交/) — 提议结盟、改善关系、王室联姻、建立间谍网、赠送礼物和使用人情。
- [战争与战报](外交操作/接口/战争与战报/) — 选择宣战理由和参战方、查询战争分数、预览议和条款的影响并提出议和。

### 地图

模型可以从操控国视角查看总览、区域和局部地图，并且地图目前拥有军事图层，可显示军队数量和位置，以及参战国的堡垒位置、等级和围城进度。地图尽量简化了细节以便于LLM理解。游戏进行时，服务还可以按游戏月份定期导出三种尺度的地图图片和省份归属数据。[地图导出接口使用说明](地图功能/地图导出接口使用说明.md)

### 定期决策与游戏时钟

测试环境可以按游戏日生成本国战略简报，并交给同一个 Codex 会话继续决策。启用时钟权限后，模型也可以暂停游戏或切换速度。[战略简报实机记录](../logs/2026-11-21战略简报触发Codex回合.md) · [统一游戏服务使用说明](共用开发/统一游戏服务使用说明.md)
***注：codex桌面版无法将简报实时插入会话，正在考虑该使用codex cli或其他方法。***

## 获取和使用方式

1. 克隆或直接复制本仓库地址给您的agent，再一并附上您本地的EU4安装目录（eu4.exe启动器所在文件夹）和数据目录（通常是C:\Users\您的用户名\Documents\Paradox Interactive\Europa Universalis IV）,由 Agent 协助完成环境配置、构建和复现实验。

2. 如果您想自己动手，可以克隆本仓库，按照[路径配置](docs/共用开发/路径配置.md)完成本地配置，然后按 [复现流程](docs/共用开发/人工实验与日志读取流程.md) 走一遍。

> [!WARNING]
> 项目依赖逆向分析得到的运行时接口、DLL注入和Hook技术。不保证其他版本的兼容性。运行实验性构建版本可能导致游戏崩溃、存档损坏或其他异常。请仅使用可丢弃的测试存档，或确保已有可靠备份。
