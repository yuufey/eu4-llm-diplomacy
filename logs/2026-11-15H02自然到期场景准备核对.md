# H02自然到期场景准备核对

本轮由同级gpt-6.1-sol独立检查现有脚本入口能否缩短补贴、停战和普通宣称三个自然到期正例的等待。继承现场为1471.10.18/raw56692920，逻辑观察国FRA、物理玩家POR，v64会话42160-1dd7494c46e0763。本轮只读取项目文件和本地脚本规则，游戏读取、业务、推进、保存、载入和安装均为0。

## 现有入口与期限

成熟控制入口位于`work/native/automated-control.inc`。向既有控制请求文件写入`TEST_ONLY run_p1_script`及换行后，由游戏主帧调用原生`run`解释器，参数固定为`llm_p1.txt`。参数长度满足现有15字节短字符串容量。2026-11-13实际移除修正的记录已证明该入口能够产生原生效果。该历史脚本、旗标及请求继续沿原有禁止重派记录保护。[入口实测记录](2026-11-13本国修正非到期移除通知.md)

本地CWTools规则的`effects.cwt`第1542至1548行定义`add_truce_with = 国家`，说明使用默认白和停战期限。第2910至2924行定义省份或国家作用域中的`add_claim`。这两个效果均没有逐条期限或日期参数。游戏现有事件文件也使用简单国家参数的`add_truce_with`。这些文件说明脚本格式，新增效果的本轮实机执行次数为0。

在既有默认配置global_a=10、global_b=5及调整量0下，1471.10.18新建直接停战的日期投影为1476.11.1/raw56737056。模型包含原生月份取整及月初规则。只调用`add_truce_with`不能形成数日后到期的停战。实际执行前应以同一国家对R03读回的日期和运行时配置为准。[已交付日期模型与合同](../docs/信息导出/接口/关系与外交/停战自然到期事件接口.md)

普通`add_claim`使用宣称国现有期限读取器。既有自然来源将历史日期加`0x3f9410`返回年数乘8760，与当前日期作小于等于比较。脚本规则没有覆盖该历史日期或期限的参数，本方案没有把未经本轮读取的年数写成固定25年。[宣称自然来源](../docs/信息导出/接口/贸易与省份/宣称自然到期事件接口.md)

在现有本地效果规则中未找到补贴效果。正常`give_subsidies`仍列为`deferred_parameterized_action`。旧v14研究计划固定月额1000原生单位即1ducat、期限10年，不能据此认定当前v64已有可调用的短期参数化发送入口。正常目录中的`duration_years`是整数年，界面10至400年、每次10年的范围也没有提供数日期限。[当前动作目录](../bridge/tag_actions_1375_v31.json) [旧固定参数计划测试](../work/candidates/directional-experiment-plan-v14-1375/test_plan.py)

## 可供主代理裁决的最小后续方案

现有成熟脚本入口可以产生如下两个效果片段。目标国家和省份须由主代理以当前状态核对，避免覆盖已有停战或刷新已有宣称。以下仅为格式与真实影响说明，未生成或发布游戏脚本。

```text
FRA = { add_truce_with = SAV }
167 = { add_claim = SAV }
```

第一项建立FRA与SAV的真实停战并影响开战约束。第二项为SAV在省份167建立普通宣称，只有当前所有国仍为FRA、该宣称及永久宣称均不存在且省份满足可见性时，才符合所选自然到期场景。两项都沿默认期限，无法单独解决短等待问题。

若主代理决定采用独立实验存档准备，可将三条选定记录的首个到期资格日统一安排在1471.11.1/raw56693256。首个检查窗为15日，到1471.11.2暂停，复用三个新的5日窗口即可。15日只给出日期窗口，原生维护函数实际进入时间尚未证明。

- 补贴保留真实合同的整数年数Y，将开始日期设为`56693232 - Y * 8760`，截止日为1471.10.31。严格大于截止日后才满足自然到期条件。
- 调整量0且运行时配置10、5的直接停战，示例输入日期为`56692920 - 5 * 8760`，模型得到1471.11.1。输入仍须满足实际`game+0x1dd4 < date_input <= current_date`等现有来源条件。
- 普通宣称使用实际宣称国期限Y，将对应历史日期安排为`56693256 - Y * 8760`。永久标记必须为false，历史条目顺序必须保持有效。

这些公式已通过既有纯日期模型的6个离线断言。本轮没有确认三类记录的当前存档序列化路径，也没有生成存档修改器或候选存档。若选该方案，具体待补材料是限定记录的序列化日期映射，以及补贴当前可复用的建约来源。仅凭日期公式尚不能直接执行存档准备。

实施范围需由主代理另行确认，涵盖三条实验记录变更、载入派生存档以及首个15日整世界推进窗口。补贴会影响双方现金流，停战会改变国家对的开战约束，外国宣称会改变对应省份的外交与扩张依据。当前委派仅授权准备方案。实际授权及执行记录应逐项写明所选国家、宣称省份、月额、期限和窗口边界。

## 读取断言

准备后、推进前，主代理应保存R07所选有效补贴与截止日、R03方向性停战截止日、G01所选普通宣称及永久宣称状态，并记录正常H02基线和共同游标。新效果须使用新的请求身份和一次性旗标，沿既有日志保护历史动作。

自然维护完成后，实际原生日志应分别出现`native_subsidy_expired`、`native_truce_expired`和`native_claim_expired`。核对补贴双方与合同载荷、停战方向、宣称国和当前所有国及省份编号。补贴事件日期必须严格晚于截止日，停战事件日期须不早于截止日。正常H02读取应持久化相同事件身份，并与当前记录的实际移除状态一致。来源健康须沿既有丢失及传输故障字段解释。[补贴接口](../docs/信息导出/接口/关系与外交/补贴到期事件接口.md) [停战接口](../docs/信息导出/接口/关系与外交/停战自然到期事件接口.md) [宣称接口](../docs/信息导出/接口/贸易与省份/宣称自然到期事件接口.md)
