# H02 停战自然到期独立交付

本轮由同级 gpt-6.1-sol 独立负责 `H02.truce_expiry`，主代理负责补贴到期生产方和共享接线。双方共用候选 v62。主代理独占游戏操作，本方游戏访问、业务派发、推进、保存、重启、构建与安装均为 0。

## 原生来源与证据

固定 B23 EXE 为 38,463,016 字节，SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。文件首选 image base 为 `0x140000000`。本节均使用 RVA，实际进程 VA 需根据载入基址换算。

已阅读 reverse-engineer-anything 技能及 `docs/共用开发/rea-workflow-1375.md`，随后复用既有有界 Capstone 与 PE 读取器。当前分析沿用普通文件分析工作流，新增 REA 函数分析 Evidence 为 0。本轮没有附加游戏进程。

旧文档的 `0xa675b0` 在本 B23 中位于函数内部。首次查询该种子时，PE `.pdata` 将其定位到 `[0xa67420, 0xa68447)`，初次保留了 256 字节入口前缀。随后只扩大到该完整函数的 4135 字节，978 条指令全部连续解码，原始字节 SHA-256 为 `bd0dbe7872bef44d7eb1c917cc9ba56a0a0006633bb9e0b674ea6e7abe9db65e`。[原始入口定位](../work/runtime/information-truce-expiry-sol-20261115-001/static-maintenance-001/report.json) [完整函数与条件](../work/runtime/information-truce-expiry-sol-20261115-001/static-maintenance-002/report.json)

入口保存关系记录的 `+0x45` bit0。在 `0xa674bd` 调用已有的 `0xa6fbc0` 日期计算器，`0xa674c7` 比较派生截止日期与当前日期，截止日期小于等于当前日期时进入 `0xa674dc`，写入 `+0x44=2` 并清除 bit0。另有原生清除分支，因此实现还逐项复现了日期门槛、特殊日期值及目标槽排除向量的前置条件。RVA `0x1fd13c4` 由原始 RIP 位移记录直接确认，早期消息中的 `0x1fc13c4` 手写地址已及时更正。

完整函数包含入口前置向量循环，随后处理一个输入关系记录的标志与通知。函数后部复用 RSI 保存 UI 临时对象。观察器保留入口 instance，并在原调用返回后重读该地址。没有直接自调用，UI callee 的间接重入继续属于未跟随范围。逐调用局部状态和返回重检控制相应配对。

`+0x1dd4` 和特殊值的业务名称尚待解析，本次沿其已确认的机器条件使用。现有 Python 停战日历规则提供业务日期解释。原生清除与运行时到期交付的真实正例由主代理后续部署采集，本方本轮实机正例为 0。

## 实现与整合

独立新增 `bridge/truce_expiry_observation.py`、`bridge/information/truce_expiry_history.py`，以及停战原生核心、guard、entry-plan 和 observer 四个文件。共享 session 采集、C04、工厂、旧 H02 字段所有权、main 与 builder 接线由主代理完成。

H02 国家对严格按方向筛选，国家和会话查询保留两个方向各自事件。行中提供双方、到期日、实际清除日和事件编号。C04 保存日期输入、调整量和两配置，并在恢复时重算核对。新增来源复用共享日志游标、载入确认门槛、事件缓存和持久账本。

按照主代理提供的真实完整引用形状 `0x10000100415246`，本方在首次测试前移除了额外的最高字节条件。原生来源始终通过国家表重查完整引用，并核对关系记录数组归属。

主代理构建的合并候选为 `work/runtime/diplomacy-observer-20261115-expiry-v62-002`，DLL SHA-256 为 `2e377ae3282e08c3f048a01329e0f77634d7e9843fee32c471256c62f5f375d0`，来源数为 199。随后本方接手 `tools/start_diplomacy_observer.py` 的 v62 准入。新验证器逐项核对两个可独立选择的到期能力，再将已核对的扩展投影到完整 v61 合同；版本选择器同样逐级投影。主代理同步扩展控制器与探针的版本白名单。
