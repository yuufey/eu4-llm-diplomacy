# 国家标签与玩家席位核查

本次核查沿服务入口、信息采集器和原生桥追踪国家的来源。逻辑观察国决定可读视野，物理玩家由当前游戏席位确定，外交决策国由接管配置和请求确定。这三个值可以不同。

| 路径 | 修正与验证 |
| --- | --- |
| 地图 | 移除对“观察国必须由 AI 控制”的检查。地图仍按观察国的实际发现集合筛选。实机以 ENG 和物理玩家 O00 分别发布，发现省份数为 1074 和 0。两批都写出三张图。[实机收据](../work/runtime/map-export-20261128/seat-exports.json) |
| 信息查询 | 本国兵力、外国经济、省份利益和省份资源等来源按绑定国家取数。任务省份条件使用当前观察国的归属和事件。实际视野、对象归属和采集来源仍参与校验。 |
| 战报、神罗、贸易、财政 | 玩家观察国可以查询其有权读取的战报、帝国、贸易和贷款信息。W03 的本国兵力复用 N02。本国 POR 的合成贷款样本正确返回本金 123。F03 的 AI 受方推断仍须确认目标确由 AI 控制。 |
| 外交与时钟 | 六类入站提议的响应使用请求绑定的接收国和决策国。原生接管列表从空集合开始。新版时钟根据游戏中的规范玩家席位和显式能力标志开放控制。正在使用的旧 DLL 只能为 O00 提供该项控制。[候选构建与测试记录](../work/runtime/country-neutral-runtime-20261128-002/verification.txt) |

直接使用 Python 外交工具时，若会话和调用都没有绑定控制国，需要控制权限的操作会返回 `DIPLOMACY_CONTROL_CONTEXT_MISSING`。普通 MCP 和 JSONL 启动路径显式绑定控制国。省份数据拒绝缺少国家身份的准入证据，债务采集拒绝属于另一观察国的选择器证据。

联合测试覆盖统一服务的构造、各采集器接入和历史记录等路径，共 474 项通过。[联合测试输出](../work/runtime/map-export-20261128/factory-final.txt)

移除外交工具的默认国家后，旧测试在夹具中显式指定其模拟的法国席位。97 个直接使用外交会话和工具的测试模块通过 1309 项测试和 453 个子测试。[直接调用回归](../work/runtime/country-neutral-runtime-20261128-002/direct-context-final.txt)

本次编译的 v65 候选通过安装清单校验，未替换正在运行的游戏 DLL，外交执行和新版时钟未做实机写入验证。旧版事件协议和第一版 T03 采集仍限其实际支持的 FRA 范围，正常 T03 入口使用支持绑定观察国的第二版。针对旧版二进制的协议适配器及历史研究样例仍可能包含固定标签。
