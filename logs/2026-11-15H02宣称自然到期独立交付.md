# H02 宣称自然到期独立交付

本轮由同级 gpt-6.1-sol 独立负责 `H02.claim_expiry` 原生生产方、Python 事件与历史适配、定向测试、稳定接口和 v63 安装准入。主代理负责共享接线、构建和游戏现场。约定范围为 FRA 是宣称国或当前省份所有国的相关自然到期摘要，可用于重新评估本国扩张依据和外国对本国领土的主张。

本方游戏访问、业务派发、日期推进、保存、重启和安装均为 0。原生代码在自有测试进程中执行。游戏内真实自然到期正例待主代理的部署与场景工作补齐。

## 原生来源

固定 B23 EXE 为 38,463,016 字节，SHA-256 为 `b23fa0e1f698d31b01cdd1c3817a675805d8c6286cb66f9c231e6e2a42544d77`。下文地址均为 RVA，文件首选 image base 为 `0x140000000`。进程 VA 根据实际载入基址换算。

本轮复用既有省份成员读器与第155批 REA 证据。留存的永久宣称 getter 为 `ev_678217a120efc78aa71637f74d5b81cbae17016542a6447fdfbeda5df387239b`，有序历史查找器为 `ev_9997581d625e5c3d2d42523c59d048537aa30b4dfaef5922a55091aa8a2d7bb5`。二者绑定本 B23，分别提供 `0xa07100` 与 `0x9f9f00` 的已有结构依据。本轮调用 REA session 库存时尚未打开目标，新增函数分析 Evidence 为 0。后续增量均为普通有界 Capstone 与 PE 文件分析。[原 REA getter](../work/runtime/information-permanent-claims-20261104-155-001/rea-permanent-getter-001/evidence.json) [原有序查找器](../work/runtime/information-permanent-claims-20261104-155-001/rea-permanent-country-record-001/evidence.json)

相邻函数的初步核对区分了宣称转移、添加和移除。省份宣称移除函数最终定位为 `[0xa06cc0, 0xa070ff)`，1087 字节。它按国家槽寻找省份 `+0x4c0` 的当前宣称成员，并更新省份及国家的成员列表。[移除函数原件](../work/runtime/information-claim-expiry-sol-20261115-001/static-claim-delete-001/report.json)

针对这个已确定函数，对固定 `.text` 做了一次流式 E8 目标查找，最大缓冲为 1,048,580 字节，得到22处直接调用编码候选。按候选所属 `.pdata` 范围定向核对后，确认 `[0x303b70, 0x3041dc)` 为自然到期来源。该函数沿当前国家宣称省份遍历，在 `0x303c81` 调既有历史查找器，排除 `0x029c77f8` 标记后读取历史记录 `+0x10` 日期，将 `0x3f9410` 的返回值乘以 8760 并相加，再与当前日期比较。截止值小于等于当前日期后，在 `0x30415c` 调用移除函数，返回地址为 `0x304161`。其它21处直接调用由这个精确返回地址条件排除。[调用候选](../work/runtime/information-claim-expiry-sol-20261115-001/static-remove-callers-001/report.json) [自然到期条件](../work/runtime/information-claim-expiry-sol-20261115-001/static-expiry-candidates-001/report.json)

原生移除函数 SHA-256 为 `ddf1ea9b24ee167cd11f92f1e5fa33d368ba91687ea0cde49a90985aaedfccc4`，自然维护函数为 `7474606112e3ff2782fd724f5c14ce81c5997ee9b817609ec10e6fb4460eba24`。已重新流式核对 EXE 身份，并将 shipping guard 数组、15字节入口前缀和32字节源 unwind 与固定文件逐字节比较，全部相同。[guard 与 ABI 字节核对](../work/runtime/information-claim-expiry-sol-20261115-001/fixed-b23-guards-001.json)

早期辅助候选 `0xa06640` 和 `0x9b5d10` 的首次 `.pdata` 提取分别只覆盖一个41字节、101字节条目片段。它们的片段与后续有界结果保留原范围，生产来源使用上述两段完整函数。历史图未扩展为新的截止日期查询，事件摘要使用实际移除日期。

## 交付实现

新增 `bridge/claim_expiry_observation.py` 和 `bridge/information/claim_expiry_history.py`，原生实现为四个独立 `information-claim-expiry` 文件。来源要求自然到期调用方、已绑定 frame 线程、FRA 角色、双方 canonical 国家引用、当前省份数组归属和正向发现位。入口要求指定完整引用恰好出现一次，返回后要求它消失，其余成员与顺序保持一致。世界、日期、所有国、引用和省份身份均再次核对。

成员采集读取节点 `+0` 的完整引用与 `+0x10` 的后继指针。节点 `+8` 的业务含义继续保留未知，其内容未进入捕获读集。完整引用以当前国家表精确匹配为准，夹具覆盖实际15位 FRA/SAV 编码及 canonical 匹配的其它高位形式。

主代理统一完成 session collector、能力、载入门槛、C04、共享游标、事件排序、过滤、H02 工厂、历史 reader 和旧字段所有权移交。H02 行提供宣称国、当前所有国、省份编号和实际移除日期。国家对按宣称国到所有国筛选。原生 `---` 所有国映射为 `null`，同国角色也保留。动作 `actors` 和 `recipients` 过滤按已约定业务语义拒绝，国家与国家对通过报告对象筛选。

v63 安装器继续复用已有扩展验证循环，先验证4个 claim 来源及能力、wire、scope、ACK和版本选择块，再递归继承完整 v62 与 v61 合同。v63 要求两项 v62 父能力齐全。主代理负责控制器、探针与已有 ACK 读器的63继承。
