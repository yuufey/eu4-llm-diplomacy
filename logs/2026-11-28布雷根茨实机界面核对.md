# 布雷根茨围城与外国部队界面核对

通过 Windows 游戏窗口自动平移、缩放和点击。在奥斯曼界面的 1495.2.3 暂停局打开布雷根茨（Bregenz，省份 4710）的围城面板。截图期间未推进日期，未下达部队命令，未写存档。

- 地图部队标牌显示 `19k`。悬停后单列米兰 8000 人和波希米亚 11976 人。围城面板显示进攻方各兵种为 11988、4994、2994 人，合计 19976，与悬停的两支部队合计一致。这是当前游戏界面显示外军及精确兵力的正例。本次没有验证部队跨越战争迷雾边界后的显示变化，也未从截图判断两国与奥斯曼的阵营关系。[外军悬停和围城面板](../work/runtime/military-map-ui-20261128/28-bregenz-details.png)
- 地图图标和面板同为 `0%`。悬停概率时，提示说明这是下一围城阶段的投降概率，同时显示围城已持续 258 天、距下阶段 30 天。面板上的阶段进度修正是单独字段，提示给出的范围为 0 到 12。[投降概率](../work/runtime/military-map-ui-20261128/29-success-chance.png) · [阶段进度修正](../work/runtime/military-map-ui-20261128/31-days.png)
- 同日存档提供省份 4710 的活动围城记录，其中 `siege_status=1`、`day=7`、`impact=5`。它可供后续对照，这些数值目前尚未与实时内存及界面各字段建立对应关系。
