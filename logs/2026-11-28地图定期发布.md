# 地图定期发布验收

统一服务新增 `manage_political_map_export`，普通 MCP、JSONL 和自管决策服务共享配置与后台轮询。默认间隔为六个游戏月。服务以数据库、调用身份、观察国和游戏会话区分计划，重启后恢复。命令行可指定目标目录。地图说明已登记在本项目信息接口目录和同级测试项目的 MCP 调用目录。

1495.2.3 测试现场的第一次 MCP 配置立即发布，下一期为 1495.8.3。另用测试项目自身的 Python 环境和服务启动参数配置目标目录，再调用立即刷新。三张图均为 768 × 512，内嵌快照编号与省份 JSON、最新清单一致，奥斯曼数据含 1724 个已发现省份。实机日期未推进。按月跨日、月底处理、暂停去重、跨期与发布失败重试使用受控时钟验证；宿主线程在无客户端请求时完成了到期发布并在关闭时退出。[实机核对](../work/runtime/map-export-20261128/latest-check.json) · [样例清单](../work/runtime/map-export-20261128/public/latest.json)

本次核对发现上一版地图采集曾复用非玩家身份准入。移除该条件后，以实际物理席位 O00 和普通国家 ENG 在同一进程分别独立采集并发布三种尺度。两者都成功；按各自发现记录返回 0 和 1074 个省份。无领土的观察国也可使用默认中心导出。[席位对照](../work/runtime/map-export-20261128/seat-exports.json)

调用方式、三种视野、状态字段与文件读取方式见[地图导出接口使用说明](../docs/地图功能/地图导出接口使用说明.md)。
