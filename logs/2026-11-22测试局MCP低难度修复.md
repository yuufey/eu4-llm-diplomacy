# 测试局 MCP 低难度修复

本轮处理 `save-play-smoke-1495-001` 的查询、预览和回执反馈。实时战报及其他事件主动推送暂缓，后续再评估 Codex CLI。战报目录与缺参数提示指向现有的 `H01.battle_sequence`、`W03.battle_losses` 和单场 `B01` 查询。

- `T03.outgoing_value` 的简洁视图保留流出总额与逐条路线金额。`T04.power_share_percent` 使用同次采样的观察国与节点总贸易力，原生 `shares` 另有字段。相关主题通过 `missing_fields` 给出缺值的状态和可公开原因。
- `N01.loans` 返回到期日和从观测日计算的剩余天数。明细与汇总可以同批查询。`R05` 可省略交换类型读取同盟信任与人情余额。积累任务可单独查询。
- `G06` 读取目标国当前领土，再复用 `G02` 的可见性与所有权检查。每次核对至多 24 个候选，可按货物、贸易中心、贸易节点与河口筛选。后两项依赖静态游戏数据。空页可能带后续游标。
- 改善关系遇到原生通用复检拒绝时，会在同一游戏日期只读核对冷却期限并写入原请求。`P06` 解约预览报告已能核对的同盟与联姻，以及配置里的重建限制期限。两端都是外国时，当前关系仍依赖后续外国关系网来源。
- 修复 F02 外国兵力和人力及 F04/W03 占领查询的依赖校验。上一提交已更新省份读取实现和发现配置，相关来源沿用项目已审查的实现与校验路径。原始配置和证据文件的散列未改。

接口参数和可读字段见[简洁信息接口](../docs/信息导出/接口/LLM简洁信息接口.md)。24 个显式测试模块共通过 445 项和 3 个子测试，覆盖正常工具查询、持久回读、外国兵力与占领校验、省份原生读取回放、和约预览和外交回执。没有启动游戏、提交实机外交动作或改动原生构建。
